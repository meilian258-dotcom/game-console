# 方块电玩 SFC 历史核心组件

本目录保留旧独立 SFC 街机、jgenesis/WASM 核心适配及兼容注册。它现在是 **完整 SFC 附属的内部组件**，不是建议玩家单独安装的另一款 SFC 模组。

想玩 SFC 家用机，请从 [SFC 附属说明](../piq-sfc-home/README.md)开始；想用通用机柜的 SFC 选项，也安装完整 SFC 附属，不需要单独找这个核心包。

## 安装边界

- 完整玩家包名形如 `game-console-sfc-版本.jar`，包含 `piq_sfc_home` 和本组件 `piq_sfc_arcade` 两个注册 ID。
- 玩家只装配套主包和完整 SFC 包，不叠加本目录构建包、旧 core9 或家用薄包，否则会出现重复 ID 或缺少组件。
- 当前内部版本为 `0.2.0-alpha.10`，随完整 SFC50 沿用。它不是“比家用包更底层，所以必须再安装一次”的前置下载。
- 目标为 Minecraft 1.21.1、NeoForge 21.1、Java 21；具体候选配套及平台条件见[玩家指南](../piq-fc-arcade/docs/玩家指南.md)。

## 为什么还保留这个目录

旧世界可能已经放置本组件的独立机柜，也有代码使用它的核心接口和资源。保留这些内容是为了兼容，不把旧方块直接删除，也不把旧存档当作新核心的存档读取。

这条历史链使用 jgenesis/WASM；当前家用 SFC 使用 Mesen-S，通用机柜的 SFC 后端由 `piq-sfc-home` 提供。三者不是同一个玩家入口。

## 旧独立机柜怎样使用

1. 管理员对旧独立机柜 Shift＋空手右键打开游戏库，选择有权使用的 `.sfc` 或 `.smc`。
2. 玩家普通右键启动；缺少本地内容时，按本局授权从服务器取得并校验游戏。
3. 再次右键同一台机柜停止自己的本地会话。多个旧柜可以保存不同的游戏选择。

它仍是客户端单人运行的历史实现，**没有接入公共多席、公共旁观或 JNI Netplay**。不要依据完整 SFC 家用机的双人功能，推断旧独立柜也支持相同功能。

## 游戏文件在哪里

- 旧柜服务器正式库存：实例根 `game-console/piq-sfc-arcade/roms/`。
- 客户端本地导入和缓存：实例根 `sfc-roms/`，旧柜“打开 ROM 文件夹”按钮仍使用这里。
- 旧服务端 `sfc-roms/` 会在使用时经过校验复制到新库存，保留原件；同名内容冲突会拒绝覆盖，不要用删除原件来绕过提示。

这次整理只统一了服务端内容入口，没有迁移玩家存档，也没有把旧柜转换成新通用机柜。客户端缓存不等于远端服务器库存。

## 开发和验证

本目录构建产物供完整 SFC 合包使用，不直接作为玩家安装包。主包依赖、固定输入和完整打包步骤见[构建说明](../source-control/BUILDING.md)；不要因目录有 `build-wasm.ps1` 就默认需要重编历史核心。

当前内容库已包含后台扫描、校验复制和取消处理；自动测试及真实 WASM 探针不替代 Minecraft 菜单、上传、断线或多人环境的验收。
