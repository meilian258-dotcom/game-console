# 方块电玩电脑

组装一台游戏里的电脑，连接电视和键鼠，在世界中的屏幕上运行程序。机箱内的硬盘、CPU 等是游戏物品，不会格式化或挂载你的真实磁盘；这也不是完整的通用操作系统模拟器。

电脑是[方块电玩](../README.md)的可选附属，目前提供硬件测试，并可接入 PvZ 和 Flash 开发验证程序。首次安装见[统一玩家指南](../piq-fc-arcade/docs/玩家指南.md)。

## 安装条件

- Minecraft 1.21.1、Java 21、NeoForge 21.1.229 及以上的 21.1 系列；按整合包的更高要求安装。
- 多人服务器和参与客户端都安装配套主包与 `game-console-computer-版本.jar`。两端共同注册机箱、零件、外设，并同步装配和操作权限。
- PvZ 是可选依赖：要运行 PvZ 再安装配套的[测试附属](../piq-pvz-addon/README.md)。不要为了使用电脑把所有附属都装上。
- Flash 需要配套完整运行库，**不要安装旧 Flash 播放盒 JAR**。现用运行库放在执行客户端的 `game-console/piq-flash-box/runtime-stream-0.1.3/`，不能只复制 EXE 或放进 `mods`。
- PvZ／Flash 执行端目前支持 Windows x64。Flash 另依赖旧原型使用的 .NET Desktop Runtime 6 与 WebView2；不推荐据此部署生产环境，后续仍需更新运行环境。

服务器不运行这些程序；普通串流观众不需要自己的游戏文件或 Flash 运行库。源码 ZIP 不包含可直接安装的整套运行环境。

## 组装与开机

1. 放置黑色或白色机箱。空手 Shift＋右键开关侧板；安装和拆卸零件前先关机。
2. 依次装主板、CPU、散热器，再装内存、显卡、电源和硬盘。第二条内存可选；机箱主体的装配页可查看缺件与取件。
3. 放置电视与键鼠套装。用视频线连接主机和电视；用外设连接器先点主机、再点键鼠套装完成配对，配对时保持关机。
4. 打开电视，右键机箱正面的电源键。右键机箱主体，进入“本机程序”，选择硬件测试或已有的程序。
5. PvZ 选择自己准备的 `main.pak`，Flash 选择自己的 `.swf` 文件；浏览文件不等于启动，确认选择后再关闭菜单。
6. 空手右键键鼠取得操作。可用准星瞄准电视；需要固定视角时，对准电视右键。Esc 退出操作，再右键键鼠可继续。

一次只有一位操作者。普通玩家无需 OP，但仍受领地权限、主机／电视 8 格及外设正常交互距离限制。关主机、断线或结束程序是结束会话；退出操作本身不是关机。

## 旁观与轮流操作

程序默认“仅本机”。想让朋友观看，在“本机程序”页将“下次启动”改为**共享旁观**，然后启动；正在运行时先结束当前程序再修改。

共享时，主机周围 32 格内最多 8 名其他玩家接收音画。运行者允许“交接键鼠”并按 Esc 让出后，朋友可右键空闲键鼠接管；不会重开游戏，进度仍属于原运行者。

这是**音画串流和单人控制权交接**，不是 Netplay，也不是两人同时操作。运行者仍负责计算与保存，离开有效范围或断线会结束共享，没有自动转移主持。

## 程序与保存的差别

- **PvZ**：电脑入口在支持的平台默认使用公共 JNI，保留显式进程选择。游戏自身文件保存与运行器隔离，不提供任意时刻即时存档；原生故障可能使 Minecraft 退出。
- **Flash**：由 Ruffle 运行器执行，当前不保留 SharedObject 进度，退出后相应进度会丢失。键盘／鼠标支持有限，不保证所有 SWF 兼容。
- 共享不上传 `main.pak`、SWF、原文件路径或存档，只传游戏音画与授权输入。不要把旁观成功理解成游戏原生多人已实现。
- 远端画面使用有损压缩并受带宽限制；运行者的 Flash 声音沿用系统 WebView 音量，不能保证与 MC 音量设置一致。

完整操作、画质预算和失效条件见[共享旁观说明](design/电脑5-串流使用说明.md)，其中旧版安装号仅作历史参考；当前配套以实际候选包说明为准。PvZ、Flash 仍是开发验证用途，多客户端、光影和长时运行未认定稳定。

## 开发与排错

公共程序边界是 `ProgramBackend`；`ComputerPrograms` 管选择与启停，`ComputerStreamServer` 管共享会话和控制权。新程序应接这些入口，不再复制一台电脑。构建前读[统一构建说明](../source-control/BUILDING.md)，显式指定配套主包及需要的 PvZ 编译输入。

启动失败先看屏幕／聊天原因和 `game-console/piq-pvz/logs/` 或 `game-console/piq-flash-box/logs/`，不要靠覆盖任意 DLL 或重复启动解决。报告问题时附完整模组版本、操作步骤和日志，勿公开游戏或存档文件。

模型来源与第三方许可见[ASSETS.md](ASSETS.md)；代码许可不自动覆盖素材或程序内容。[历史 README](README-history.md)保留旧版本详情，不作当前安装指引。
