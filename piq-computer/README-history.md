## 安装

先正常退出游戏、备份测试世界，建议用世界副本。没有自动安装、发布或重启服务器。

1. 服务端与所有参与客户端的 `mods` 都安装 `game_console_computer-0.1.0-prototype.3.jar` 和已有的 `game_console-0.31.0-alpha.75.jar`。同 MOD ID 只留一个版本，旧电脑 prototype.1/2 放到 mods 外保留。电脑协议仍为2，建议双方电脑附属同版。已有prototype.2完整包的运行库、PvZ7和游戏文件全部沿用；本次小补丁包不重复附带它们。
2. 运行 PvZ 时，双方还需兼容 FC75 的 `game_console_pvz-0.1.0-prototype.7.jar`（完整包 `可选-PvZ/` 内提供）。已有该版本不用重复安装。使用你自己的 `main.pak`；无须另装 RetroArch 或下载 DLL。原 PvZ 播放盒仍可使用，不能同时打开同一个玩家的同一存档。
3. 运行 Flash 时，把完整包 `客户端运行库/piq-flash-box` 整个文件夹放入**实际客户端游戏实例根目录**，路径应为 `实例/piq-flash-box/runtime/FlashBox.Helper.exe`。不要放 mods、不要只复制 EXE。已完整安装相同 Flash0.1.2 运行器可沿用。**不要安装旧 Flash8 JAR，它不兼容 FC75；电脑附属已包含独立 Flash 接口。**
4. Flash 执行端暂限 Windows x64，需本机已有 .NET Desktop Runtime6 与 Microsoft Edge WebView2 Runtime。没有自动安装系统组件。.NET6 是旧原型依赖，正式发布前仍应迁移；本测试包不是面向生产环境的长期方案。服务器不需要 Windows Flash 运行库。
5. 重启后在创造分类“方块电玩”搜索“电脑”“键鼠套装”“外设连接器”。亦提供16个原版材料配方。

安装端依据：`ComputerRegistry` 两端注册方块/物品/方块实体；`ComputerEntity` 在服务端保存部件、绑定和控制者；`ComputerNetwork` 双端菜单/输入授权；`client/` 负责显示与本机执行。不是据依赖 `side` 猜测。运行器、路径、游戏内容和进度只在执行客户端，不上传服务器。

## 组装与操作

1. 放置黑色或白色机箱。已缩小为原来60%，约 **0.825格高**，新机箱只占一格。旧两格机箱加载时仅移除同型号、同朝向的旧上半部占位，保留底部零件和身份；仍需在世界副本验证迁移。
2. 空手 **Shift＋右键机箱** 开关侧板，开机状态也可以开盖。装卸零件必须关机，不要求合盖才能开机。
3. 手持零件右键安装：主板 → CPU → CPU散热器；主板上再装至少一条内存及显卡，另装电源和硬盘。第二内存槽可选。空手右键机箱主体打开装配页取件，拆卸顺序遵循依赖，生存实际消耗/返还物品。
4. 放置电视和**键鼠套装**，套装将两者放在同一格。黑/白键盘＋同色鼠标可无序合成对应套装；旧独立键盘/鼠标仍可分别使用。
5. 用主模组视频线依次右键主机、电视；新版LCD/壁挂LCD接HDMI接口。旧CRT模型没有HDMI，兼容使用AV视频端，不伪造一个HDMI孔。用外设连接器先点主机，再点键鼠套装即可同时连接两者；独立设备需分别点。外设接线需关机。
6. 打开电视，再空手右键机箱正面USB下的圆形电源键。零件齐全后开机；机箱、CPU和显卡风扇叶片随开机转动，关机停止。侧板开合不影响转动。
7. 空手右键机箱主体 → **本机程序**，选择“植物大战僵尸”或“Flash”。点击“浏览…”进入本机目录选 `main.pak` / `.swf`，也可粘贴完整路径。可上一级、切换磁盘或输入目录；不会因浏览就启动文件。点“使用此程序”保存选择，两种路径分别记住。
8. 关闭菜单，空手右键键鼠。**移动鼠标转视角，用准星瞄准电视中的按钮并点击**，不再弹出全屏预览。请先松开进入时按住的键和鼠标，避免右键穿透。人物移动/挖掘和重叠快捷键被隔离。
9. **Esc 退出操作并暂停本机游戏**，再次右键键鼠继续；换程序前，在程序页点击“结束当前程序”，等退出完成再选择另一项。关主机、关电视、断开连接、失去权限/离开范围、断线等会结束本机程序；打开菜单或窗口失焦暂停，不自动抢回控制权。

普通玩家不需要OP，仍受领地/交互权限约束。同一时间只有一人占用键鼠，其他人不能抢占。操作时与主机/电视≤8格，且处于两件外设交互范围（普通生存约5.5格）。空手Shift＋右键外设断线；断开套装会同时断开键盘和鼠标。

主机拆除会分别掉机箱和零件；重放重新装配/绑定。创造模式不掉机箱本体，零件返还。重载世界/区块保留零件/绑定但关机。此硬盘是游戏内装配部件，不会格式化或挂载你的真实磁盘。

## 两种程序的边界

| 项目 | PvZ | Flash |
|---|---|---|
| 内容 | 本机 `main.pak`；沿用原PvZ核心 | 本机SWF≤32MiB；固定Ruffle运行器 |
| 操作 | 准星瞄准，鼠标左/右键；ASCII文字、退格；Enter/Tab及原核心手柄映射 | 左键点击；方向键＋空格，WASD＋左Shift，两组同机键盘 |
| 存档 | 沿用 `piq-pvz/saves/<玩家UUID>/<内容SHA>/PvZ-Portable`；正常结束时由游戏写入 | 当前运行器不保留 SharedObject 进度，退出即丢失 |
| 声音 | 沿用PvZ本机音频，受Minecraft主音量调节 | WebView系统声音，不受Minecraft主音量/空间距离调节 |
| 多人 | 本版没有游戏旁观/远端鼠标交接 | 本版没有远端双人或游戏旁观 |

Flash是Ruffle后端，不是libretro核心；不保证所有SWF兼容。旧运行器只提供两组各五键及左键，不支持任意文字输入、右键/滚轮或依赖外网资源的所有游戏。两组按键不是两名Minecraft玩家。输出固定640×480、JPEG有损捕获，近看可见压缩痕迹；已避免原GUI后处理造成的全屏模糊，但未宣称无损画质或稳定60FPS。按键映射可沿用客户端 `piq-flash-box/bindings.json`，见运行器说明。

同服务器其他玩家在该版只能看到硬件检测页，不会收到 PvZ/Flash 音画。后续设计为主持客户端运行并保存、音画串流供旁观、确认后独占转交鼠标，以及退出／失焦强制松键；仍需音频出口、授权转发和真实多人验证，不代表该版已支持 Netplay。

## 故障与验证

- 程序启动失败会在聊天提示具体原因；Flash日志在 `实例/piq-flash-box/logs/`。路径必须是实际文件，不能填ZIP、网页或文件夹。运行器文件受JAR内固定27项SHA校验，缺文件/版本不符会拒绝启动，不绕过校验。
- 若不能切换，先结束当前程序并等待退出完成。不要把直接关闭Minecraft当作所有进度已保存。
- 仅运行自己有权使用且可信的文件；运行器限制外部资源访问不等于对恶意SWF的安全认证。包内没有ROM、BIOS、SWF、main.pak或用户存档。
- 自动测试与独立运行器验证见 `VERIFICATION.md`。Minecraft的四向模型、精确点击、迁移、领地和多客户端占用仍待验收；航空载具尚未适配，不标稳定。

## 开发

`world/` 管硬件/服务器事务，`InputLease` 管临时占用，`ComputerWorldInput` 管世界内输入隔离，`ProgramBackend` 是程序输出/输入/生命周期边界，`ComputerPrograms` 管本机选择与异步启停。`PvzComputerBackend` 复用可选PvZ7公开API；`FlashComputerBackend` 使用隔离命名空间的原Flash IPC代码，不加载旧Flash MOD。

编译使用工作区FC wrapper，项目内执行 `../piq-fc-arcade/gradlew.bat --offline check jar`；依赖冻结FC75和PvZ7。源码包包含移植前的三个Flash接口源文件和完整运行器源码，build.gradle描述隔离/补状态接口规则；不含全部离线依赖。代码GPL-3.0-or-later，模型与第三方条款见ASSETS.md及各许可证。旧prototype.1成品/说明留在原目录，不覆盖。
