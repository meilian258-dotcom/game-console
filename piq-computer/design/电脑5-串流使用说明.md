# 电脑5：PvZ / Flash 实验性串流

适用：Minecraft1.21.1、NeoForge21.1.236、Java21，FC76系列（建议已交付FC76.3）、电脑0.1.0-prototype.5、可选PvZ0.1.0-prototype.9。2026-09-26测试候选；自动测试/独立原生运行器验证不等于Minecraft双客户端验收。

## 安装

1. 退出游戏，备份世界。在服务端和参与客户端的mods替换电脑5；运行PvZ时同样替换PvZ9。旧同ID JAR移出mods保留，不与新版本并装。主包、街机、SFC、GBA沿用现有配套版本，本次未修改或重新发布它们。
2. Flash执行者把配套完整 `客户端运行库/game-console/piq-flash-box/runtime-stream-0.1.3` 复制到**实际实例的同名路径**。必须包含EXE、DLL、web、vendor、清单等全部30文件；不要放mods或仅复制EXE。不要替换旧runtime文件夹，也不要安装旧Flash播放盒JAR。已有.NET Desktop6和WebView2依赖继续使用，不会自动安装系统组件。
3. 原本机main.pak及properties、SWF路径继续使用。这里只共享画面声音及输入，不传原文件、配置路径或存档。游戏不包含在交付包内。旁观者无需自己的main.pak/SWF/Flash运行器，但须两端安装匹配模组。
4. PvZ/Flash本机执行暂限Windows x64。服务器只授权和转发，不运行DLL/WebView。双方安装依据为ComputerRegistry共同注册方块/实体，ComputerNetwork菜单输入及ComputerStreamNetwork双向载荷；不是根据依赖side猜测。

## 开始共享与技术记录

1. 按原流程装齐硬件、接电视和键鼠并开机。机箱主体右键 → 本机程序，选择PvZ的main.pak或Flash的SWF并保存。
2. 本机程序页把“下次启动”改为**共享旁观**。默认仍是仅本机，避免无意广播。限速档对下次启动生效；正在运行时先“结束当前程序”，等待完成再启动。
3. 右键键鼠启动；固定视角仍为“瞄准电视→右键固定”，Esc退出操作。主机周围32格内最多8名其他玩家自动收到同一画面和声音，不需要领取手柄或选择同一个文件。只发送给服务器已登记的附近观众。
4. 交接默认锁定。运行者Esc退出操作，打开本机程序页，将“交接键鼠”改为**允许**。其他附近玩家右键这台电脑已连接的键鼠即可接管。一次只有一个操作员，不支持抢占；当前操作者先Esc让出。领地权限、主机/电视8格和外设交互距离要求保留。
5. 运行者仍负责执行与保存，不会把存档转给新操作者。运行者本人也可以再次右键空闲键鼠接管。将交接锁定会撤销其他操作员并清空输入。无人操作时暂停，已有画面保留供旁观。
6. 关机、拆机、断电视/外设、运行者离开32格/断线或停止程序会结束共享。没有自动换主持；PvZ正常退出继续使用运行者原存档身份和文件锁。旁观者离开范围/断线只清自己的图像音频，不终止其他人的会话。

## 流量、画质与限制

- 这是**串流，不是Netplay，也不是零流量**。运行者本地画面不降为旁观规格；远端640×480 JPEG有损画面，目标上限15帧/秒，复杂画面受限速后可能明显更低。局域网可试384KiB/s档换取更多帧，96档更省流但更卡；默认192档。
- 单主持上传媒体预算96/192/384KiB/s，另有最多64KiB短时突发。音频计入预算，24kHz单声道G.711有损，约24KB/s原编码量；不是原音乐无损品质。显示的流量是媒体加固定封包开销**估算**，不是操作系统完整网卡计数，不包括MC其他包、TCP加密/压缩/重传等。
- 在一直跑满限速的情况下，192档约11.25MiB/分钟、3分钟约33.75MiB单向预算；实际取决于内容与丢帧。每多一个观众，服务器多转发一份；运行者只上传一份。因此服务器总上传可能明显高于运行者数字。
- 编码、解码、音频播放用后台线程，画面最多一个在途编码/解码结果；音频有有界队列，拥堵丢旧数据而不无限堆积。MC自身TCP链路仍可能出现延迟/队头阻塞；未保证低配机器精确音画同步或公网低延迟。
- 暂停时保留最后画面，每约2秒给观众补发一次独立图，供中途加入者显示；仍计入限速。无人旁观时不发送媒体，也不会把“暂停”宣称为绝对零流量。
- 网络统计在本机程序页；Host的“旁观”不含自己。远端声音按MC主音量、方块音量和32格距离衰减；运行者PvZ沿用原主音量，Flash沿用系统WebView音量。采集只含游戏，不录麦克风/桌面/其他软件声音。
- Flash仍仅方向键/空格、WASD/左Shift和鼠标左键，不保证所有SWF兼容，也不保存SharedObject进度。两组Flash按键不是两名玩家同时控制；本版只做一人操作、其他人观看、轮流交接。
- 原PvZ测试播放盒仍是本机模式。共享必须用可组装电脑，不通过街机Netplay菜单启动。
- 不改主包模型/核心、原目录迁移规则和真实世界。旧机柜连线漏同步问题不是本次修复。未安装、发布、部署或重启任何游戏实例。

## 首次建议测试

先在世界副本用两名玩家：A开启共享、B不选文件直接看电视；检查画面、声音与限速。A允许交接并Esc，B右键键鼠，确认不会重启游戏、没有卡住的按键；再测试B退出/A接回、锁定、离开范围、A断线与正常保存。最后分别对PvZ和Flash重复。真实MC多人、混合光影、低配/拥堵/长时测试均待验证，不标稳定。

源码入口：ComputerStreamServer服务端会话/独占授权；ComputerStreams客户端媒体与统计；stream/纯预算、封包组装、音频/图像；ProgramBackend.audioSink输出接口。PvzRuntime.audioSink返回独占PCM副本，回调必须非阻塞；Flash使用电脑专属vendor桥接与固定清单，不修改旧播放盒Java接口。
