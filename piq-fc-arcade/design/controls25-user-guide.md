# 统一键位与手柄测试版 · alpha25

适用 Minecraft 1.21.1 / NeoForge。此包没有自动安装，没有修改现有配置、ROM 或存档。

## 怎么设置

1. 进入世界按 **F7**，或输入 `/fc-controls`。原 `/fc-gamepad` 入口仍可使用。
2. 选择 **FC / SFC / 街机**，再选择键盘方案。三种系统可以分别保存偏好，设置仅影响你本人。
3. 选好后点击“保存键盘设置”。编辑自定义时先“暂存自定义”，再返回保存；取消不会修改原配置。
4. **F8** 为操作锁：按一次专心操作模拟器、停止玩家主动行走，再按一次解除并恢复世界操作；不会结束游戏。鼠标仍可以转视角，右键仍按机器原来的交互退出。操作锁不会让角色免受重力、击退等世界影响。

F7/F8 均可在页面改键。若原来的 MC / 模组旧绑定已占用这两个键，旧绑定优先，不会被新快捷键抢走；使用 `/fc-controls` 打开页面重新选择快捷键。

## 四种键盘方案

| 方案 | 方向 | 功能 |
| --- | --- | --- |
| 现有方案 | 保留原设置 | 保留原设置和备用键，不改 options.txt |
| 方向键＋小键盘 | ↑ ↓ ← → | 小键盘 1 2 3 4 5 6 |
| WASD＋JKL/IOP | W S A D | J K L / I O P |
| 自定义 | 自己指定 | 左键改键、右键清空；不允许重复或占用快捷键 |

WASD 方案进入后先按操作锁再控制游戏，解锁后 WASD 只负责世界移动。现有方案、小键盘方案默认可边移动边玩，也可以主动按操作锁切换。

新预设的开始键是 Enter，选择 / 投币是 Backspace。街机按键 1～6 对应小键盘 1～6 或 J/K/L/I/O/P；SFC 按 B/A/Y/X/L/R 排列，FC 仅使用 A/B。页面中的功能名称和实际键位是最终依据。

切方案、开菜单、窗口失焦或解除操作锁时会清空本人输入。重新开始前先松开按键、摇杆回中，再重新按下，防止卡键。不会抢走其他玩家的 P2/P3/P4，也不会把旁观者变成玩家。

## 实体手柄

统一控制页中点击“实体手柄 / 控制器设置”。这里可查看当前连接设备、选择自动或指定设备、测试按键和摇杆、调整死区，以及分别重映射 FC/SFC/街机。此页有独立的保存按钮。

新配置默认启用手柄，并自动选取第一个具有标准映射的设备；此前明确关闭过的配置仍保留关闭状态。手柄只有在取得机器控制权且当前允许操作时才会控制模拟器，不接管世界移动或其他玩家。使用 WASD 方案时同样需要先开操作锁。

按键标签使用“下键 / 右键 / 左键 / 上键”和肩键位置，避免 Xbox、NS、PS 字母布局不同造成误认。设备是否可用取决于系统与 GLFW 是否提供标准手柄映射；无法识别的设备会标为“无映射”，不会假装已适配。当前未进行实体 Xbox / NS / PS 插拔实测。

## 这次还包含什么

- 新版双人街机外观与增大的有效屏幕；保留原占地、控制分件、联机绑定和旁观流程，不自动改世界里的方块。
- 大电视 / 街机屏幕的统一有效画面几何：按实际画面区域换算光枪坐标，黑边、边框和屏幕外不算画面内。
- 独立的光枪核心原型已通过亮度、扳机、离屏和状态隔离诊断；原 FC 核心资源保持原样。**尚未接入世界里的光枪物品、瞄准操作和联机输入，因此本包不能直接拿光枪玩《打鸭子》。**
- GBA 模型保留为后续素材，本包没有 GBA 模拟器。

## 文件与手动更新

包内 `mods` 中三个文件需配套使用：

- `piq_fc_arcade-0.31.0-alpha.25.jar`：主模组，内置 FC 和共享控制组件。
- `piq_sfc-0.1.0-alpha.14.jar`：合并 SFC 附属，已包含原 `piq_sfc_arcade` 核心。
- `piq_native_arcade-0.1.0-alpha.9.jar`：原生街机附属。

更新前保存退出游戏并备份旧包，不要同时保留同一模组的新旧 JAR；使用合并 SFC 后不要再放旧 `piq_sfc_arcade`、`piq_sfc_home` 或另一份 `piq_sfc`。联机各端和服务器应更新到同一套版本。

`piq-native-arcade/runtime/piq-native-helper.jar` 是与前版字节一致的辅助运行文件，放游戏实例对应路径，**不要放 mods**。已有相同文件无需更换。本包不包含 ROM、BIOS、游戏截图或用户存档。

## 验证范围

完整构建：FC 1061 项（7 项环境条件跳过）、SFC 275 项、原生街机 46 项，失败均为 0。最终 JAR 另做键盘 / 手柄 / 几何、FML 发现、协议编解码、真实 Mixin 转换和 SFC 双工作进程输入/音画同步回归；各报告在 `checks`。

这些离线测试不等同于真实多人服务器游玩，也没有完成实际游戏窗口的外观/操作验收。请优先检查：F7 设置保存、F8 来回切换、失焦后松键恢复、右键退出、好友与旁观者不受本机设置影响，以及你的实体手柄识别情况。
