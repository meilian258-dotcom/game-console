# 方块电玩：管理终端与权限整理测试版

适用：Minecraft 1.21.1、NeoForge 21.1.236 起的 21.1 系列、Java 21。候选版本 FC58 / SFC36 / 可选 Flash prototype.5。未完成 Minecraft 实机验收，不是稳定版。

## 安装

关闭游戏、正常停服并备份世界后，客户端和服务端成套替换 FC58；使用 SFC 时同时更新 SFC36。只玩 FC / 小霸王不需要 SFC。只安装最终测试包中的 JAR，不安装工程 build/libs 中间件。

SFC36 成品合并原 core9，不再叠装旧独立 piq_sfc_home / piq_sfc_arcade。使用 Flash 时双方更换 prototype.5；继续沿用完整 runtime0.1.2，无需重新安装运行器。Native0.1.1、GBA8及其运行库本轮未修改。不含 ROM、BIOS、SWF。

两端安装依据：FC 的共同物品/设备注册、AdminTerminalNetwork / CartridgeNetwork 协议及服务端鉴权对应客户端界面；SFC 的共同硬件、SfcHomeNetwork 与服务端卡带管理对应 SfcCardEditorScreen。Flash 的共同硬件和授权协议仍需要双方安装，运行器只放实际执行 SWF 的 Windows 客户端。不是仅依据依赖声明的 side 推断。

本轮新增物品与协议，必须完整重启，两端不能混装旧版。回退需要恢复旧 JAR 和升级前世界备份。本轮没有自动安装、上传、发布或重启。

## 管理终端

OP2 获取物品：`/give @s piq_fc_arcade:admin_terminal`。手持右键，生存模式同样可用。非 OP 即使在创造模式也不能管理。

- 玩家权限：选择全体玩家或沿用授权名单；分别控制使用服务器游戏、使用服务器封面、上传本机游戏、上传本机封面。使用已有内容与上传新文件分开。
- 新机器默认：运行模式与旁观范围，只影响新放置设备，已有设备不迁移。
- 管理工具：单机设置指令菜单、本机网络诊断、全服模组流量与聊天监控。单机菜单发送到聊天栏，关闭终端后点击选项、回车确认；不是点击终端就直接切换设备界面，原螺丝刀入口保留。

已有授权名单、显式开关保留。旧配置没有新字段时保守兼容：原获准玩家保留使用服务器游戏的资格，服务器封面选用默认关闭；不会自动把所有普通玩家放开。OP 不受普通玩家的内容开关限制，领地保护和设备忙碌检查仍然有效。

流量统计为本模组已埋点的压缩前载荷，不是网卡或整个 Minecraft 的流量；旁观范围不改变区块加载、声音距离或手柄距离。

## 游戏库与存档

卡带与街机的文件来源明确显示本机 / 服务器；这是文件位置，不是本地同步 / 玩家串流 / 服务端托管。机柜运行模式仍在同步设置中选择。非 OP 需要 OP 开放相应功能，不能用创造模式绕过。

FC 卡带工作台增加具体存档管理：查看、重命名、确认删除当前 ROM 的实际服务端存档。非 OP 只能操作自己的个人存档，管理员仍受正在使用、退出收尾与并发修改保护。进入管理页不会删除、迁移或改写存档。旧 v1/v2 格式仅查看；删除先移至原存档目录下的 deleted-by-cartridge-manager 回收目录，不直接销毁文件，也不在游戏内自动恢复。目录较大达到扫描上限时会提示“部分结果”，空列表不代表没有其它存档。

本轮不把 SFC 本机恢复 ZIP、私人存档与服务端托管 SRAM 混为一个库。SFC 具体存档管理暂未交付，界面明确提示不可用；原保存与恢复机制不变。

## 交互与外观

- 双手空，右键光枪支架出线口或 FC 对应数据口拆线。实际付费连接只返还一根，历史免费连接不补发；取枪/取手柄等原操作保留。
- 新电视共用走线改为横竖主干和圆角，桌面段落在支撑高度，壁挂段在电视侧下垂。FC、小霸王、SFC 与调用同一接口的 Flash 受益；没有加入任意地形物理寻路。
- 小霸王键帽移除十处拼音小字，字母、数字、UV 与模型不变。
- 双人街机背面移至原两格占位后沿，四朝向统一；侧面宽度、十二个旧代理方块编号不变。屏幕、控制面板、碰撞和占用提示一起移动；物品栏展示保持原居中。背部接线空间仍需按实际布置留出，不宣称后接口穿墙可用。
- 常用工具提示简短显示，按 Shift 看详细操作。私人页面改为“仅自己玩”并去除菜单模糊：游戏在本机运行，别人看不到也不能加入；ROM、画面、按键和存档不上传，实体手柄借还仍联网。

## 优先验收

1. OP 切生存后用终端、螺丝刀、卡带工作台；普通玩家切创造不能获得管理权限。
2. 四个内容开关逐个开关：只允许选用服务器游戏时不能上传；关服务器封面选用时不能用旧列表提交；已有名单不丢失。
3. FC / SFC 卡带与旧 FC / 附属街机的服务器条目选用、分页缩小、领地保护、运行中禁止改配置。
4. FC 存档列表、重命名、取消删除、确认删除；游戏正在运行/正在退出时不能改删，换卡或离开工作台后旧请求不能生效。请先用可丢弃测试存档。
5. 光枪两端空手拔线、重复点击、领地拒绝和包裹已满；确认无重复掉线。
6. 多型号、多朝向桌面/挂墙接线，尤其接口正下方；双人街机四朝向贴墙，检查画面、摇杆、按钮和碰撞对齐。
7. “仅自己玩”页面文字清晰、关闭菜单继续运行、正常结束保存；与公开游戏模式区分。

构建、测试数量和冻结 SHA 以随包验证记录为准。源码断言不等于游戏交互测试，离线网格预览不等于 Minecraft 光影验收；不自动勾选“本轮已验证”。
