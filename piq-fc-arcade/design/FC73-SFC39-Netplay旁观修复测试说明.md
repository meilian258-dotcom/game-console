# FC73 / SFC39：SFC 与街机 Netplay 旁观修复

适用：2026-09-25 本地测试候选，Minecraft 1.21.1、NeoForge 21.1.236 的构建环境、Java 21。运行模拟器的客户端需要 Windows x64。不是正式稳定版，没有自动安装、部署或重启服务器。

## 更新哪些包

| 组件 | 本轮配套 | 安装位置 |
| --- | --- | --- |
| 方块电玩主模组 | `game_console-0.31.0-alpha.73.jar` | 服务器与所有客户端 |
| SFC 完整附属 | `game_console_sfc-0.1.0-alpha.39.jar` | 玩 SFC 时，两端一起更新 |
| 街机附属 | `game_console_arcade-0.1.3.jar` | 沿用现有完整包，不用另换核心 |
| PvZ 测试附属 | `game_console_pvz-0.1.0-prototype.5.jar` | **已经装了 PvZ 才需要**，两端替换旧版 |

PvZ5 仅调整兼容声明，允许 FC70～73，拒绝未核对的 FC74；旧 PvZ4 会拦截 FC73。没有加入 PvZ 联机，也没有换成新提供的优化 DLL。不玩 PvZ 就不必安装。

主模组内有公共旁观协议（本轮 `watch-2`），所以不能只给某一位玩家换 SFC 包。两端共同注册方块/物品/方块实体，以及服务端授权和客户端消息处理，均须成套更新；不是从依赖的 `side` 字段推断安装端。单人世界内置服务器与客户端共用同一份安装。

完整 SFC39 已合入原 SFC core9 的注册与资产，Mesen-S 核心字节未变。不要叠装旧 `piq_sfc_home`、`piq_sfc_arcade`，也不要用 `build/libs` 的 SFC 薄包替代完整成品。不需要另装 RetroArch。

请先正常结束游戏、备份世界，在副本测试。退出客户端并由服主安排停服后，将同 MOD ID 的旧 JAR 移到 `mods` 外保留，再放入新 JAR；不要删除游戏库或保存目录。压缩包先解压，只把需要的 JAR 放进 `mods`。不混装未核对兼容性的旧 Flash8；GBA 本轮未改。

## 修复内容

- SFC 的旧默认本地旁观流程排除了 Netplay；街机 Netplay 也仅续期操作玩家。本轮为附近非操作玩家增加独立的原生 Netplay 旁观连接。
- 不拿手柄即可观看和听声音。领取 2P 时退掉自己的旧旁观连接，归还后可重新旁观；旧连接的清理不会误撤销新的 2P 身份。
- 旁观不申请手柄、不发送操作、不上传或修改游戏、不读写存档。给 2P 保留连接名额，每局至多 7 个此类只读旁观连接；每个客户端同时自动旁观一台设备。
- 沿用旁观距离、维度、设备身份、接线和连接代次校验。离开、关机、拆机或主持退出时结束相应旁观。回到范围后重新接入，不迁移主持。
- 若缺少当前公开会话的游戏缓存，按服务器授权下载并校验哈希；街机沿用该机柜已共享的游戏及声明的辅助文件清单。不是任意游戏库浏览权，也不允许服务器指定新的核心程序。
- Netplay 旁观在本机运行同一核心，通过既有 Minecraft 连接交换状态与操作数据，不是主持画面推流。首次同步、下载或追进度需要等待，也会占本机算力和流量。

FC 自身普通/光枪 Netplay、旧模式与用户保存未改。旧 SFC 本地输入同步的 `local` 旁观仍要求先导入同游戏；本轮自动缓存仅用于新的 Netplay 旁观，不偷换旧规则。

## 怎样测试

1. 两台或三台客户端与服务器统一更新。用第三人只看不拿手柄，最好先测这一项，避免用“2P 能玩”代替旁观验收。
2. 主持正常关机后，在设备设置选择 **RetroArch Netplay（实验）** 再开机。保持该模式要求的关闭存档设置；本轮没新增 Netplay 存档。
3. **SFC：旁观玩家输入 `/sfc-watch local`**（默认选项，也是重试入口），站到已开电视附近，不拿手柄，等画面与声音出现。`/sfc-watch off` 会关闭 SFC 旁观；如果之前按旧说明切过 `media`，本次先切回 `local`。
4. **街机：使用通用机柜的 Netplay 模式**。先用恐龙快打 `dino.zip`，再测三国战纪 `kov.zip`；后者需要匹配的、按原共享流程准备的 `pgm.zip`。不是旧 `LOCAL_SYNC` 模式，不下载互联网 ROM/BIOS。兼容的其他 FBNeo 游戏也可选，但不保证每个版本和变体。
5. 旁观正常后，允许 2P 加入，领取第二只手柄：应能操作；归还后停留原地：应恢复旁观且不能再操作游戏。再试一次领取和归还。
6. 走出旁观范围再返回；另测退出服务器再加入、主持关机。旧音画不应残留，重入应看到当前游戏，不是开头。

不要用暂未修复的“流量监控一直为 0”判断有没有 Netplay。仍黑屏时，请提供双方版本、模式、是否持手柄、首次等待时间，以及 `logs/latest.log` / 运行环境的复制诊断。不要发送游戏 ROM 或私人存档。

## 验证边界

最终构建检查：FC 2336 项（8 项既有跳过）、SFC 482 项、PvZ 28 项，均零失败。包含新的只读票据、2P 名额、角色切换、真实旁观消息编解码、取消下载与分片校验测试。

交付包的独立原生三进程与命名模块测试结果见同目录 `verification.json` / `SHA256.txt`。这些检查不是 Minecraft 多客户端实机验收，实际领取/归还、网络波动和长期运行仍需按上述步骤验证。FBNeo 既有完整状态 CRC 差异未在本轮修复，不把可见画面匹配当作完整确定性证明。
