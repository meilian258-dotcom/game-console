# FC76.10 / 电脑6：遗漏需求整批补做

适用：2026-09-27，Minecraft 1.21.1、NeoForge 21.1.236、Java 21。主包 `0.31.0-alpha.76.10`，电脑 `0.1.0-prototype.6`。测试候选，未做 Minecraft 实机验收，未自动安装或发布。

## 本轮已实现

1. **单人竖屏街机（3:4）**：新增独立物品 `piq_fc_arcade:portrait_cabinet`，使用所提供模型套件，等比缩为两格高，屏幕仍是3:4。独立上下方块共同组成机柜，上半部可点击，单台只开放1P。八组摇杆/按键按现有输入动起来；四朝向屏幕、当前游戏配置、联网/旁观、投币和配对接入已有机柜系统。侧面上方只有一个小翘板电源：通电亮红、关闭暗红、翘动方向切换，使用76.9开关咔嗒声。
2. **双人街机选框收紧**：按真实模型分层生成轮廓，斜屏前方不再是一大片空矩形。新旧占地、四朝向和代理块沿用，不改变旧柜身份/配对，不要求拆机重放；原双人柜碰撞逻辑不变。轮廓是小台阶近似，不是逐三角形描边。
3. **鼠标移到键盘右边**：黑白套装统一调整，以面对键盘的使用者方向为准，两件仍在一格内。创造栏不再提供单独键盘/鼠标，取消四个单件配方，套装直接用原版材料合成。保留旧ID、贴图、物品和旧存档绑定，不清空玩家背包；已有同色旧键盘＋鼠标仍可合成套装。
4. **无线键鼠**：去掉键盘/鼠标至主机的两条外设线，有有效配对时在主机前置USB口显示小接收器。电视视频线/HDMI不删除，PvZ/Flash已有运行与串流协议不改。

此前76.9已实现的街机通讯线落地、单侧小开关及音效继续保留；竖屏柜通讯线接口按新柜尺寸适配。落地线仍以柜体支撑平面走线，不是复杂地形自动贴合。

## 安装

退出客户端/服务器并备份世界，将包内 **两个 JAR** 分别替换双方 `mods` 中的主包和电脑附属；同MOD ID不可并装。旧包移到 `mods` 外保留。服务端与所有客户端使用相同配套版本。

- 主包：`game_console-0.31.0-alpha.76.10.jar`
- 电脑：`game_console_computer-0.1.0-prototype.6.jar`
- 沿用：街机 `0.1.5.1`、完整 SFC41/core9、GBA10；电脑运行植物大战僵尸时沿用 PvZ9，Flash沿用已有完整运行器 `0.1.3`。本小补丁不重复附送这些旧组件。
- Flash/PvZ文件、运行库、ROM/BIOS、用户存档不移动、不清理。包里没有游戏内容。

安装端依据：主包共同注册新方块/物品/BE，服务端管理席位/投币/机柜权限，客户端绘制模型；电脑共同注册配对工具、方块及网络，服务端保存绑定，客户端绘制接收器/运行程序，故两者均双方安装。并非仅从依赖side推断。

## 使用

### 竖屏柜

创造分类“方块电玩”搜索“单人竖屏街机”；生存可用铁锭、红石、玻璃、石按钮合成。上方需空一格。默认已安装街机附属时选择原生街机后端；否则仍需安装兼容附属，并由管理员选好后端。

空手 Shift＋右键进入已有机柜设置/选择入口，配置游戏和运行方式；右键侧上方小红开关通断电。开机后正常右键进入/退出操作；1P退出操作不是点击电源关机。手持现有街机币点击正面投币器；PGM设置仍要求OP。游戏方向/比例沿用服务器游戏资料及核心旋转信息，不能通过竖柜强制把横屏游戏变成竖屏游戏，横屏内容会保持比例留黑边。

竖屏柜单台1P；接通讯线后按物理控制台分配席位：两台单人柜2席，单人柜＋双人柜3席，并仍受后端实际人数上限限制。多人真人验证尚未进行。

### 无线键鼠

1. 放组合键鼠，鼠标自动位于右侧。
2. 关机，拿原“外设连接器”（现名 **USB 无线接收器配对工具**）先右键电脑主机，再右键套装；主机USB口随配对显示接收器。工具仍是可重复使用的配对工具，不是额外消耗一个USB物品。
3. 原有效配对无需重连；更新后线消失、接收器显示。断开仍用空手Shift＋右键外设；全部外设断开时接收器隐藏。
4. 开电脑并选择PvZ/Flash。右键键鼠控制电视，瞄准电视后右键固定视角、Esc退出，沿用电脑5操作方式。无线不代表无限距离：原8格配对/控制范围和权限规则不变。

黑白套装直接配方：3个石按钮、铁锭、红石、铜锭和对应染料，无序合成。旧单件只为兼容保留，不再作为推荐入口。

## 模型来源

竖屏模型来自用户提供的 `单人竖屏街机_3比4_完整模型套件.zip`，SHA256 `24442BDB4D3AFD9148D22474897F2E99DB354983FE006BE9D3548DE9EFFF2F0A`。只解析模型/贴图/分组数据，不执行包内指令或代码。保持原贴图与UV，导出9个Java模型（坐标减半以满足Java模型范围，渲染再还原并统一缩放）。代码GPL许可不自动覆盖用户提供资产，公开发行前仍需提供者确认许可。

键鼠与接收器派生自原黑白主机/键鼠套件，只改模型坐标和现有UV取样，不改原PNG。生成器分别是 `tools/import_portrait77.py`（文件名77为开发名，发行76.10）和电脑 `tools/wireless6_assets.py`。不要重跑历史全量导入器覆盖本轮改动。
