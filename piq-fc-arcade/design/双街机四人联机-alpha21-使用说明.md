# 双街机四人联机测试版 · alpha21

这是待实机验收的测试包。MC 1.21.1 / NeoForge；请先在备份测试世界验收。

## 包里是什么

| 文件 | 用途 |
| --- | --- |
| `mods/piq_fc_arcade-0.31.0-alpha.21.jar` | 必装主包，仍内置 FC；提供通用机柜、通讯线和多人房间 |
| `mods/piq_sfc-0.1.0-alpha.9.jar` | 可选 SFC 附属；包含旧 SFC 核心和家用机，不另装旧拆分包 |
| `mods/piq_native_arcade-0.1.0-alpha.7.jar` | MAME 街机附属，四人街机需要它 |
| `piq-native-arcade/runtime/piq-native-helper.jar` | 新版四端口辅助程序，放游戏实例根目录的对应子目录，**不是放 mods** |

所有参与者和服务器都要更新主包及本局使用的附属，不能与旧版混用。先退出游戏/停止服务器并备份，再手工替换这三个模组的旧版本；其他模组不动。已经使用合并 SFC 包时直接替换它，不要再同时安装 `piq_sfc_home` 和 `piq_sfc_arcade` 两个旧拆分 JAR。

P1 的电脑负责运行 MAME，需要原来已配置好的 Windows 64 位 MAME/JNA 运行库、自己的 ROM/BIOS，并将旧 helper 移到备份目录后换成包内的新 helper；旧 helper 与新协议不兼容。已有 `mame_libretro.dll` 和 JNA 保持不变。本包不包含这些运行库、商业 ROM 或 BIOS。其他参与者由主机接收音画，不在各自电脑再运行一份 ROM。服务器也不运行 MAME；同版模组仍要装。

## 两台双人街机怎么接

1. 放置主模组里的两台“双人街机”，建议紧挨摆放。不要使用旧独立 Native 机柜，它仍是本地路径。
2. 管理员在第一台空手 **Shift + 右键** 打开配置，选择 MAME；P1 在自己电脑的这台主机配置中选好游戏。选游戏会试启动，**再次右键主柜结束这次试启动，再接线**。外观也在首层菜单，和通讯线独立。
3. 从创造物品栏取得“街机通讯线”（可重复使用，暂时没有生存合成配方），或用命令 `/give @s piq_fc_arcade:cabinet_link_cable`。
4. 手持通讯线，先右键第一台，再于 60 秒内右键第二台。第一台是 **P1/P2**，第二台是 **P3/P4**，顺序决定主副。第二台自动采用第一台的模拟器类型，两台皮肤各自保留。
5. 收起通讯线，P1 空手右键第一台启动。准备好后，第二位玩家右键第一台加入 P2；第三、第四位玩家依次右键第二台加入 P3/P4。每个人操作自己的按键，不分配同键盘 P2。
6. 四位参与者看到的是同一个核心的同一局，两台屏幕同步显示。再次右键自己加入的那台退出；**P1 退出结束整局，其他人退出只释放自己的席位**，空席可以再加入。

接线/拆线限管理员 OP2，普通玩家加入不需要 OP。两台需同维度、间距不超过 16 格；完成接线/拆线时操作者还需同时在两端 8 格内并拥有交互权限。先结束本局，再手持通讯线 **Shift + 右键** 拆线。连接会保存在世界中；卸载区块不删连接，但当前游戏会结束，重新加载后再启动。真正拆掉任一机柜会解除连接。未接线时，每台外部核心机柜最多两席。

默认方向键控制街机方向，J/K/U/I/O/P 为动作键，Backspace 选择/投币，Enter 开始；各玩家的按键只送到自己的端口。WASD 和鼠标继续用于 Minecraft，Esc 是原版菜单，不作为必需退出键。菜单、失焦、断线会清除对应玩家的按键。

## 人数与本版边界

- **必须是支持四人及对应四端口设置的游戏/ROM 版本**。接线不能把双人游戏变成四人；《拳皇97》仍是双人。不同游戏可能共用或分别使用投币口。
- FC 与当前 SFC 适配器只有两端口，不支持这次四人串联；SFC 家用机继续使用先前的双人邀请方式，本包没有改它的播放/邀请协议。
- 这是单核心主持 + 音画传输，不是两份模拟器互相锁步，也不支持模拟原机专用跨机板通信。只有参与本局的客户端显示同步音画，尚未增加旁观者观战。
- 视频为限带宽压缩传输，目标约 20 fps、最高 384×288；复杂画面会降低分辨率/丢弃旧视频帧，远端不等同 P1 的本地画质与响应。未实现回滚、主持迁移；P1 断线、机柜被拆/卸载会结束本局。
- 模型/贴图、双人机柜原占地没有改。本版通讯线是连接功能和物品，尚未绘制两台之间的实体线缆模型。

## 已验证与建议验收

FC/SFC/Native 完整离线构建测试：913 / 216 / 46 项，0 失败/错误；FC 有 7 项 Windows 符号链接权限相关跳过。最终 JAR 另做协议、发送队列背压、持久化、原生四端口、SFC 双 JVM 回归，详细结果随包附上。

**尚未完成四个真实 Minecraft 客户端的游戏内联机验收**，也未对所有商业游戏或权限插件作兼容保证。建议先用四位玩家在测试世界检查：两柜各两席 → 同画面/各自输入 → P3 退出再加入 → P2 打开菜单不影响别人 → P1 退出全局结束 → 保存重进后连接仍在。若某个游戏无法进入四人，请反馈游戏版本、各端日志及使用的机柜类型。
