# 创造栏公开事件兼容修复 · FC76.59

维护者：像素匠 / 方块电玩维护组。日期：2026-10-17。

适用 Minecraft 1.21.1、NeoForge 21.1.236、Java 21；主包开发候选 0.31.0-alpha.76.59。本次仅调整创造栏内容构建，不改变模拟核心、存档身份、设备注册 ID、网络协议或附属依赖。

## 需求与实现

打开创造物品栏时，主包原先通过 `CreativeHardwareOrderMixin` 在 `CreativeModeTab.buildContents` 尾部直接替换私有集合。这使简单的物品分组依赖 Minecraft 内部字段和其他优化模组的注入顺序。现移除该 Mixin 及其配置，保留普通的 `DeferredRegister` / `CreativeModeTab.builder().displayItems(...)` 注册，并通过 NeoForge 公开事件排序。

| 需求 | 实现 | 验收 |
| --- | --- | --- |
| 普通注册并避免创造栏 Mixin | 删除 `CreativeHardwareOrderMixin`；`FcArcadeMod` 注册 `BuildCreativeModeTabContentsEvent` 的 LOWEST 回调 | 检查最终 JAR，真实加载与重复构建 |
| 保留主包与附属用途分组 | 复用 `CreativeHardwareOrder` 原有稳定排序；仅处理 `piq_fc_arcade:fc` | 核对主机、街机、电视、电脑、配件和未知物品 |
| 保留标签与搜索可见性 | 分别快照公开父标签/搜索集合，使用事件 `remove` / `accept` 的单独可见性操作 | parent-only、search-only、两者可见及不同组件栈测试 |
| 保留退役物品和旧世界兼容 | 仅从本标签与搜索入口过滤 `piq_pvz:player_box`，不删除其注册 | 真实附属注册表与内容检查 |

## 接口与兼容边界

沿用 NeoForge 21.1.236 的 `BuildCreativeModeTabContentsEvent` 和 `EventHooks.onCreativeModeTabBuildContents`。事件提供不可修改的集合视图及公开的增删接口，排序不修改视图、不替换原版字段。FML 4.0.43 的 `ModLoader.postEvent` 按优先级逐轮遍历所有模组，LOWEST 因此在所有默认 NORMAL 回调之后执行；本仓库现有附属使用普通回调。其他模组若也使用 LOWEST 并随后添加内容，按其回调顺序保留，不承诺本回调总是最后一个。

ModernFix 的 `perf.memoize_creative_tab_build` 会包裹 `buildContents` 并缓存构建参数。本修复不要求关闭该优化，不更改 ModernFix 配置。正式注册接口承担集合构建，参数变化时重新触发正常事件；命中缓存时沿用已经排好的内容。上游参考：[ModernFix 1.21.1 固定源码](https://github.com/embeddedt/ModernFix/blob/1957e7798d9b0c51dfacec1cd39a74c58b4dd2b5/src/main/java/org/embeddedt/modernfix/common/mixin/perf/memoize_creative_tab_build/CreativeModeTabMixin.java)。

本次未取得反馈环境的完整崩溃栈，不能将方法交集直接认定为某种确定异常。修复消除原有内部字段 Mixin 依赖；验证结果与未覆盖范围分开记录。
