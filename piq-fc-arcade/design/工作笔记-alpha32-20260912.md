## 范围与当前状态

该版本包含四项联机优化和游戏内同步模式切换。实现和最终 JAR 验证完成；成套包在该记录时间仍处封装校验阶段。模型、ROM、BIOS、个人存档和核心二进制不变。

1. 街机游戏绑定到服务器世界：管理员明确选择后受控上传 ROM 与白名单 BIOS，后续启动者按内容哈希下载，解决只存在原启动者本机的选项。缓存限额、路径/链接拒绝、连接/租约复验、有界分片与发送完成背压齐备。
2. `Shift + 空手右键 → 同步 / 网络`：管理员仅在相连机柜均空闲时切换，下局生效。SFC 机柜支持传画面/本地同步；FC/NES 和 FC/SFC 家用保留原本地输入同步；GBA/MAME 本版保留传画面。
3. 传画面独立音频发送、自动 20/30 帧及诊断，保持 1 MiB/s 负载预算。不是核心 CPU 超频，不保证消除《合金弹头2》原机减速。
4. 家用 SFC 周期状态检查、仅异常端快照与有界历史恢复；机柜本地同步复用同一实际 SFC 核心，输入序列/状态恢复/生命周期隔离。首次邀请仍需审批和短暂停表，未做无缝 Host 迁移。
5. MAME 真实《拳皇97》《合金弹头2》两实例从头一致，但快照恢复 PCM/完整状态不满足可靠同步资格，因此本地同步明确禁用；不把仅画面一致冒充通过。
