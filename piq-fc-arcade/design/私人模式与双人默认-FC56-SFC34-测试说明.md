# 方块电玩：私人模式与双人默认

适用：Minecraft 1.21.1 / NeoForge 21.1.236，FC 0.31.0-alpha.56，可选 SFC 0.1.0-alpha.34（最低 FC56）。本地候选测试版，尚未通过 Minecraft 实际双端人工验收，不是稳定版。

## 安装

服务器与玩家客户端均使用 FC56；需要 SFC 时两端同时使用 SFC34。SFC 合包包含原 core9，不叠装旧独立 piq_sfc_home / piq_sfc_arcade 包。只玩 FC/小霸王不需要 SFC。

正常退出游戏、停止服务端并备份世界和配置后，手动将相同 MOD ID 的旧 JAR 移到实例外备份，再换新 JAR，完整启动。不要删除 ROM、BIOS、存档或旧交付包。本文不表示已自动安装、停服或发布。

Native 街机 0.1.1 / GBA8 未修改，本包不重复包含；用户提供的 Native 故障按要求暂不处理。

## 私人模式怎么用

1. 正常摆放 FC/小霸王/SFC，接好视频线和完整电视；公共主机保持关机、无公开游戏。按原操作借出实体手柄并拿在手中。不需要向卡带写入私人 ROM，也不需要普通玩家上传权限。
2. 输入客户端指令 `/gameconsole-private`（不要求 OP，也不会把这个指令发给 Minecraft 服务端），或在设备调试页点击“私人模式”。没有手持有效手柄时不能启动。
3. 粘贴自己电脑上 ROM 的完整绝对路径，例如 `D:\Games\demo.nes`。FC/小霸王使用 `.nes`，SFC 使用 `.sfc` / `.smc`。不提供 ROM、不下载服务器 ROM、不修改服务器卡带；实际格式和大小仍由核心校验。
4. 点击“仅在本机启动 / 续玩”，关闭菜单后松开全部游戏按键再操作。实体手柄的 P1/P2 都只作为你这一局的本地 P1；首版私人模式是单人，其他玩家不能加入这一局。
5. 再次输入该指令、或私人游戏中持手柄右键非收纳槽位置，可以打开私人菜单。点击“结束并保存到本机”，等待实际保存结果。也可 `/gameconsole-private stop`。右键本机手柄槽仍走原服务器归还，先结束私人局；私人时点本机电源/重置只结束私人局，不替你打开公共游戏。

私人模式只支持这三种家用机，不支持街机、GBA、光枪或私人双人。键盘、位置锁、实体 USB 手柄继续使用原本地配置。菜单、失焦、暂停、暂时不手持时停止推进并松键；主副手互换也重新等待松键。手柄归还/掉落/失效、超过手柄有效距离、断线、死亡、换维度、设备拆换/拔线/卸载、电视公共电源或公共会话状态变化都会停止私人局。

## “不上传”的具体范围

私人核心不加入公开会话，不发送私人 ROM、手柄游戏输入、音画、分数/摘要、快照或存档；不发布给旁观者。只自己看见电视上的私人画面和本地开机灯，电视无信号画面/提示音只在自己客户端被遮住。其他人仍看到服务器原有电源状态。

Minecraft 普通人物移动、聊天、物品、实体手柄借还和服务器区块/设备同步仍联网，不是断网或全客户端零流量。流量监控会注明私人模式，但连接累计值仍包含已埋点的其它模组业务，不能把它理解为私人游戏上传量。

私人入口不会改变服务器公共模式。若别人启动同一台公共机器，客户端观察到新信号/会话/手柄状态后停止私人显示和输入；私人状态不告诉服务器，因此不承诺与其他玩家的公共开机动作做到跨客户端原子互斥。

## 私人存档

保存在游戏目录 `piq-private-home/<玩家UUID>/<服务器地址SHA256>/private-saves-v1/<机型>/<核心身份SHA256>/<ROM完整SHA256>/`。单人内置服务器使用固定本地标识；同账户同 ROM 的不同单人世界可共享这一套私人进度。

与服务器卡带存档、原本地输入同步恢复备份、玩家串流和服务器托管存档分开，不自动迁移或覆盖。每个身份保留当前和上一份已校验档；读取校验身份、长度、SHA 与 ZIP 结构，损坏时拒绝启动并保留原件，不自动修复或回退。正常退出才保存，没有定时自动存档；核心异常不覆盖上一份。FC 保存核心完整状态，SFC 保存状态和 SRAM 并验证恢复。

点击“结束并保存”后必须等成功提示，失败不表示成功。正常关闭客户端最多额外等待 8 秒保存；超时记录“未确认”，不会中断写入线程。强退、蓝屏、断电或进程被杀不能保证本局保存，请先手动正常结束。不要把上一份完好档等同于本局最新进度已保存。

## 公开双人默认

新建/尚无明确配置的 FC、学习机、SFC 默认无需申请加入；新游戏/新卡带的未配置人数默认 2，实际游戏仍需支持双人。第二位玩家按原方式领取第二只实体手柄即可加入，保留原领地保护、距离、席位、租约和就绪校验。

已有明确单人设置、加入需同意开关以及旧存档人数全部保留，不批量覆写。旧机器若仍要申请，管理员在设备调试页关掉“加入需同意”；旧单人游戏由管理员按原卡带/游戏库设置调整。街机旧规则不随此修改。

## 验收清单

- 三机型分别在服务器公共关机状态借手柄，普通非 OP 选本机文件启动；第二客户端看不到私人画面，也不会因拿 P2 加入。
- 断网/换维度/拆换设备/归还/丢手柄可停止，关闭菜单、切手柄、失焦后无残留按键；原借还数量不变。
- 私人正常结束后同 ROM 恢复，公共卡带档不变；损坏私人档拒绝且原件保留；确认音量、静音和所有电视画面正常。
- 新公开 FC/小霸王/SFC 两人无需申请；旧明确审批/单人/存档人数保持；保护区域仍禁止未授权借取。
- 验证包内 `验证结果.json` 记录本次自动测试和真实冻结 JAR 探针；这些不替代 Minecraft 双端、光影、声音、硬件手柄和保护插件实测。

本包沿用 FC55/SFC33 的上传权限、授权服务器库与电视深度间隙修改；没有携带 ROM/BIOS，没有修改原 WASM、SFC core9、正式模型与 PNG。
