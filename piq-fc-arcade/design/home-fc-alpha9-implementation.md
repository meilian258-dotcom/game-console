# 家用 FC alpha.9：卡壳拆装、按键动画与宽屏 LCD

日期：2026-09-09；负责人：像素匠（Codex）。目标 Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21。
本地交付，不自动安装客户端、上传服务器、发布版本或关机。协议 27，需要双端更新。

## 范围与设计

- 双人柜由约 2 格增至 2.35 格高，厚顶牌及喇叭区恢复层次；原屏幕、两组摇杆、操作台与下柜世界坐标保持 alpha.8，不把整台等比拉长。顶部原始模型 Y 下移 5.6 单位，BER/物品补偿 0.35 格，保持原生 JSON 顶点边界内；第三层实际碰撞仅 0.35 格，原 12 格归属保留。
- 新 `wide_lcd_tv` 实际外框 24×15 模型单位（1.5×0.9375 格），薄板/底座不增厚。屏口 22×12.375，为严格 16:9。`WideLcdPresentation` 调用 `ScreenAspectFit`，缓存四朝向的 4:3 完整视频；左右各 2.75 模型单位黑边，完整 UV。不是 ROM 自动比例识别。现有 `/fc-client aspect` 仍只影响双人柜。
- 新 LCD 用相邻两个水平格放置，新 ID 和独立 `WideLcdTvAssemblyLedger`，不扩大旧单格 LCD 或改动旧 CRT/其存档。所有代理点击通过 `HomeTvStructure` 分流，复用主机连接、会话和原权限校验。snapshot 取消、逐格回滚、关闭后单次掉落、卸载延后清理及外来替换保护均保留。三色 AV 插口使用新几何，旧签名兼容。

## 卡带拆装

- 完整卡主手 Shift＋左键由客户端 HIGHEST 输入事件取消攻击/挖掘，提交独立 `CartridgeNetwork.DismantleRequest`；不在客户端写背包。
- 服务端验证当前主手、热栏、卡 ID、修订号、数量、潜行、生存状态、背包界面与冷却/请求重放。完整卡替换为 PCB；原封面空壳放进背包空位。满包不消耗、不掉落。创造模式没有免消费例外。
- PCB 仅保留 ROM、内部标题和固定外观；名字/提示/渲染不显示游戏信息或封面，但这不是加密 ROM/NBT。可直接插 FC 和小霸王，写 ROM 编辑器仍只接受原完整卡及原 OP 权限。
- 主手 PCB＋副手空壳，Shift＋右键合回；ROM 来自 PCB、封面来自空壳。两个输入消耗成一个完整卡，可换壳。准确槽位暂存事务保护，回滚时不复制；替换物品会使旧编辑绑定失效。
- `CartridgeAssemblyMetadata` 仅检查显式 ComponentsPatch；默认组件不拦截。显式改名、描述、第三方组件/根数据、显式移除和未知字段不能安全拆分时，提示并拒绝原地保留，不静默丢数据。
- 三种板首次拆出随机固定：长 DIP、双 DIP、黑色环氧封装；反复装拆不重抽。模型使用原生方块纹理、代码几何，不新增 PNG、不包含游戏内容。空壳是错开两片的凹壳，原标签平面和 UV 完全保留。PCB/壳为独立注册物品，不能直接降级旧版本读新物品。

## 手柄

`ClientNesWorker` 发布实际完成模拟帧的按键快照；`ClientControllerAnimation` 校验本机借用身份和 P1/P2，再控制原模型的独立按钮面。
D-pad 倾斜、A/B/SELECT/START 下压回弹。FC P2 原模型没有 SELECT/START，不伪造按键；小霸王上下同列按 A/B 有效输入联动，没有新增连发。
FC 复用原 PNG/RawSkinUv；小霸王复用原 held 网格，停靠模型不动。没有引入机械动力依赖。

手掌和袖口围绕握持点默认放大为 1.18 倍，原低位手柄姿态不抬高。`/fc-client hand-size 1.0..1.3` 本地保存。
失焦、GUI、暂停、退出、失效借用清零；换会话第一帧清零，避免旧线程结果回写。
动画目前只保证本机第一/第三人称，未增加向其他玩家广播按键动作的数据包。
