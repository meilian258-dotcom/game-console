# 方块电玩 · 统一线材与流量监控测试版
适用：Minecraft 1.21.1 / NeoForge；FC 0.31.0-alpha.50、SFC 0.1.0-alpha.29。2026-09-17。

## 安装
这是本地测试包，不是已完成实机验收的稳定版。

1. 备份世界和当前模组文件，先在世界副本测试。
2. 解压本包；客户端、服务器均安装 game_console-0.31.0-alpha.50.jar。
3. 需要 SFC 时，两端同时安装 game_console_sfc-0.1.0-alpha.29.jar。SFC29 使用 FC50 的只读诊断接口，最低需要 FC50。不要同放旧版本或另装独立 piq_sfc_home / piq_sfc_arcade；SFC29 已合并原 core9。
4. 只玩 FC/小霸王不需要 SFC 附属。街机 0.1.1、GBA8 继续沿用，本次未重编也未放进更新包。
5. JAR 更换后完整重启对应游戏/服务器。外层 ZIP、文档、校验清单不放进 mods。

两端安装依据：FC 的公共方块/物品注册、FcNetwork 和服务端连接服务；SFC 的 SfcHomeNetwork / SfcHomeServer 服务端租约，以及 SfcHomeClient / SfcPlayback 客户端执行。不是只凭元数据中的 side 推断。主协议38及既有同步协议未变。

## 本轮修改

### 共用新电视走线
FC、各小霸王布局与 SFC 接新电视时，共用同一个主干路由；只保留接口位置、主机外壳和同轴/AV/Multi-Out 接头差异。SFC 实际渲染入口调用主包的共享实现，并非仅替换预览。

- 桌面：主干下降到支撑高度后横向走线，AV 分支自然下垂，不再保留半空的汇合高度。
- 壁挂：电视侧沿墙下降，地面横向连接到主机；移除“主机侧升高后横跨”的悬空桥。
- 紧贴墙的 FC 正下方连接仍保留空间较短的同轴转接头，但改为向下弯，后续仍走同一条公共路线。
- 增加远距离自适应采样，保留 256 点上限，避免合法长线因超过点数而整根不见。
- 原有旧电视路径保持不变。既有 LCD 电源/待机红灯、光枪与街机扣线及单次返还修复保留。

这不是实时软体物理或任意障碍寻路；它依据设备和已知支撑高度生成确定性线条。复杂桌子、台阶、其他模组模型等仍需实机检查，不能保证自动贴合所有地形。

### 网络监控
在原“托管帧率 / 网络”页面中，“流量监控”页显示：

- 当前实际同步模式、设备与控制/旁观角色；优先显示正在控制的设备。
- 实时上传、下载 KiB/s。
- 本次连接累计上传、下载、合计，按 B / KiB / MiB / GiB 等自动换算。
- 完整接收视频帧率，最多列两路，更多以数量提示。

HUD 原默认关闭，仍可在该页面切换。隐藏 HUD 或换维度不清零，断开连接、重新进入或换服务器清零；没有跨游戏启动永久累计。SFC29 新增只读模式提供者，不修改按键归属或模拟过程。

“托管设置”单独页签保留原20/30/60 FPS设置与权限，不改变模拟速度。

统计口径是当前连接上所有已埋点的本模组载荷合计，不是单台设备，也不是电脑网卡总流量：包括 FC/小霸王、SFC家用和共享机柜及文件传输，在 Minecraft 压缩前统计成功编解码字节；不包含原版、其他模组、TCP/加密开销或历史 SFC core9 独立协议。1 KiB = 1024 B。单人同机内部连接不经过网络，显示0；接收FPS不是Minecraft渲染FPS。

旁观音画协议没有下发主机同步模式时，明确显示“旁观音画（主机模式未下发）”，不猜测模式。

## 建议人工验收

1. FC、小霸王、SFC 分别连接桌面液晶、小CRT及壁挂液晶；从正面、侧面和背面看贴面、插头和线材。
2. 主机放壁挂电视正下方，测试紧贴墙及离墙一格、多朝向、不同高低、接近8格距离。
3. 验证旧电视连接、液晶开关/红绿灯、光枪及街机成功扣线/拆线单次返还未回退。
4. 多人服务器开启 HUD，分别启动本地输入同步与可用的音画模式；看当前模式是否对应正在控制的设备。
5. 传输游戏或接收音画时看上下行累计增长；关HUD再开、切维度后累计应保留，断线重进应清零。
6. 测试 SFC 操作与旁观，以及单人同机连接0流量的说明；检查 GUI 不同缩放下页面与悬浮窗。

桌面与壁挂线材、模式显示及累计流量应分别验收，不能以其中一项通过代替整批验收。
