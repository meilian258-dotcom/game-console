# 光枪、改版街机、GBA 最终模型合集

- `01_光枪_带展示支架`：橙灰 Zapper，带展示底座、连接线和插头；本体尺寸未放大，支架与扳机独立分组。
- `02_双人街机_上半部重塑大屏版`：最新版双人街机，上半部重新设计、屏幕扩大，保留边框和按键动画分组。整体 1.5 格宽 × 2 格高 × 1.1 格深。
- `03_GBA_经典横版`：横版 GBA，独立按键分组，可替换屏幕和完整 UV 皮肤。

每个文件夹都有可编辑 `.bbmodel`、静态 Java `.json`、一张完整 PNG 皮肤、预览图、映射与使用说明，以及 `minecraft_assets` 资源目录副本。

请使用各文件夹中对应的完整 UV PNG，不要互相混用。`UV_透明线框`、`UV_分区参考`、屏幕模板等是编辑辅助图，不是额外必需贴图。

此合集直接整合三份已交付的最终包，没有重新缩放、修改几何或贴图。`文件校验清单.json` 记录包内文件的 SHA256。没有混入旧版模型、建模脚本或多层压缩包。

模型资源不等于已安装的模组；运行时换肤、按键绑定和游戏内行为仍需由你的模组接入，未在本次执行安装或游戏测试。
