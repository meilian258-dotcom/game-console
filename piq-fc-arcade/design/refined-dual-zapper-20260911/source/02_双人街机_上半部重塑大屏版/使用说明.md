# 双人街机：上半部重塑、大屏版

此版独立另存，不覆盖原来的加深机柜版。编辑主文件为 `街机_双人_上半部重塑大屏版.bbmodel`。

## 本次修改

- 屏幕从 16×12 放大为 **18×13.5** 模型单位，面积增加 **26.56%**，仍是 4:3。
- 灯箱加高并前伸，增加实体下檐、收边和隐藏连接梁；上半部形成灯箱罩、内嵌屏幕的层次。
- 重接屏幕侧板、后脊与灯箱侧颊，去掉原来生硬的转折；边框收窄但保留四边可贴图区域。
- 外尺寸仍为 **24 宽 × 32 高 × 17.6 深**，即 **1.5 格宽 × 2 格高 × 1.1 格深**。
- 下柜及全部操控零件的位置不变；原按键、摇杆组 UUID、枢轴、组成员和控件 UV 保留。

## 单张 PNG 换肤

唯一主皮肤为 `双人街机_重塑版UV.png`，2048×2048；与 `.bbmodel` 内嵌贴图相同。

**请用本版 PNG，不要直接混用旧版整张皮肤。** 侧面斜板、灯箱、边框及上部结构的 UV 已调整，参考 `UV_分区参考.png` 和 `UV_部件索引.csv`。侧面 A/B 分区仍为同侧连续投影；同一分区的结构面可能有意重叠。

屏幕 UV 位置保持不变：左上角 **(1200,280)**，大小 **672×504 像素**。用 4:3 画面替换该区域即可；屏幕变大不会裁切画面。屏幕和可贴图边框分开，边框无需画进游戏画面中。

`UV_透明线框.png` 只作为编辑辅助层，导出正式皮肤前隐藏它。当前贴图是通用纯色占位，没有绑定游戏画面或品牌广告。

## 按键和游戏接入

`按键动画映射.json` / `.csv` 沿用上一版两位玩家的独立按钮、开始键、摇杆及固定胶套分组。`.bbmodel` 包含分组和轴心；`arcade_refined_upper.json` 是 **静态 Java 模型**，不携带可驱动骨骼或运行时按键动画。

模型标识为 `arcade_refined_upper:block/arcade_refined_upper`。`minecraft_assets` 只有模型和纹理片段，不是可直接启用的完整资源包或模组。FC 模组的导入、皮肤绑定、按键动画、碰撞箱和摆放偏移需要单独配置；本次没有改动服务器或这些运行逻辑，也没有声称完成游戏内测试。

预览均来自实际 Blockbench 模型。对比图使用相同镜头、相同视口和统一裁切，没有分别缩放两台街机。
