# 方块电玩 · 功能制作验收清单

更新：2026-10-04。目标以[通用制作规范](机器制作与交互标准.md)为准，配套[模组制作规范 v1](方块电玩模组制作规范-v1.md)、[功能说明模板](功能制作说明模板.md)。新增运行后端另填[能力声明](附属能力声明模板.md)。F 项验完整闭环，V13～V16 分别验本人／他人姿势、按键动画和隐私；家用远端按钮按用户决定非必做，街机要求不变。均不是任何机型的已通过声明。

### 完整闭环门槛

- [ ] F01 每个声明可用的模式从真实玩家入口完成内容准备→设备准备→开局→操作／适用加入与旁观→保存／结束→再次继续，证据对应同版本、内容、介质和保存身份。
- [ ] F02 家用校验→按需选档→独立 2P 确认→加载／恢复→就绪授权顺序正确；不存档跳选档但不跳适用 2P 确认，单人内容／私人模式不伪造双人。
- [ ] F03 每个准备窗口取消／Esc／返回／超时、重复点击、失败和迟到回包均验终态；没有未确认开局或授权，临时锁有限释放。普通运行菜单关闭不关机。
- [ ] F04 开局玩家、存档所有者、计算主持和操作者分别验证；借还／交接／旁观不暗换档主或授予管理权限。
- [ ] F05 正常保存确认、保存中重复关机／拔卡／换内容、撤权／磁盘满、旧结果迟到分别测试；失败保留旧好档，公开存储端确认与私人本地确认不混用。
- [ ] F06 断线／崩溃／卸载另验有限收尾和可恢复检查点；不保证不可取得的最后进度，不假报保存、不永久占锁。
- [ ] F07 街机投币／申请／组柜／空席策略、掌机举放／独立电源、电脑交接／程序保存、外设端口按类型验，不硬套家用流程。
- [ ] F08 公共合同变化回归已有调用者，旧身份／命名空间保持。适用基础项有缺口的版本只标候选和已验证范围，不因可选模式禁用就宣称整机达标。

## 2. 启停与异常收尾

- [ ] L01 首次选择并完成适用开局确认 → 输入音画正常 → 退出操作 → 按策略保持／关机 → 电源重开保留已选游戏并重走适用确认，不重新挑 ROM。
- [ ] L02 快速连续开关、启动中关机、换游戏、断线重连、切服：取消有效，迟到回调不污染新会话。
- [ ] L03 死亡、切维度、设备拆除/区块卸载、主持离线、worker崩溃/卡死均有明确安全收尾。
- [ ] L04 每次退出的进程、线程、音频、纹理、文件锁、临时目录释放；强制终止后下次安全回收，不删他人目录。
- [ ] L05 权限/资源/内容错误可诊断重试；日志不泄漏凭据和内容正文；保存失败保留可恢复好档。
- [ ] L06 多次开关/换服长测记录次数、时长和资源曲线；不可只用一次正常退出证明无泄漏。

## 3. 操作、权限、关机策略

- [ ] I01 所有声明端口分别输入/释放，1P退席不清掉其他席；键盘与真实手柄分别验证。
- [ ] I02 菜单、失焦、同时按键、长按、断线无粘键；无按键过场不等同退出。
- [ ] I03 非占席玩家伪造输入、旁观发控制、过期会话/票据、换服旧请求均被服务器拒绝。
- [ ] I04 非OP管理请求与打开界面后撤权被拒绝；距离、遮挡、保护与真实连接均检查。
- [ ] I05 付费投币一次扣除一次生效，重发不重复扣/加币；退席不丢合法投币边沿，免费模式不绕过收费规则。
- [ ] I06 维护菜单不能借普通控制流越权；若不支持，入口和协议都关闭并有原因。
- [ ] I07 街机策略：最后一席主动右键退出才可立即关机；副柜有人不关，非主动离场不误触“主动退出”。
- [ ] I08 空席计时0禁用、默认60秒、边界值拒绝/钳制符合实现；重新入席取消，其他玩家继续游戏不计时。
- [ ] I09 全服规则改动覆盖新旧机柜，客户端/单机旧字段不能盖过强制规则；同时保存有冲突提示。
- [ ] I10 不适用街机策略的家庭/电脑/掌机声明自己的规则，旧设备回归无意外改变。
- [ ] I11 OP螺丝刀可打开适用设备的设置/诊断，非OP及撤权有服务端保护；工具不误开关机、借柄或拔卡。无多人能力也不因同步开关屏蔽所有诊断，未实现模式不伪报可用。
- [ ] I12 公开双人家用局开局独立确认允许／拒绝；不存档、空槽、已有档分别走全流程，不用存档单双人标签代替。允许后2P直接领空闲柄，拒绝／取消／迟到回复不得意外授权；街机申请和电脑交接另验。
- [ ] I13 同一张卡的人数上限贯穿编辑→写入→插机→NBT重载→开局；旧缺省字段界面与权威一致。人数上限、本局加入许可、存档人数标签分别验证，不用不同卡或不同服务器截图代替整链。

## 4. 画面、声音、模型

- [ ] V01 0/90/180/270度、横竖屏、像素比例≠显示比例、动态尺寸与重复帧：不双重旋转、不镜像、不错误拉伸。
- [ ] V02 图像通道/行序与音频格式/采样率正确；暂停恢复、音频设备失败/重连不阻塞主线程。
- [ ] V03 画面不可见时不做无用纹理上传，仍作为主持时附近其他玩家音画不断；音量按规则衰减。
- [ ] V04 所有机型四朝向、贴墙/邻柜：开关可点、触区与位置一致；真实机身/墙/保护不能穿透。
- [ ] V05 红灯/通断姿态/音效随权威状态变化，不因同步包多播重复响；主副柜一致。
- [ ] V06 摇杆按钮按真实席位动画、释放回中、旁观可见；物品图标/比例与创造分类正常。
- [ ] V07 旧世界放置/连接/介质可读；退役物品保留旧ID；新模型不要求拆机重放才能用。
- [ ] V08 若声明硬件渲染：上下文/线程正确、设备丢失可恢复、导出边界验证；未实现不得标支持。
- [ ] V09 GUI多种缩放、长中文名/文件名、窄窗口、滚动和焦点正常；按钮不出屏，重要说明不被截断。
- [ ] V10 配置取消不写入、保存有成功/失败/冲突反馈；界面状态与服务器一致，菜单路径和帮助有效。
- [ ] V11 物品栏/手持/地面/物品框图标与模型均检查；分类不抢原版位置，无过小、灰片或裁边。
- [ ] V12 有线设备的连接业务与实体线分别验收：正确插头、四向/高低差、视锥和包围盒、近远、卸载/重连；连接成功有可见线，断开后消失，拆机/退线仅返一次。不是只检查服务端连接成功提示。
- [ ] V13 持握姿势与按键动作分别记录本人第一人称、本人 F5 第三人称和他人视角结果。按2026-10-04用户决定，家用远端按钮动画记“非必做／静态”，不要求补齐；他人看到的持握与线材仍需第二客户端检查。街机或已声明远端动画仍需实测，模型/手臂/线材可见不能算按键动画通过。
- [ ] V14 动态按钮跟随实际映射后的游戏输入：方向/功能键、短按/组合键、重绑键盘/实体手柄、主副手和所有有效端口逐项正确。旁人看的是操作者，不是自己的输入；GUI/掉落/物品框/停放模型保持静态。
- [ ] V15 已实现的公开动画按设备/操作者/会话/端口/手持身份隔离、只在声明的有效范围内同步；不要求新增家用远端按钮动画。私人模式本人动画正常但按键及动画状态不外发。检查通信记录，不能仅凭“旁人没看见”认定没有发送，也不能为显示动画启动核心/强加载区块/扩展控制权限。
- [ ] V16 松键、菜单、失焦、换手、归还、超距、关机、断线及撤权后回位；旧会话晚包不复活新租约动画，1P清理不影响2P。短按视觉锁存不得延长真实游戏输入；远离返回/重连/重新领取有真实恢复测试。

## 5. 内容与存档安全

- [ ] S01 缺文件、同名不同内容、损坏内容、错误固件、非法扩展名、大小/数量边界都有清晰结果。
- [ ] S02 路径遍历、绝对路径、重解析点、恶意压缩、超额/截断/伪造分块被拒绝，无根目录逃逸。
- [ ] S03 本地/服务器列表和下载权限一致；授权撤回、连接更换与迟到下载不会启动旧内容。
- [ ] S04 若声明续传：离远、暂停、断网、重连仅续可信分块；最终哈希正确，错误块重试不复用坏缓存。
- [ ] S05 SRAM/RTC/记忆卡/即时状态/NVRAM按声明分别做保存→退出→重启→恢复，不能互相代替测试。
- [ ] S06 两设备、两玩家、同名游戏、改名游戏、换游戏/核心：保存归属正确，没有交叉覆盖或并发写卡。
- [ ] S07 磁盘满、权限拒绝、写一半中断、坏档恢复、旧格式迁移：原好档/备份可恢复，失败不冒充成功。
- [ ] S08 多盘/换盘/固件/核心选项确实进入所需兼容身份；禁止把另一游戏或核心状态强行恢复。
- [ ] S09 卡带工作台具备来源/搜索/刷新/分页、预览再确认写入及真实支持的名称/封面/存档入口；空列表/无匹配/超时/无权限分别提示，取消/失败不损坏原卡，不以简化上传页冒充与FC/SFC完整流程一致。
- [ ] S10 中文／空格原名上传、刷新、重进和服务器重启后仍可读可搜索；区分内容hash、磁盘定位、库名、卡名。同内容多来源和同名不同内容不串项，改卡名不越权改库或改身份。
- [ ] S11 每个保存模式分别走继续／从头／替换→新保存失败；旧好档仅在新数据持久成功后才退役，不能在创建会话或发送请求后就删除。成功进度标记绑定真实卡和确认结果。
- [ ] S12 每个运行方式实际读取/写入的归属与菜单声明一致；恢复备份、托管SRAM、私人档、Netplay档和卡带档分别验，不用一种通过推断其它模式。不同系统保存模式整数不能直接互抄。

## 6. 网络模式与远距性能

- [ ] N01 每种声明模式独立启动/加入/旁观/退出，不能用本地单人通过推断多人或Netplay。
- [ ] N02 普通远处在线玩家没有被加入重型流；用计数/抓包核对，区块基础同步与全服小配置另算。
- [ ] N03 默认距离内、边界、外侧与缓冲退出（当前原生街机16/20格）、再次靠近与副柜范围；无抖动重启或幽灵租约。
- [ ] N04 远处主持与附近操作/旁观并存时，主持本地隐藏画面不切断必要核心计算/发送。
- [ ] N05 观众换操作席/退回旁观、旧清理晚到、同人重连：无双重控制或错误撤销新票据。
- [ ] N06 同步核心/内容/固件/选项不一致明确拒绝；合法相同组合做状态往返、确定性和长期同步测试。
- [ ] N07 丢包、延迟、断线、拥塞、超大/截断载荷：有界队列、超时、背压/降级与恢复，不无限占CPU/内存。
- [ ] N08 不支持的联机/保存/端口不会因伪造请求被开启；对旧协议有明确拒绝或已测试兼容路径。
- [ ] N09 给出单台/多台设备、操作/旁观/无观众场景的CPU、内存、FPS、流量与线程数；预算及测试时长有记录。
- [ ] N10 适用的共享模拟会话优先完成 JNI Netplay；核心、调用方式、同步模式分别登记。不能用私人单人／MEDIA／独立进程通过代替，也不能只改菜单标签或开启能力位。确不适用给出理由，未实现仍记缺口。
- [ ] N11 相同初态／输入的独立实例、延迟输入恢复重演、SRAM／RTC 等影响后续运行的内存、音画呈现分别验证；排除字段须有源码与行为证据，不屏蔽未知差异。固定核心／内容／选项／端口／协议及测试长度。
- [ ] N12 JNI Netplay 从真实入口走公共开局链，准备和取消不提前公开运行／授权／写档；家用不存档、空槽、已有槽都执行适用的独立 2P 许可，两名操作者端口与失焦释放正确。
- [ ] N13 JNI Netplay 晚加入旁观、离远返回和重连通过授权内容、种子及追帧流程；旁观不发输入、不占操作席、不写档。主持与操作席分离，1P归还后按类型保留仍有效的会话。
- [ ] N14 JNI Netplay 各适用保存归属单独验周期／手动／最终持久化及再次恢复；只保存确认进度，失败／取消不覆盖原好档，MEDIA／私人／旧核心档不静默迁移。关闭原生实例与保存成功分别确认。
- [ ] N15 同步不兼容、缺资源、坏种子、弱网、断线、关机晚包均有真实失败与有限收尾；未实现／服务器限制／试验未确认／运行忙碌的菜单原因区分。单元、隔离真实核心、MC双客户端、弱网长测分别给结论，不互相代替。
