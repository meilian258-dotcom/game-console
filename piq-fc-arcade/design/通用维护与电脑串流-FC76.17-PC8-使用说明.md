# 通用维护入口与电脑串流修复候选

适用：2026-09-28；Minecraft 1.21.1、NeoForge 21.1.236 及各 JAR 声明的兼容范围、Java 21；游戏运行端 Windows x64。维护：像素匠。

## 安装

正常退出并备份后，服务器和所有客户端一起替换：

- 主包 `game_console-0.31.0-alpha.76.17.jar`
- 街机附属 `game_console_arcade-0.1.5.2.jar`
- 电脑附属 `game_console_computer-0.1.0-prototype.8.jar`

不要同目录保留同组件旧 JAR。街机 0.1.5.2 明确依赖 FC76.17；机柜协议升级为 cabinet-room-10，避免新旧维护输入方式混用。SFC41/core9、GBA10、PvZ9、Flash 完整运行器 0.1.3 沿用，不必再次更换。两端安装要求来自各项目网络注册、服务端实体/授权及客户端渲染/运行器代码，不是只看依赖 side。未代装、线上发布或重启。

## 街机通用维护：本轮是 Test 入口，不是完整 DIP 编辑器

在 **FBNeo Netplay** 中，OP2 玩家先领取主柜 1P，等待游戏运行，输入：

```
/gameconsole arcade service
/gameconsole arcade service confirm
```

第一条查看说明，第二条确认请求。旧 `/gameconsole arcade pgm confirm` 保留为别名。确认后关闭聊天、松开按键并保持焦点，等待约 4 秒；按游戏自带菜单提示调整，菜单 EXIT 返回。影响整个游戏房间。

不再限制 `kov*.zip` 或要求 `pgm.zip` 才能请求；核心使用 `fbneo-diagnostic-input = "Hold Start + L + R"`。具备诊断输入和维护菜单的 FBNeo 驱动才会响应。没有 Test 菜单的游戏不能凭此获得菜单；旧 MAME 串流/快照方式未适配，明确拒绝，不伪装成功。普通长按 START 不再是默认诊断入口。

服务器复核 OP、当前连接、主柜 1P、房间就绪、租约和内容授权；授权 15 秒内仅该席位能发送保留组合，失焦取消本次按键。免费模式也使用服务器审核后的输入，不靠客户端隐藏按钮。免费投币仍保留；实体投币仍需服务器发放。

**本轮未新增动态 DIP 列表、NVRAM/EEPROM 机柜保存、保存后整局重启流程。不能把本轮当成这些功能已完成。** 原生菜单布局因游戏而异，菜单中修改重开后仍可能恢复默认。也没有宣称可以阻止修改过的主持端自己篡改模拟器。

附属接入点：在公共初始化注册 `PgmServicePolicy.registerDiagnosticBackend(backendId)`；其所有 Netplay profile 必须一致保留上述诊断组合，不得仅在主持端换选项。此接口仅声明诊断输入入口，不声明 DIP、持久化或 MAME 能力。

## Flash 本机文件问题

本机真实日志出现 `Command queue overflow`：运行器输入队列溢出会结束 Flash。电脑 8 合并连续、同按键状态的鼠标移动，保留点击/键盘边沿顺序，限制向 WebView 队列发送速度；运行器 ready 前不灌入游戏键鼠。无需替换 0.1.3 的 DLL/EXE。

运行库目录不存在时明确提示需要在**运行游戏的玩家客户端**安装，服务器目录不能代替。入口仍是电脑装配 → 本机程序设置 → Flash → 浏览 SWF → 使用此程序，再右键键鼠开始。路径和 SWF 不上传服务器，旁观者无需同一 SWF。

上述运行器故障已定位并修复；文件浏览或启动失败仍需按具体阶段诊断，**不能断言所有相关问题都由队列溢出引起**。若仍看不到文件或无法启动，应提供程序设置页面提示及本次 helper 日志。部分 SWF 依赖外部文件/网络或 Ruffle 未支持功能，不在本修复兼容保证内。

## PvZ 旁观卡顿

旧实现先生成最高可接受大小 JPEG，随后限速丢帧。现在根据所选 96/192/384 KiB/s 分配 15 FPS 的单帧预算，预留音频、包头及调度余量，自动调节 JPEG 质量；极复杂图像会降低细节以维持帧间隔。仍保留原流量硬上限，不以加大带宽冒充优化。

旁观端改为批量纹理上传，移除每帧 307200 次逐像素设置。网络格式仍为受限 640×480 JPEG、24 kHz 单声道，权限/32 格旁观/最多 8 人/主持与键鼠交接不变。低带宽档画质会更低，可以在本机程序设置选择 384 KiB/s；不保证所有硬件和网络均达到 15 FPS。

## 验证边界

候选不是稳定版；Minecraft 真人多人、实际领地、光影下 GPU 上传、网络抖动和长时间运行仍需验收。
