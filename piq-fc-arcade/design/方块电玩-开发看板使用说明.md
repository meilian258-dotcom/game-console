# 方块电玩开发看板使用说明

适用：本地开发工作台 **v0.1.0**（2026-09-16 原型），不是新的 FC/附属 MOD 版本。

本机打开 [开发工作台](http://127.0.0.1:18743)。如果没有启动，双击 [启动开发工作台.cmd](</G:/服务器/服务器Codex/game-console-devdesk/启动开发工作台.cmd>)。

完整说明在 [工作台 README](</G:/服务器/服务器Codex/game-console-devdesk/README.md>)；测试范围见 [验证记录](</G:/服务器/服务器Codex/game-console-devdesk/验证记录.md>)。

## 协作方式

1. 用户在“新建需求”中填写标题、组件、说明和可选截图链接，先存为“待确认”。
2. 在对话中明确要求处理哪些需求编号；当前没有自动轮询或自动开发执行器。
3. 开发者开工后按事实记录“开发中”；交付时填写版本与验证结果，进入“待验收”。
4. 用户在详情填测试反馈；通过后人工设为验收通过，再标为“已完成”；不通过则记录问题继续修订。
5. MOD 构建仍按根目录维护规范同步原 MOD 管理台；本工作台不替代游戏发布批准。

## 当前资料

初始数据来自《方块电玩-开发进度与功能说明》的 2026-09-16 快照，基线为 FC44 / 街机0.1.0 / SFC25 / GBA8，含 16 项需求与验收事项、4 项版本记录。另通过页面登记本次开发工作台试用需求 GC-017，保持待验收，未冒充用户已验收。

旧成品与源码未修改、没有新 MOD 构建。新建需求、修改状态和历史实际写入维护电脑的 `game-console-devdesk/data/state.json`；不是只存浏览器。完整原文与历史保留，已有数据不会因改种子而重置。

仅本机使用，不放 `mods`，无 MOD 前置。运行要求为 Python 3.11+，启动脚本优先复用本机 Codex 配套 Python。不是云端协作站点，没有账号隔离，没有自动安装、重启或公开发布功能。
