# 方块电玩问题反馈与验收说明

反馈问题时，请附 Minecraft、NeoForge、主包及相关附属版本，并说明机型、游戏、运行模式和本人角色（主持、加入者或旁观者）。

## 可复现问题

1. 写明预期行为、实际行为和最短复现步骤。
2. 附错误提示、截图及脱敏后的相关日志；原生崩溃可另附 `hs_err_pid*.log`。
3. 不上传 ROM、BIOS、个人存档、密码、令牌或包含私人路径的完整日志。
4. 将不同功能的问题分别记录，避免用一项测试通过代替整套验收。

## 验证状态

编译通过、自动测试通过、真实核心验证、Minecraft 实机验证和稳定发行是不同状态。反馈应写清对应版本、环境、测试人数和时长；无法复现或尚未测试的项目标为待验证。

安装或更新前备份世界、配置和 `game-console` 数据。当前安装与测试入口见[玩家指南](../docs/玩家指南.md)。
