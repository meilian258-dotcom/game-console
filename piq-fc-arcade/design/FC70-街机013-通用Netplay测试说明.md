# FC70 / 街机0.1.3：通用街机 Netplay 测试

适用 Minecraft 1.21.1、NeoForge 21.1.236、Java 21，2026-09-24。执行 Netplay 模拟的客户端要求 Windows x64。此为本地实验候选，不是稳定版或公开上架包。

## 本次变化

- 通用机柜的 **RetroArch Netplay（实验）** 后端接入 FBNeo，不再仅允许拳皇97、合金弹头2两个固定 ROM 哈希。选择兼容当前 FBNeo 的街机 ZIP 即可尝试。
- 重点验证恐龙快打 `dino.zip`、三国战纪 `kov.zip`；后者需要匹配的 `pgm.zip`。核心已在街机 JAR 内置，无需玩家另外安装 RetroArch 或手工复制 DLL。
- 修正公共 IPC 视频前端被误报为“无视频输出”的问题，保留回滚重演阶段的音画抑制。FC 和 SFC 共用此前端，并做回归检查。
- 游戏库可将同目录声明的 `pgm.zip`、`qsound.zip`、`qsound_hle.zip`、`neogeo.zip` 纳入上传清单。最多游戏1份+辅助4份；仅上传自己有权使用和分享的内容。没有扫描其他目录或下载 BIOS 的功能。

“通用”是取消游戏白名单，不代表所有街机、所有 ROM 集、改版和外设已兼容。当前仍是最多两席、免费按键投币；不是三人/四人联机。实验模式不加载或保存游戏进度。

## 安装

1. 正常结束游戏并退出客户端；服务器正常关闭后再更换 JAR。先备份并在世界副本测试。
2. 客户端和服务器 `mods` 都换为本次冻结的 `game_console-0.31.0-alpha.70.jar` 与 `game_console_arcade-0.1.3.jar`。同 ID 旧包移到实例外保留，不叠装，不把外层 ZIP 放进 `mods`。
3. 如使用 SFC，继续使用包内完整 `game_console_sfc-0.1.0-alpha.38.jar`；与上一轮冻结件字节完全相同，不需要另装旧 SFC 核心或 build/libs 薄包。
4. 已有普通运行库及旧 helper 保留。本次 FBNeo 单独内置提取到会话临时目录，不会替换旧 MAME 核心。不要拿网上任意 DLL 覆盖配套组件。
5. 不与 Flash prototype.8 混装；GBA 未迁移。联机双方都需要本次 FC70，因为街机共享文件协议更新为 `cabinet-game-4`。

此交付只产生本地测试包，没有替换用户游戏实例、部署服务器、发布版本或重启服务。

## 开始测试

在**通用街机机柜**中配置游戏；管理员先让设备空闲，在设备设置选择 **RetroArch Netplay（实验）**，设为最多两席及免费按键投币。主持玩家使用1P，获准玩家使用2P；旁观仍沿现有音画路径。所有连接经过 Minecraft 会话和席位权限，原生端口只监听本机，不需要开额外公网端口。

ROM 保留原短名称，不改成中文名、不解压、不拼凑不同核心版本的文件。建议使用与本包 FBNeo 匹配的完整/non-merged 游戏集；克隆若仍依赖父集，本轮不会自动找到或补齐父集。CHD、外部样本和任意配套文件不在本轮范围。

例如（文件由使用者自行准备，发行包不含这些文件）：

```text
游戏目录/
  dino.zip
  kov.zip
  pgm.zip
```

用现有游戏库页面选择并上传游戏；只有声明的同目录 BIOS 会随清单传输，不会把另一个游戏一起上传。先前上传的 `kov.zip` 若清单没有 `pgm.zip`，需由有权限的玩家重新提交配套清单。每份游戏最多64 MiB；Netplay 辅助文件每份最多16 MiB，总计最多128 MiB。

加入后先等核心完成自检，再投币、开始并选人。键位按当前控制设置；本模式使用 FBNeo 的 Classic RetroPad 默认布局，动作编号可能与旧 MAME 不同，可在按键设置调整。未声称所有街机的六键布局均逐款验收。没有金币付费扣除功能，不要以此模式替代服务器付费投币。

## 保留的旧模式

普通音画仍使用原 MAME，不是 FBNeo；两者要求的 ROM 版本可能不同。旧“本地输入同步”仍保留已核验的拳皇97/合金弹头2限制，它与新 **RetroArch Netplay（实验）** 不是同一个选项。三国战纪和恐龙快打请选新实验模式。

旧 FC/SFC 模式、保存空间及原型设备不迁移；新 Netplay 不读写旧存档，也不把主持断线自动切换给另一人。需要续玩存档时仍使用既有支持保存的模式。

## 验证边界

本包的自动构建、实际进程测试和最终字节回执见包内 `verification.json`，原始证据在 `outputs/netplay70/`。自动多进程测试经真实 RetroArch Netplay、模组授权转发及生产载荷编码，不等于已通过两台 Minecraft 客户端、真实网络抖动、声卡、航空学或长期压力验收。

FBNeo 的不透明快照 CRC 在本次三进程检查中有差异，因此没有声称快照逐字节确定性通过；保留原始失败证据，没有删除校验或裁剪快照使其“通过”。另行比较动态游戏画面序列、非零 PCM、实际投币/选人截图及重进状态。仍需重点观察长时联机是否分歧、声音是否稳定。

建议两台客户端验收：两款游戏各投币和选人 → P1/P2分别移动、攻击 → 旁观 → 2P退出重进 → 主持退出；至少连续玩15分钟。若异常，提供所选模式、双方模组版本、ROM/BIOS版本、运行环境诊断与日志。流量监控一直为0的问题按此前要求暂缓，不能拿该数字判断本轮是否联网。
