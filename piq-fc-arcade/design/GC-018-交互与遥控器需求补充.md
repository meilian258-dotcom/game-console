# FC45 交互修复与遥控器设计

2026-09-16，历史设计说明。FC45 / SFC26 的最终行为与验证结果见[测试版说明](GC-018-测试版说明.md)；以下设计状态不作为最终实现清单。

## 用户已明确的范围

- 保留原需求中的 FC P2 丢弃手柄变掉落物、原位置无法归还、SFC 丢弃后消失、FC 手持卡带自定义封面不显示等问题，后续对照 FC/SFC 完整取还操作。
- “正在使用”文字不跟随玩家视角旋转。
- 存档设置继续放在卡带相关流程，不移入遥控器。此项替代最初需求“遥控器替换机器存档设置”的表述；不据此迁移或更改现有存档命名空间/槽位。
- 遥控器设置菜单集中扫描线、文字是否显示、加入是否需要同意等选项。
- 希望电视有开机动画，避免瞬间切出画面；增加开关机按键音效和插卡音效。

## 当前源码核对

- `TvRemoteService` 目前只切换目标电视扫描线，没有设置菜单，已有射线/距离/领地/实际目标身份检查，扩展时保留。
- `HomeTvBlockEntity` 有电源、音量、信号和扫描线状态，可复用音量能力；不要拿全局设置充当单台电视设置。
- `HomeApplianceService` 提交电源按钮操作，`HomeHardware.insertCartridge` 提交 FC 插卡。当前没有上述交互的专用一次性音效。
- 游戏画面存在 FC 和外部家用机（SFC）两条渲染路径；开机过渡需共同门控/覆盖，不能只改电视外壳后被游戏画面盖住。

## 建议方案（额外选项仍待确认）

遥控器右键打开当前指向设备的设置；显示当前目标，避免误改旁边机器。按类别分区：

| 分区 | 选项 | 作用范围 |
| --- | --- | --- |
| 显示 | 扫描线、正在使用文字、开关机动画 | 单台电视/所连接设备；个人关闭动画可作为无障碍选项 |
| 声音 | 音量、静音；交互提示音开关/音量 | 区分电视节目音量与玩家个人提示音偏好 |
| 联机 | 加入是否需要当前控制者同意 | 关联主机；保持现有服务端授权检查 |
| 控制 | 跳转键盘方案、实体手柄设置 | 当前玩家个人设置，不改其他玩家 |

暂不把存档删除/保留天数、ROM 上传、同步模式、服务器托管和全局距离混入普通遥控器菜单。只允许有相应交互/管理权限的人修改影响他人的设置，持有遥控器本身不授予管理员权限。

## 视听建议与验收边界

- CRT 开机建议约 0.6–0.8 秒：柔和窄亮线展开、画面渐亮；不使用强白闪或持续闪烁。关机短暂收束后熄灭；LCD 使用淡入淡出，不照搬 CRT 亮线。
- 电源键轻微机械“咔嗒”，插卡短促卡槽扣合声；退卡和归还手柄可选同类轻音效，不添加厂商标志性开机音乐。
- 音效在操作真正成功后由服务端广播一次，有距离衰减；拒绝、插卡失败、重复按住、收到同一状态更新不重复播放。
- 已开机设备在玩家进服、走近或区块重新加载时不重播开机动画/音效。快速反复切电源时以最新状态收尾。
- 动画仅影响显示，不重启模拟器、不改存档、不暂停其他玩家输入或延迟联机状态；FC/SFC和不同电视共用规则。
- 尚需确认原需求电视状态句的含义。建议电视关闭=黑屏；电视打开且主机关机/未连接=彩条；主机开机但无卡=未插卡，实际有游戏信号=游戏。此项是建议，不标记用户已同意。
