# 家用 FC alpha.12：老式卡带电脑工作台

日期：2026-09-10；修改者：像素匠。新增电脑与卡带写入入口，保留既有电视、FC/小霸王、街机、手柄及已写好的卡带。版本 0.31.0-alpha.12，双方网络协议 29，无新前置 MOD，不包含商业 ROM。

## 外观与放置

独立注册 `piq_fc_arcade:cartridge_computer`，从「PIQ FC」或功能方块创造页获取，也可用 `/give @s piq_fc_arcade:cartridge_computer`。方块朝向玩家，可放桌面；整个模型在一格内。

米黄色厚 CRT 显示器放在横卧机箱上，前方键盘与正视右侧鼠标分开建模，机箱有凹入的写卡槽。屏腔为内凹 4:3 黑玻璃，绿色 PIQ/CARD/>_ 字符只是静态待机装饰，不是运行中的游戏或真实写入进度。实际卡带留在玩家手中，不存入方块，避免拆机/卸载时产生第二份卡带。

- 319 元素、954 个有效面，范围 `[0.65,0,0.6]..[15,13.5,14.6]`（16 单位 = 1 格）。四向选择/碰撞包络由 `CartridgeComputerLayout.parts` 共用。
- 机壳复用原有纯色资源；终端使用原版 `minecraft:block/lime_concrete` 固定小 UV。没有新增、覆盖 PNG，只有 block model/item model/blockstate 三个新外观资源。
- 旧 alpha.11 的 64 项外观应逐字节不变，新清单为 67 项；43 项额外历史外观仍保护。首版与接缝校正-v2 预览保留，最终 body SHA `04AA576783EAA9FAFBEF1AB80F1A6F1B1B2ADEEBA3BC612595E70CAA9DE29CC0`。
- 生成器 `tools/build_cartridge_computer_model.py`，模型 QA `tools/check_cartridge_computer_model.py`。离线预览直接读取交付模型与实际纹理，不是 Minecraft 截图。

## 写入流程

手持一张完整黄卡，右键老式电脑打开写卡工具；Shift + 右键电脑也支持。电脑不是 AV 设备，不接电视，也不是游戏模拟器。

1. 游戏库：选择服务器已有 ROM 直接写卡，或选择本地合法 ROM 上传并写卡。
2. 本地封面：选择 PNG 上传并替换当前卡带封面；保留默认封面、恢复打开时封面的按钮。
3. 保存名称、打开本地 ROM/封面目录、分页/刷新均复用既有编辑器，文件 IO 在后台，不在 render/init/tick 读文件。
4. 原空中 Shift + 右键不再打开编辑器，只在快捷栏上方提示去电脑。普通右键 FC 仍是插入已写好的卡，拆壳/合壳不改；裸 PCB 请先合回完整卡再编写。

写入仍需要 OP2 权限，电脑不会放开普通玩家向服务器上传 ROM 的权限。普通玩家使用写好卡带的权限不变。新增语言键同时提供中文和英文；编辑器沿用既有中文界面。

## 人数设置

顶部增加「人数：单人／双人」，只作用于当前卡带已写入且服务器存在的 ROM。空卡时禁用，上传或扫描时禁用。`SET_PLAYERS=8` 复用既有请求字段：hash 为当前 ROM SHA，total 为 1 或 2，其余载荷为空；服务端拒绝异 ROM、非法人数及上传中的更改。

人数是服务器 ROM 库的共享属性，因此同一 ROM 的所有卡带与街机共用，不是假装只改此卡。正在运行的游戏创建时已取得人数上限，需先结束再启动；游戏本身也必须支持双人。设置写盘失败恢复旧内存值，同 ROM 重传不会把已设双人重置为单人。

成功设置与写卡均使用 STATUS + 最新目录回应，由原 STATUS 收尾分支刷新目录并解锁。REFRESH 的 OPEN 回应只刷新内容，不能清 busy/upload；保留旧延迟刷新防护测试，避免 OPEN 回复打断传输状态。

## 服务端授权与取消

电脑 BE 保存随机持久 UUID；会话除卡带 nonce/UUID/手位/槽位外，还绑定电脑维度、坐标、UUID 和具体 BE 对象。相同坐标新放一台、复制相同 UUID、跨维度均不能继承旧会话。

- 主线程只检查已加载区块，不强制加载；玩家需存活、非旁观、连接仍有效、OP2、有权交互且离电脑中心不超过 5 格。
- 标准 mayInteract 与 NeoForge RightClickBlock 的取消/useBlock/useItem 结果均复验，带重入保护，回调后再次检查电脑与手中卡。不是宣称支持任何非标准领地 API。
- 卡带必须单张、完整、可安全处理元数据，与打开时相同 ItemStack 身份及全组件快照；检测当前背包/光标中重复卡 UUID。成功的自身写入更新快照，外部更换/修改使会话取消。
- 每次请求、服务端 tick、异步 IO 回到主线程及真正改卡前复验。拆机、卸载、移远、换槽/换卡、失权、断线都会取消；旧回调不能改新卡或重新打开已关闭 UI。
- 有效 ROM/封面先进入公共内容寻址缓存。若随后取消，卡带不写入，但已验证的公共缓存可以保留；不删除可能正被其他玩家使用的共享数据。
- 现有分块长度/SHA/ROM 兼容性/路径/传输额度校验继续使用。方块不存 ItemStack，掉落一台电脑，不随身携带编辑会话。

## 验证与边界

定向测试包括电脑身份/距离/权限、原卡手位、人数写盘事务、四向模型包络/无共面重复/屏腔无遮挡、四列菜单小窗口布局与延迟 OPEN 防护。最终完整测试、打包清单与散列见分类目录同版校验清单。

新注册与协议要求客户端、服务器一起更新。仅本地交付，不自动替换用户 HMCL 实例，不上传或发布服务器版本。未做 Minecraft 实机、双人联机和第三方领地插件验收；离线几何、真实 API 编译和包内探针不代替这些测试。含新电脑的世界不要直接降级到不认识该注册的旧版。
