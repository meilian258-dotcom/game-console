# FC 统一操作测试版

版本：FC 0.31.0-alpha.24、SFC 0.1.0-alpha.13、原生街机 0.1.0-alpha.8。

这版统一日常操作和加入审批，不改现有模型、SFC/卡带比例、游戏核心与原有音画协议。

## 统一后的操作

| 操作 | FC / SFC 家用机 | 通用街机（FC / SFC / 原生后端） |
| --- | --- | --- |
| 开始 | 卡带已写入、电视已连好后，空手右键主机或电视拿手柄；插入卡带且条件满足也会启动 | 普通右键进入；SFC/原生后端直接启动此前设置的游戏，没有设置时提示，不强行打开选游戏菜单 |
| 结束 | 持自己的手柄右键绑定主机或电视归还；P1 结束整局，P2 只退出自己 | 再次普通右键自己使用的机柜退出；通用非 NES 房间 P1 退出会结束本局 |
| 右键空气 | 只提示如何归还，不结束 | 不结束 |
| 切快捷栏 / 收进背包 | 暂停本人输入、保留本局；拿回原手柄继续。空手点原设备也可取回库存中的原手柄 | 保持席位；不占用 WASD 与鼠标视角 |
| Esc / 打开菜单 / 切出窗口 | 清本人按键，不作为归还操作；恢复后先松开游戏键再操作 | 清本人按键，不作为退出操作；恢复后先松开游戏键再操作 |
| Shift + 右键 | 空手点主机取出卡带；持卡 Shift 右键不插卡 | 打开机柜配置，含原有外观入口（用户双人柜仍使用配套贴图） |
| 写卡 | 持对应卡带右键卡带电脑；原有文件夹、游戏列表和确认写入保持 | SFC/原生后端通过机柜配置选择本机 ROM；核心所需 BIOS 仍按原规则准备 |

NES 街机保留原 FC 服务器 ROM 库、存档/续玩与保存退出确认流程，不用附属的直启直退规则覆盖它。

SFC 手柄支持主手和副手。把原手柄暂存在自己的物品栏、个人合成格或鼠标光标不代表归还；光标/合成格中的手柄需要手动放回。放入外部容器、离开有效范围、失去权限或断开连接仍会安全释放，不把手柄物品当成永久控制权。

## 多人和旁观

1. P1 先启动，选择“允许申请”。选择“保持私有”或关闭提示，本局保持私有。
2. 其他玩家右键同一台家用设备/街机申请，P1 选择“接受申请”后才加入当前进度。新通用街机中申请人再次右键同机可撤回。
3. 使用通讯线连接的两台双人街机仍是主机 P1/P2、副机 P3/P4；加入哪台就申请那台的空席。ROM 和后端必须支持相应人数。
4. 同一房间一次处理一份申请。过期、撤回、断线或权限改变的申请不能再批准；加入不会重开正在运行的核心。
5. 不参与的附近玩家继续自动旁观，无需右键，不占操作席位。原有范围、人数与带宽限制保持。

通用街机的邀请新增独立协议，联机双方和服务器请使用同一组版本。原 FC 邀请与存档行为保持。旧的独立 Native 街机仍只支持本机世界；联网请使用 FC 提供的通用机柜，再选原生街机后端。

## 安装时注意

* 先退出 Minecraft，备份旧 MOD；服务端更新也应正常停服并备份。
* 本组件在 `mods/` 中只保留本次对应的新版 JAR，勿混用旧 FC/Native 版本；其他无关模组不动。SFC 可以作为可选附属，不想玩原生街机也可不装 Native。
* `piq_sfc-0.1.0-alpha.13.jar` 已包含家用层与 SFC 核心；旧 `piq_sfc_arcade-0.2.0-alpha.6.jar`、旧 `piq_sfc_home-*.jar` 和旧合并 `piq_sfc-*.jar` 请移到 `mods` 以外备份，不能重复安装。
* `piq-native-arcade/runtime/piq-native-helper.jar` 放在实例根目录下的对应路径，不是 `mods`。本次 helper 与上一版完全相同，无需重复替换相同文件。服务端不需要运行模拟器；使用原生核心的主持客户端保留原有 DLL/JNA 运行文件。
* 不含 ROM、BIOS。不要删除原来的游戏文件夹、配置或存档。

## 本轮没有扩大宣称的能力

这不是把所有模拟器强行改成同一个核心。各平台按键数量、固定/可改键方式仍有区别；没有给 SFC/原生街机新增 FC 同等级的服务端存档、续玩或排行榜。SFC 仍不支持 FC 的 P2 实体手柄投掷转交。原生核心没有全局暂停协议，打开菜单只清本人的输入，不承诺冻结核心或替其他玩家暂停。

为防止邀请消息无限堆积，通用街机单局最多处理 256 次不同审批提示；达到上限后需结束重开本局。

旧独立 Native 机柜的尺寸已固定为它原本使用的尺寸，避免升级共享主包后随新双人模型的尺寸变化而变形；没有修改模型贴图。

测试证据在包内 `checks/`：完整单元测试、最终 JAR 邀请/输入/真实消息编解码、SFC 实际核心双进程音画回归。它们不等于真人 Minecraft 联机、真实 GUI/保护插件或 Xbox/PS/NS 实体手柄验收。

建议先在备份世界验收：SFC 拿柄→切快捷栏→拿回继续→点电视归还；P2 申请被拒/被批准/退出再申请；街机撤回申请、两柜 P1–P4 席位、周围旁观画面；打开菜单及切出窗口后无卡键。
