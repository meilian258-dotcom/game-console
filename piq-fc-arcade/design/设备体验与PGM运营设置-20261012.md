# 设备体验与 PGM 运营设置

适用候选：FC76.54、SFC54、街机0.1.5.12及同批电脑附属。维护：方块电玩；2026-10-12。目标环境为 Minecraft 1.21.1、NeoForge 21.1.236、Java 21。本文记录开发候选，不是稳定版或已发布版本声明。

## 公共入口与保存边界

PGM 运营设置不同于一局游戏进度，也不同于界面中的最大席位标签。沿用固定 JNI FBNeo 的原生 NVRAM 文件，不能拿整局即时档冒充运营设置；改动只在模组的文件暂存、持久化和授权层。管理员修改后须从游戏后台选择 `EXIT` 返回游戏，再正常关机；失败保留上一份有效数据。真实三国战纪验证已观察到：停在设置菜单直接关闭不保存，正常 `EXIT` 后写出文件，在全新独立进程重开仍为四人。MAME／RetroArch 尚未接入此持久化，恢复旧游戏即时档也可能把其中的旧设置带回。按制作规范，同柜当前游戏在重启、换操作者时保留；成功切换另一款游戏后使用新代次，旧文件保留历史但不再当成当前配置。客户端无权提交任意路径或替其他机柜保存。

SFC 沿用自身的个人／卡带 Netplay 保存身份，通过公共存档库展示真实条目，不伪造 FC 的三槽、改名或删除能力。公共页面的按钮位置一致不意味着各保存器能力相同。只有当前持卡及原工作台授权有效时返回目录；关页、换卡、断线或旧回包不能继续修改卡带。

联机方式仍分清实际运行器与同步方式。新街机默认现有 JNI Netplay，不将实验 RetroArch 作为替换；服务器禁用或后端不支持时按明确能力处理，不静默改写旧设备。

## 提示、外观和性能

运行环境页由玩家从模组设置或设备设置手动进入。已有安装检查继续执行，失败在进入游戏后提示，诊断详情仍可复制。启动报告按组件分别保留，某组件成功不能覆盖其他组件失败；无法确定来源的旧失败保守保留至本次进程结束。聊天框仅展示可读摘要与手动路径，不展示原始磁盘路径、堆栈或核心日志；同类错误十秒内合并，全部错误最多每秒一条。详细诊断的有界历史保留。

模型改动只涉及展示：移除 SFC 独立品牌面及无线接收器手持变换，不改可交互范围、世界占地、插口与其他贴图。实际不同窗口缩放、左右手及光影视觉尚需游戏内确认。

## 交付与验证记录

服务端与客户端需使用同批主包、SFC 和街机组件，因为这些组件共同处理实体、内容授权和网络；机柜协议为 `cabinet-room-12`，SFC 协议为 `15`。电脑资源更新也随本批配套；不依据依赖声明的 side 猜测安装端。

最终组件自动回归：FC 3023 项（11 跳过）、SFC 611 项（2 跳过）、街机 172 项、电脑 87 项、沿用 MD16 回归 109 项，合计 4002 项、0 失败／错误。条件跳过未视为成功覆盖。仓库工具另有 203 项、0 失败、3 跳过。主包打包后原生 smoke 和公共 Replay API v1 门禁通过。首次命令／缺构建依赖／旧协议断言失败均保留证据，未放宽固定来源或核心身份门槛。

真实核心探针已确认三国战纪四人设置正常 EXIT 后，在新 JVM 重开仍为四人；不是 Minecraft 多人验收。可选 Replay test.7 使用公共 v1 主包接口，并核对本批 SFC54／街机12／电脑13 的有界适配；旧补丁与历史安装组合保留。

最终七包／八个 Mod ID 在隔离 NeoForge 21.1.236 专服正常启动、正常 stop、退出码 0；原测试实例、既有世界与全部历史输入完整恢复。Replay test.7 在有／无 Iris 两组各 26 个 Java 入口通过，真实变换各覆盖音频 1200 项、生命周期 38 项、打开保护 102 项，Iris 包装／收尾通过；两组生成同一补丁 JAR。四个新旧成品共 90 项原生库／WASM 资源逐项 SHA-256 相同，新增、丢失、变化均为 0（包含嵌套 JAR 的原生库，并非 90 个模拟核心）。

开发临时目录使用独立工作目录，不清理系统临时目录或玩家文件。本批为新的本地成品，不将上一批 JAR 当成本批成果；MD16／GBA15／PvZ12 保留原件。完整哈希和安装组合随冻结交付回执记录。Minecraft 窗口缩放、光影、多人、长局和实际录像视听仍待验，不能把自动测试标为稳定版。
