# 街机红灯翘板开关与游戏资料 · FC76.7 测试候选

适用：2026-09-27，Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21。测试候选，不标稳定；真实 Minecraft 点击、界面和多人同步仍待用户验收。

## 安装

服务器与所有客户端统一换主包 `game_console-0.31.0-alpha.76.7.jar`，退出游戏/服务器并备份后替换，旧主包移出 mods 留存，不能同 ID 并装。主包共同注册方块/BE、服务端权限/资料存储和载荷，客户端显示/输入依赖这些载荷，故双方安装。目录协议更新 `cabinet-game-5`，沿用76.6的其他协议；不可与旧主包混连。

街机0.1.5.1、完整SFC41/core9、GBA10、PvZ9、电脑5-r2及Flash0.1.3沿用，不是本轮重新构建。本轮不会代安装、发布、部署或重启。不改核心、ROM、BIOS、正式游戏存档，不再重复打包78MB原生前端源码；76.6对应原生源码仍在原交付目录。

## 红灯翘板开关

- 位置：左右侧板**上方靠后**，顶边下约0.1～0.3格，按用户圈选位置移动；原下半部红块已移除，无隐藏旧开关。
- 黑色边框、红色立体翘板、白色 I/O 标记。关机暗红，开机亮红且 I 端下压。红灯自身可见，不是照亮周围方块的动态光源。
- 空手、不蹲下，对准开关右键开机；已有会话时，主持或OP2可关整组。主柜与副柜显示同一组的电源状态，旁观者也通过方块更新接收。
- 灯表示会话已通电/启动中，不保证某客户端核心已成功出图；取消配置、启动失败收尾、关机后熄灭。1P右键退出操作不关机、不熄灯，再右键恢复。旧机器不需要重放。
- 主持仍受原约8格、在线/同维度及机柜加载等限制；离远仍可能结束整局。本包**没有**取消距离限制或增加无人值守托管。

## 每款游戏的资料

游戏选择界面分为“服务器游戏”和“本地游戏”。普通玩家可以查看服务器标注；OP2管理员在服务器列表选中一款游戏，点“游戏资料”：

1. 显示名称：最多64字符，留空恢复ROM文件名。不改ZIP文件名、文件内容和下载哈希。
2. 支持人数：未标注、1人、2人、3人、4人，点击切换。
3. 屏幕标注：未标注、横屏、竖屏。
4. 显示比例：跟随核心、4:3、3:4、16:9、1:1、铺满屏幕，点击切换。
5. 保存到服务器。Esc或“返回列表”放弃未保存编辑，回到选游戏界面。

入口仍沿用现有配置流程：机器空闲时，Shift空手右键机柜，进入原生街机游戏选择。资料编辑需要有效配置席位、内容浏览/服务器ROM使用权限及OP2；运行中请先正常停机再进入游戏选择。保存资料不会自动选中/启动游戏。

人数和横竖屏是人工说明，**不自动修改DIP、PGM或核心旋转**。把三国战纪标成4人后，仍需在游戏内部设置 `4 PLAYERS`。比例是旋转后的最终显示比例，对主副柜、控制玩家、旁观路径共用；不裁剪源画面，强制比例可能拉伸。默认“跟随核心”保留原76.6效果。

服务器资料按“后端ID+主ROM SHA256”存于该世界 `data/piq_cabinet_game_profiles_v1.dat`，随世界备份；不是每个客户端各自改名。不同ROM哈希分别标注，同一ROM重新选用/改文件名/换机柜仍可复用资料。多人管理员同时编辑时拒绝旧修订覆盖，提示刷新。

本地游戏页只浏览本人ROM目录，不等于绕开服务器上传权限或开启离线模式。“上传并使用”仍需原权限并共享到服务器；尚未入库的本地文件不猜测人数/横竖屏，先上传入库后由管理员标注。本包不改下载机制，不实现大文件断点续传或离开范围后台下载。
