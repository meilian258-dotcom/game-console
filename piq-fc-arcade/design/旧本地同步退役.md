# 旧本地同步退役

本轮退役的是设备菜单中独立可选的旧“本地同步／本地输入同步”，不是 JNI Netplay，也不是删除游戏机。配套为 FC76.57 与完整 SFC55（内含原 core11），已完成本地自动验证；未发布，不能据源码版本视为公开下载已更新。

## 保留与移除的范围

| 入口或数据 | 处理 |
| --- | --- |
| 街机、FC 家用机、SFC 的独立旧本地同步选项 | 不再提供新选择；服务端拒绝旧客户端发来的选择请求 |
| 已保存的旧同步配置 | 原值保留；开局明确提示已退役，请管理员关机后选择当前支持的模式，不自动换核心 |
| 普通单人／双人机柜内的 `FC / NES` 后端 | 保留；它仍使用独立旧会话链，目前没有等价替代，不能随菜单退役一并停机 |
| JNI Netplay、RetroArch Netplay | 保留原能力和权限；未通过的试验仍不因此变为稳定 |
| `LOCAL_SYNC` 内部枚举及线格式 | 保留；Netplay 也使用该标记，并以独立标志区分运行路线 |
| 旧世界、核心文件、存档和历史交付 | 保留；不删除、转换或自动导入到另一核心 |
| 私人单人附属 | 不因继承旧内部默认标记而停用 |

“机柜里的 FC / NES”指的是选来运行红白机游戏的后端，不是玩拳皇、街霸的 FBNeo 街机，也不是新增的一种“老式街机”物品。

## 实施合同

R01：从共同菜单和管理入口退役可选旧模式，服务端检查与客户端显示一致。旧客户端的按钮不产生越权或静默成功；旧配置须有明确的重选提示。

R02：在真实开局路径检查，而不只隐藏按钮。家用 FC、SFC 和通用机柜分别核对；已有会话仍能正常结束，旧数据读写枚举不重排。

R03：保留 Netplay 的模式标识、默认选择、租约、2P 和旁观合同。全局 `allowLocalSync` 目前同时约束 Netplay，因此不因退役旧菜单而删除该策略或放开 Netplay 权限。

新放置设备的自动策略在 JNI 不可用时才选真实可用的音画路线；不再默认回落旧同步。旧全局显式 `preferred=1` 和已保存的旧 NBT 保留停用值，须由管理员重选，不能把“自动新机默认”逻辑用来迁移旧设备。

R04：同批接入街机 Netplay 输入限流热修，验证最终主包、完整 SFC 及原附属的注册和专服正常启停。不修改模拟器核心，不把启动检查当作多人实机验收。

完整 SFC 由家用55与已核 core11 合包，旧核心68个非元数据条目保留；主包11个与 SFC3个原生资源逐件与原 FC54／SFC54 相同。未修改或重编模拟器核心。最终七件组合在 NeoForge21.1.236 隔离专服精确加载8个组件，完成正常启动、`stop`、退出码0，原测试环境、世界、旧成品与EULA保全。
