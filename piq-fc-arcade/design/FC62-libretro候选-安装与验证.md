# 方块电玩 FC62：libretro 迁移候选

适用目标：Minecraft 1.21.1、NeoForge 21.1.236、Java 21，FC 主模组 `0.31.0-alpha.62`。2026-09-21 编写。

**这是已完成本地自动验证的测试候选，不是已完成 Minecraft 实机验收的正式版。** 使用交付目录中的 `game_console-0.31.0-alpha.62.jar`，不要安装 `build/libs` 中间包。

交付 JAR SHA-256：`BE0982EFAAF5C23F76D1395453D54417D8B6811BBE36E5F5F4F4D981CAB36A61`，35,800,957 字节。

## 本轮变化

FC 使用 Mesen libretro 核心的接入方案，保留电视、主机、卡带、权限和原有联机会话接口。原生核心在单独的 Java 子进程运行，隔离不同模拟器实例；这不是操作系统安全沙箱。运行时不应要求自行安装 RetroArch，不从网上自动寻找或加载任意核心。

这次不是全平台切换。SFC、GBA、原生街机和 Flash 没有改成新的 FC 核心；旧 WASM 和附属依赖的公共运行库保留。不会因为使用 libretro 就自动增加所有机型、所有游戏兼容性或 RetroArch 联机功能。

## 安装与旧数据

1. 关闭客户端及测试服务器，完整备份测试世界和模组数据目录；首次验证请使用副本，不直接更新正式服。
2. 客户端和服务端使用同一 FC62 交付 JAR。将旧 FC JAR 移到 `mods` 之外的备份目录，不同时放两份主模组。
3. **不要与 Flash prototype.8 混装**：其声明仅接受 FC56～61，不接受 FC62。本轮不修改这个附属，请在独立测试配置中不加载 Flash8，原安装和运行库保留。
4. SFC36、原生街机 0.1.1、GBA8 的 FC 依赖声明允许此版本范围；这只说明加载器范围，不代表已完成新核心下的附属实机验收。仅做 FC 测试时可以不加载这些附属。
5. 不含商业游戏 ROM 或原厂 BIOS。游戏文件由使用者自行合法准备；本次仍按 FC 的 `.nes` 流程，不把 Mesen 上游支持的 FDS 等格式等同于本模组已支持。

新核心的即时存档与旧 WASM 即时存档不是同一格式。新旧档案必须分开识别；不要手工更名替换，不要把“检测到旧档”当作新核心能够续玩。旧文件保留，不自动删除或转换；回退时连同备份配置和旧版本一起恢复。每张卡的“不存档／个人存档／卡带存档”使用规则不因核心迁移而改成全服统一 ROM 设置。

新即时快照校验核心配置及 ROM 身份，并保存核心状态、当前画面/RAM 缓存、两只手柄和光枪输入状态。恢复后不会重播旧音频缓存。这里的缓存用于准确恢复和立刻显示，不是把旧 WASM 存档转换成 Mesen 存档，也不代表可以任意混用不同核心版本。

## 必须核对的体验

- 开机有画面和声音，两个手柄的 A/B、方向、开始、选择没有错位，N/F7 提示使用实际按键绑定。
- 个人档和卡带档分别完成“游玩—关机保存—再次开机继续”，再测试换主机和转交卡带；旧档不会被覆盖成新格式。
- 两台主机同时运行不同游戏，互不串画面、输入、音频或存档；关闭其中一台不影响另一台。
- 光枪屏幕内命中、屏幕外开枪和存读档后继续正常。
- 本地输入同步、玩家串流、服务端托管分别验证；本地同步还应验证中途旁观和断线清理。
- 正常退出、取消开机、切世界及核心异常之后，相关子进程退出，无残留持续占用。
- 现有 FC62 之外的航空学、光影、桌面音频设备等兼容性不因自动测试通过而视为已实机确认。

## 平台与验证状态

Windows x64 已真实运行验证；Linux x64 二进制已内置并校验，但本机没有可用 Linux/WSL 环境，因此 Linux 执行、Windows/Linux 混合同步仍未验证。Minecraft 游戏内单人、多人和光影/航空学也未在本轮实际启动验收。macOS、ARM 和其他系统本次不作承诺。

最终 `check jar --offline --rerun-tasks` 共 2222 项、0 失败、0 错误、8 项既有 Windows 权限环境跳过。构建前后源码/资源指纹一致。独立探针 1709 检查通过：原创诊断 ROM 的非黑画面、有效音频、双手柄、光枪、双进程状态一致、保存恢复及暂停重入。最终冻结 JAR 单独启动两个核心，恢复后连续 30 帧画面一致；不依赖开发目录里的运行库。

每个活动核心使用独立子进程，会增加进程和内存开销；目前未给出真实大型服务器承载量结论。核心固定 NTSC，保持现有会话的 60 帧调度；不是 PAL 原速支持，也不是已完成所有游戏兼容验证。

测试使用项目原创诊断 ROM。原资源和附属依赖的 WASM/公共运行库保留，成品旧运行库加载探针通过；这不等同于 SFC/GBA/街机组合实机验收。上面的“必须核对的体验”仍是游戏内验收清单。
