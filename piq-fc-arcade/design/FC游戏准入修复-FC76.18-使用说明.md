# 方块电玩 FC76.18：游戏扫描与 Mapper 准入修复

2026-09-28，像素匠。适用 MC1.21.1、NeoForge21.1、Java21。本地测试候选，不是稳定发行；Minecraft 单机/专服界面及真人多人待验。

## 改了什么

FC 正常运行已走内置 Mesen/libretro，但卡带本地扫描、服务器索引、上传和核心选择仍套用旧 WASM 的 Mapper 白名单，导致有效 ROM 被隐藏或拒绝。本版统一按现代核心的实现表判断，不再只允许 0/1/2/3/4/140 和受限的19。

本次反馈对应：Lethal Weapon (As) 为 Mapper25/NES2/submapper1，Gimmick 为69，Gumshoe 为66，Lagrange Point 为85。文件原件不需要改头。规则针对板型而非这几个游戏名，也不以重命名作为修复。

格式有效但当前实现表未包含的 ROM 会留在目录中，选中后显示 Mapper 编号及原因，写入/使用按钮禁用；服务端卡带提交与游戏选择也复核，上传去重命中旧索引不能绕过检查。坏头/截断/超容量文件仍拒绝，不开放任意格式。

Mapper 实现表来自已归档 libretro/Mesen `Core/MapperFactory.cpp`、提交 `0102910c39ad1a62bc3f784466f3f67ca9eae335`，排除空实现与非 iNES 入口。它是准入提示，不是每个 ROM/子型号/外围设备均可玩的保证，最终由实际核心加载判定。现有 buildbot 二进制与此源码的逐构建对应尚无可重复构建证明，详见既有 FC62 来源审计；本版不更新原生库或许可声明。

旧 WASM 专属校验、三个模块、原核心/网络身份及保存格式保留；没有删除旧后端、迁移存档、改为 JNI，也没有新增联机模式。

## 安装和使用

1. 备份世界和 `game-console`，正常退出客户端/服务器后，两端用 `game_console-0.31.0-alpha.76.18.jar` 替换旧的方块电玩主包。同一组件不要同时留两个 JAR。
2. 这次只交付主包；街机1.5.2、SFC41完整包/core9、GBA10、电脑9/PvZ10可以沿用，未要求启用 PvZ JNI。既有已验组合和各附属说明仍需遵守；不把依赖范围通过当成功能联机验收。
3. 打开 FC 卡带编辑器 → ROM目录，把自己合法持有的 `.nes` 放在实际游戏实例的 `game-console/piq-fc/roms`，返回刷新。下载文件夹不是默认扫描位置；本次没有代拷文件。Gimmick 的相同内容副本按哈希合并，文件名不同不产生第二款游戏。
4. 选中游戏，再确认写入。多人服本地文件的上传仍需要原有授权；服务器游戏文件须位于服务器自己的 ROM 目录，两端都更新才不会再被旧服务端白名单拒绝。
5. Gumshoe 需要现有光枪设备/模式进行正常玩法；扫描成功不代表普通手柄可以代替光枪。普通/光枪进度保持原有分离。

单文件32MiB、目录保留256项/128MiB、服务器最多检查4096候选等原预算保持；无效头/重复文件的实际读取也计入扫描字节预算。大量文件仍可能达到容量限制，本版不是无限目录扫描。

## 验证与边界

自动构建、真实核心探针、Minecraft 验收分开记录；探针图片只作私人验证，不打包游戏画面/ROM/存档。

未代装客户端或服务器，未上传发行服务、发布、重启或关机。回退时正常停机后换回保留的上一主包；本版没有存档迁移，但新开放板型在旧版会重新被拒绝。
