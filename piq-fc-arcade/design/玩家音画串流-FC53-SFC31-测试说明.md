# 方块电玩：家用机玩家音画串流测试版

适用：Minecraft 1.21.1 / NeoForge 21.1.236；FC 0.31.0-alpha.53，SFC 0.1.0-alpha.31。2026-09-17。

本包是本地开发测试包，未自动安装、部署或发布；自动化验证不等于双人实机验收。具体用例数、JAR 哈希和验证状态以包内《验证结果.json》为准。

## 文件与安装

- game_console-0.31.0-alpha.53.jar：基础模组，含 FC、小霸王、公共电视和同步组件，服务器与客户端均需更新。
- game_console_sfc-0.1.0-alpha.31.jar：SFC 家用附属，最低 FC53，使用 SFC 时服务器与客户端均安装。保持内嵌原 core9，不要额外重复装同 ID 核心。
- 只玩 FC/小霸王无需 SFC 包。街机附属 0.1.1、GBA8 本轮未重做，不包含在此 ZIP。

正常退出游戏、停服并备份实例/世界后，将旧的同 MOD ID JAR 移到实例外备份，成套换入新包再完整启动。FC 主协议39、家用媒体协议2、SFC协议7；不要混装FC52/SFC30或更早版本。建议先用世界副本和两位测试玩家验证。

不包含游戏 ROM、原厂 BIOS 或其下载链接。主持须按原游戏库流程准备自己有权使用的游戏文件；本轮不改变服务器原有文件管理策略，不自动删除已有文件。

## 怎么启用

1. 正常关机并等存档/退出收尾结束。
2. OP2 使用现有调试螺丝刀右键目标 FC、小霸王或 SFC，选“玩家音画串流”。
3. 若不可用，检查服务端 piq-sync-server.toml 的 allowPlayerHosting，以及是否成套更新。权限、空闲检查和领地保护仍有效。
4. 重新开机。开机主持运行现有模拟核心；其他持柄玩家只接收音画并发送经服务器确认的手柄输入，不为这一媒体会话下载 ROM 或启动第二个核心。已有玩家自己的游戏文件不会被删除。

本地输入同步仍是家用机默认，原本地/服务端托管流程保留。旧 FC/NES 街机柜仍固定本地输入同步，本轮没有把它解锁成三种模式。

## 行为与限制

- 主持不等于 P1：主持归还手柄后仍可继续运算；其他人借还手柄不迁移主持。
- 把手柄切到背包只释放输入，音画继续；原物品被丢弃、转移、重复、越界或权限失效仍按原规则收回控制权。
- 主持本机静音、局部声音距离和远端音频分开。远端手柄按钮动画使用本机已授权输入；不因此创建核心。
- 复位/重连/归还会校验原连接、会话、代次和租约。旁观仍只读，不获得手柄权限。
- 主持断线：安全停机，暂不自动换主持。重新开机才能再次运行。
- FC 核心或必需媒体发布失败时本机停止；在线但无响应的主持由现有3600帧历史上限兜底，正常20 TPS时约一分钟，服务器卡顿时可能更久。不是任何故障都即时停机。
- 压缩、网络发包及音画队列沿用既有有界限制。网络差时可能降帧/丢帧或超时，不保证局域网以外无延迟。本版未测量真实公网带宽与延迟。

## 存档说明，务必先看

**FC/小霸王**沿用卡带存档策略和服务器已确认快照；玩家串流使用独立模式命名空间，避免覆盖本地/服务器托管存档。切换模式不会自动迁移旧进度。异常停机只能保留最近已确认快照，未确认操作可能丢失；无存档策略的游戏仍不会凭空新增永久存档。

**SFC**目前仅有主持本机恢复备份：按 ROM SHA 位于 `piq-sfc-home/local-backups/<SHA>/latest.state` 与 SRAM，原逻辑每1800帧及正常关闭时备份。它不是服务器卡带存档，也不会在重新开机时自动恢复；同 ROM 的本地备份不是按同步模式分开的独立进度。进程崩溃可能丢失最近备份之后的操作。服务器存档和自动恢复尚未在本版补齐。

## 推荐人工验收

1. FC与SFC分别测试：主持P1、另一玩家P2；远端本地没有该ROM仍能加入并控制，只有主持运算。
2. 主持和远端分别切菜单、失焦、松键、切背包、借还手柄，确认无卡键，画面不因切背包中断。
3. 主持静音/走远但保持合法会话，确认远端声音不被一起关闭；第三人旁观没有控制权限。
4. 主持归还手柄后让另一人继续玩；主持断线应停机，不自动换主持。检查FC最近确认存档和SFC本机备份，勿假定两者一致。
5. 复位、断线重进、断开视频线、换电视、关机/开机，确认旧画面/旧输入不串入新会话。
6. 禁用玩家托管、非OP、设备忙碌、保护区等场景，确认不能绕过设置和访问权限。
7. 流量监控显示“玩家音画串流”；OP的 /gameconsole traffic、watch、off 继续适用。统计是本模组已埋点协议载荷，不是整机网卡流量。

本轮未修改模型、贴图、WASM、街机运行库及用户 ROM/BIOS。最终包保留既有正式手柄贴图，不夹带工作区草稿。
