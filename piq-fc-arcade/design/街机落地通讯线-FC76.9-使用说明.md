# 方块电玩 FC76.9：落地通讯线与开关音效

适用：Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21，主包 0.31.0-alpha.76.9。测试候选，不是稳定版。

## 本次变化

- 平行摆放的两台街机：沿用侧下方接口，接头保持横向，两端圆弧下垂，中段贴地平铺，去掉悬空 U 形线。四朝向、单/双人柜、紧凑/旧占地沿用。
- 两台不平行时保留绕机柜后方的落地路线。地面段中心距机柜支撑平面 0.017 格、线半径 0.015 格，留 0.002 格避免闪烁；不是逐方块检测地形。机柜高低不同按较低柜底面，台阶、挖坑、地毯和复杂地形仍待进一步适配。
- 空手右键实体侧开关，有效切到通电/关闭才播放一次机械咔嗒声。开机略高、关机略低，附近玩家共同听到，受“方块”音量控制。复用原版声音，不需额外资源包。
- 权限拒绝、限频、无状态变化、进入控制/旁观、主副柜同步及超距结束不重复响。开机声表示开关进入启动中，不保证 ROM/核心已成功运行。

## 安装与旧存档

退出游戏/服务器，先备份；将服务器与所有客户端 `mods` 中原方块电玩主包替换为本版，不能同 MOD ID 并装。没有替用户安装或重启。

沿用街机 0.1.5.1、完整 SFC41/core9、GBA10、PvZ9、电脑5-r2 / Flash运行库0.1.3；只替换主包，不换 ROM、BIOS、运行库或正式存档。

旧有效配对直接使用，更新后重新进入世界即可，不必拆机重放、重新接线或再扣线材。修改没有增加新配对协议、自动迁移或数据清理。

安装端依据：主包共同注册街机方块/方块实体与网络消息；`ServerCabinets` 在服务端验证物理交互及广播原版声音；`CabinetDataCableRenderer` 在客户端使用几何显示线材。不是仅依据依赖 side 推断。
