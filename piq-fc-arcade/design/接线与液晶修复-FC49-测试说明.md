# 方块电玩 · FC49 接线与液晶修复测试版

适用：Minecraft 1.21.1 / NeoForge 21.1.x；2026-09-17。
这是本地待验收测试包，不是稳定版。没有自动安装、发布或重启。

## 安装

先退出游戏/服务器并备份世界，再把 FC49 JAR 替换到客户端和服务端实际实例的 `mods`。同一 MOD ID 只保留一份，旧文件移到实例外备份。ZIP、说明和校验文件不要直接放进 `mods`。

本包两份 JAR：

| 文件 | 用法 |
| --- | --- |
| game_console-0.31.0-alpha.49.jar | 本次新版本。客户端、服务端都更新。协议仍为 38，但只升级客户端不会修复服务端扣线逻辑。 |
| game_console_sfc-0.1.0-alpha.28.jar | 可选 SFC 附属，与上次 SFC28 完全相同；已有正确版本不必换。内含原 core9，不叠装旧独立核心。 |

街机沿用上次 `game_console_arcade-0.1.1.jar`，本包不重复附带；GBA8 和原配套运行库沿用。只玩 FC 不需要附属。本次没有新增 ROM、BIOS、模拟核心或外置运行库。

安装端依据：公共设备注册、`ZapperStandService` / `CabinetLinks` 服务端连接与扣除、客户端线缆/指示灯绘制；SFC 的 `SfcHomeServer` / `SfcHomeClient` 分别处理服务端租约与客户端运行。不是根据依赖声明的 side 推断。

## 本次改动与操作

- **液晶开关：**空手右键正面下边框中央的 LCD 标牌区域即可开关；桌放、挂墙都适用。不需要新增遥控器，原底部按钮和遥控器设置仍保留，屏幕本身不作为电源键。
- **指示灯：**电视关闭显示红色，开启显示绿色。红色待机灯受环境光影响，不作为照明灯；绿灯保留开启效果。
- **数据线：**依次右键光枪支架与 FC，或两台街机，只有连接成功才扣一根，创造模式也扣；选择第一个设备、取消、越距、占用或保护校验拒绝都不应扣。
- **拆线：**手持另一根数据线，Shift＋右键已连接设备；或者拆掉对应设备。新版本实际扣过线的连接会掉落一根，重复拆除不会多返还。更新前没有扣线的旧连接不补发；它们仍可使用，重新接线后按新规则计数。
- **FC 外观：**降低收纳槽两端挡块，改用原红色底座配色，去除突出的高白块。保留收纳槽和原取还点击范围。
- **线缆外观：**小电视插头/线径缩小；同轴端线径衔接；壁挂电视在机身附近短分线汇合，不再把三根 AV 线一直拉到地面。
- **电视正下方摆机：**针对贴墙、上下投影重叠时后端线头撞墙而被隐藏的情况，增加短向上弯头和立体转弯路径。旧连接随客户端更新重新绘制，不要求拆电视或迁移世界数据。

原保护检查、街机连接权限、距离限制仍保留。接线保存中的 `PaidCable` 是可选服务器字段；旧连接没有该字段就不退款。需要回退时同时恢复升级前世界备份，避免丢失新记账状态。

## 请优先验收

1. 用截图相同的四种电视和桌放/壁挂方式测试：FC 紧贴墙放在电视正下方，四个朝向都能接线并看见线，线不穿墙；斜放、相邻摆放也查看。
2. 液晶下沿中央右键开关：关机红灯、开机绿灯；屏幕点击不误开关，音量与原遥控设置不受影响。
3. 主手各拿一根数据线测试光枪和街机：第一下不扣，第二个端点成功扣一根；拒绝连接不扣。再拿备用线拆除，看地上只返一根；重进世界后再拆也只返一根。
4. 保留一条升级前的旧数据连接，确认可用且拆除不补发。连接使用中、被保护和越距场景仍应拒绝非法操作。
5. FC/SFC 普通电视连接、取还手柄、光枪与街机双人连接、开关机和游戏操作均复测。
