# 经典实验街机 UV 定位摘要

坐标来自 `UV_Locator_32px.png` 的 16×16 网格；列为 `A-P`，行为 `0-F`。
OBJ 纹理坐标使用左上为原点的 PNG 坐标解释。

| 模型表面 | 主要定位区 | 设计用途 |
| --- | --- | --- |
| 正面灯箱 | `H0-K0` | 短标题、胶囊标志；文字必须保持紧凑 |
| 动态游戏屏幕 | `J-D` 至 `L-F` | 保持深色；运行时由 NES 动态画面覆盖 |
| 右侧主轮廓 | `A8-D F` | 适合单个竖向人物或大面积图案 |
| 左侧主轮廓 | `E8-H F` | 适合游戏标题、角色组或说明图案 |
| 背部主板 | 约 `E4-H7` | 适合重复纹理、通风口和小型标志 |
| 顶部大面 | 约 `I8-L C` | 适合低细节底纹，不放关键文字 |
| 操作台与前部小面 | 分布在 `A0-K4` | 使用色块、按钮、短胶囊图案，避免连续大图 |
| 底部、边框和窄条 | 分散在图集边缘及 `I-P` | 使用纯色或简单渐变，避免文字 |

正式皮肤应由 `tools/BuildMedicalArcadeSkin.ps1` 读取 OBJ 的真实多边形边界并裁切，
不应让生成式图像工具重新解释或重排 UV 岛。
