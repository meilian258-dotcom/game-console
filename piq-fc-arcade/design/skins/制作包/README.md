本制作包适用于 `piq_fc_arcade` 的“经典 FC 街机（实验型）”模型。

## 推荐制作流程

1. 先填写需求单，确定主题、主色、角色、文字和版权来源。
2. 把 `AI绘图提示词模板.md` 中的“连续侧板原画”提示词交给 AI。
3. AI 只输出连续原画或独立面板素材，不让 AI 直接绘制最终 UV 图集。
4. 使用 `01_经典街机_UV面片定位模板.png` 确认真实面片。
5. 通过 `tools/BuildMedicalArcadeSkin.ps1` 或图像软件的蒙版，把原画映射到真实 UV 多边形。
6. 屏幕区域保持深色，正面灯箱文字由脚本或图像软件确定性排版。
7. 导出 512×512 PNG，按制作规范完成检查。
8. 放入游戏实例的 `piq_fc_arcade/skins`，由 OP 在机身皮肤菜单中上传并应用。

## 方向校正规则（必须看）

- `Back` 材质的 B18、B21 在 UV 图集里转了四分之一圈。
- 这两个面上，**机身向上 = 图集向右**；实机想看到水平线，图集中必须画成竖线。
- 转速表、箭头、文字、数字等有明确方向的内容，必须在图集中顺时针预旋转 90°，或交给脚本处理。
- 后盖尽量不用可读文字；使用通风口、圆形接口、蜂窝和灯条更安全。
- `01_经典街机_UV面片定位模板.png` 已在 B18、B21 内用 `MODEL UP →` 标出真实向上方向。
- 连续侧板必须按 OBJ 的模型坐标投影，不能把散落的左右侧 UV 岛当成一张平面海报手工切片。

旧的 `06_红色赛车_完成范本_v1.png` 后盖方向错误，已移出制作包，不得再作为范本。

## 最重要的规则

不要把 UV 定位图交给 AI 后要求“直接生成最终贴图”。生成式模型通常会移动、合并或重画 UV 岛，最终必然产生错位、镜像、切字、黑洞和接缝。

正确分工是：

- AI：创作连续原画、纹理和局部装饰。
- UV 脚本或图像软件：准确映射和裁切。
- 人工：检查文字、方向、接缝与游戏实机效果。

AI 生成的图片只能是“原画素材”，不能是最终 512×512 UV；标题、方向性图标和后盖内容必须在映射阶段确定性添加。
