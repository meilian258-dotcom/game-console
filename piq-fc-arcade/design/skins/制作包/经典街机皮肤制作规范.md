# PIQ 经典街机皮肤制作规范

## 1. 技术规格

- 最终格式：PNG。
- 最终尺寸：512×512 像素。
- 色彩：建议使用 sRGB。
- 源图边长：1–2048 像素。
- 源文件大小：小于 4 MiB。
- 模组规范化后的 PNG：不得超过 1 MiB。
- 文件名：建议使用 `主题_作者_版本.png`，例如 `PillLab_Reborn_v2.png`。
- 不要依赖 PSD、图层或外部字体才能正常显示；上传文件必须是完整 PNG。
- 不要在动态游戏屏幕中画永久内容。运行时 NES 画面会覆盖该区域。
- 避免无意的透明像素；机身主体推荐完全不透明。

## 2. 模板与面片编号

`01_经典街机_UV面片定位模板.png` 来自真实 OBJ 的 UV 坐标。

面片前缀：

| 前缀 | 材质 |
| --- | --- |
| `S` | 动态屏幕 |
| `SB` | 屏幕边框 |
| `R` | 右侧机身 |
| `L` | 左侧机身 |
| `C` | 控制台 |
| `F` | 正面结构 |
| `T` | 顶部和灯箱 |
| `B` | 背部结构 |
| `D` | 底面 |
| `Z` | 外框和遮罩 |
| `N` | 投币器 |

面片角上的颜色表示 OBJ 顶点顺序：

1. 红色
2. 绿色
3. 蓝色
4. 黄色

定位图只用于制作。发布前必须隐藏定位颜色、编号、黑色轮廓和顶点标记。

### 2.1 背板真实方向警告

`Back` 组中两个主要后盖面不是普通的直立 UV：

| 面片 | 图集区域（约） | 真实方向 |
| --- | --- | --- |
| `B21` | `x=13–95, y=139–251` | 模型向上 = 图集向右 |
| `B18` | `x=137–226, y=139–251` | 模型向上 = 图集向右 |

因此制作这两个面时必须遵守：

- 希望游戏中呈水平的灯条、格栅或刻度，必须在图集里画成竖直。
- 带明显上下方向的图案，写入图集前先顺时针旋转 90°。
- 后盖尽量不放可读文字；若必须放文字，要用模型预览确认方向，不能只看 PNG。
- 这条旋转规则只适用于 `B18`、`B21` 等定位图明确标注的面，不得把整张图集一起旋转。
- 新版定位图在这两个面内标有 `MODEL UP →`，箭头方向就是机身在游戏中的上方。

## 3. 重点区域

| 模型表面 | 大致 UV 区域 | 要求 |
| --- | --- | --- |
| 正面灯箱 | `H0-K0` | 只放短标题；保留四周安全边距 |
| 动态游戏屏幕 | `J-D` 至 `L-F` | 保持黑色或极深色，不放 Logo |
| 右侧完整轮廓 | `RightSide` 全部面片 | 使用模型空间连续投影 |
| 左侧完整轮廓 | `LeftSide` 全部面片 | 与右侧配套，文字必须正向 |
| 控制台 | `Controller` | 按钮、摇杆、短图标；不要放大段文字 |
| 后盖 | `Back` | 通风口、设备舱、重复纹理；`B18`、`B21` 必须按 2.1 节校正方向 |
| 顶盖 | `Top` | 低信息量纹理，避免关键人物和文字 |
| 底面与窄条 | `Bottom` 等零散面片 | 纯色、渐变、颗粒或拉丝纹 |

## 4. 连续侧板规范

侧板不能用多个旧素材裁片拼起来。必须先制作一张完整竖向原画，再按模型坐标投影到所有 `RightSide` 和 `LeftSide` 面片。

建议原画规格：

- 工作尺寸：864×1821 或同等纵向比例。
- 画面必须从顶部到底部连续。
- 主体放在中上部和中部，避免重要面部紧贴轮廓边缘。
- 背景纹理延伸到四边，禁止留白边。
- 顶部标题区只保留干净底板，最终文字后期添加。
- 不把关键文字跨越灯箱、屏幕凹口、控制台凸起或机脚切口。
- 左右侧文字应分别校正方向，不能简单复制后导致镜像。

连续不等于“UV 图上相邻”。UV 岛在 512×512 图集中可能分散，但它们在模型空间中必须读取同一张原画的对应坐标。

连续侧板必须依据 OBJ 的模型坐标投影，不能把 UV 岛按平面位置拼接，也不能把旧成品图裁成若干矩形后重新铺回去。UV 岛在图集上被旋转、镜像或分散都是正常现象，最终方向以游戏内模型表面为准。

## 5. 构图规范

- 一台机器只使用一个明确主题。
- 主色建议 2–3 种，辅助色不超过 3 种。
- 远距离先看轮廓和主色，近距离再看到纹理与小图标。
- 重要 Logo 或标题与边缘至少保留 6–10 像素安全距离。
- 正面灯箱文字建议不超过 12 个拉丁字符或 6 个汉字。
- AI 生成的文字必须删除，最终文字使用可控字体重新排版。
- 不在多个小面片上重复同一个大 Logo。
- 控制台按钮图形与实际交互按键不必一一对应，但视觉方向必须合理。

## 6. 纹理规范

推荐组合：

- 大型金属面：低对比拉丝纹。
- 医疗或科技面板：低透明度蜂窝、六边形或电路纹。
- 喷漆外壳：细颗粒和少量磨砂噪点。
- 面板四角：铆钉、螺丝或小型高光。
- 接缝处：1–2 像素暗边或高光，不能画出多重重复黑线。

纹理必须满足：

- 不覆盖动态屏幕。
- 不影响文字可读性。
- 不在 512×512 原图上形成高频摩尔纹。
- 缩小到游戏视距后仍能看出层次，但不能像彩色噪点。
- 光影开关前后都能分辨主体。

## 7. 版权规范

- ROM、游戏截图、角色、Logo 和旧模组资产可能分别拥有不同权利。
- 未获得许可时，优先使用原创主题、原创角色和原创标志。
- “只在私人服务器使用”不自动取得复制或改编授权。
- 使用第三方模型或贴图前，记录作者、来源链接、许可证和授权截图。
- AI 输出不得故意仿制特定在世艺术家的独特风格。
- 对外发布时附上实际使用资产的署名和许可证文本。

## 8. 导出检查

发布前逐项确认：

- [ ] PNG 为 512×512。
- [ ] 文件小于 1 MiB。
- [ ] 没有 UV 编号、彩色顶点、定位线。
- [ ] 屏幕区域保持深色。
- [ ] 正面标题完整，没有被切字。
- [ ] 左右侧文字均为正向。
- [ ] `B18`、`B21` 已按“模型向上 = 图集向右”校正。
- [ ] 后盖希望水平显示的灯条、格栅在图集中为竖直方向。
- [ ] 没有黑色三角缺口。
- [ ] 没有透明裂缝和白边。
- [ ] 控制台、灯箱、后盖、顶盖、底面均有合理内容。
- [ ] 连续侧板在模型空间中连贯。
- [ ] 文件名包含版本号，旧版没有被覆盖。

## 9. 游戏内验收

必须实际进入游戏检查，不能只看平面 UV：

1. 正面近看和远看。
2. 左侧 45°、正侧面和后侧 45°。
3. 右侧 45°、正侧面和后侧 45°。
4. 正对后盖截图，确认 `B18`、`B21` 的上下方向和灯条/格栅方向正确。
5. 从上方检查顶盖。
6. 从下方检查底面和控制台下方。
7. 开始游戏，确认 NES 画面完整覆盖屏幕。
8. 白天、夜晚各看一次。
9. 无光影和常用光影各看一次。
10. 检查放置方向改变后是否镜像。
11. 多人环境确认服务器下载后的皮肤与上传者一致。

任何未在游戏中实际验证的项目，只能标记为“已生成/已检查图集”，不能写“游戏内测试通过”。
