# 同步优化测试版：FC alpha32 + SFC alpha19

这是文件交付测试包，不会自动安装、上传、发布或修改你正在玩的服务器。

## 成套更新

客户端和服务器都使用本包 FC alpha32、SFC alpha19。SFC 是合并包，保留 `piq_sfc_arcade` 与 `piq_sfc_home` 两个历史模组 ID，不要再叠放旧的独立 SFC 核心/家用 JAR。

Native alpha10、GBA alpha2 没改核心二进制，可继续使用；包中如附带这两个 JAR，也是原版字节。已有 `piq-native-arcade/runtime`、`piq-gba/runtime` 请保留，不需要重新下载模拟器。服务器不运行 Windows DLL。ROM、BIOS、个人存档不包含在交付包里。

此版升级了机柜房间协议，并新增游戏共享、同步设置与 SFC 修复协议；不能让一部分客户端继续用旧 FC/SFC。

## 先配置一次共享游戏

1. 管理员 `Shift + 空手右键` 机柜，选择模拟器后打开游戏列表。
2. 明确选择游戏并启动，即上传该 ROM；街机 ZIP 同目录的 `neogeo.zip`、`qsound_hle.zip` 若存在，也会一并上传。不会上传 DLL、整个文件夹或其他文件。
3. 完成后，这台机器的游戏由服务器世界数据记录。A 结束游戏后，B 普通右键可同步相同游戏并重新开机，无须在 B 的电脑重新选择 ROM。
4. 第一次下载显示百分比，之后校验缓存。旧版仅保存在 A 电脑上的选项不会偷偷上传，管理员需要在新版明确重选一次。

只加入传画面模式的 P2 或旁观，不需要下载游戏或运行模拟器；想成为新的主持人开机，需要安装对应核心运行环境。下载游戏本身不会给未安装的模拟器补 DLL。

上传只在管理员、有效租约、正确机柜和未开机条件下允许；断线、离开或取消不会把半份文件绑定为有效游戏。绑定包含主 ROM 和依赖哈希。两台数据线连接的机柜使用主机柜同一份绑定。

每文件最大 64 MiB，主游戏加依赖最大 128 MiB；世界共享缓存和本机下载缓存各有 2 GiB 上限。达到上限明确报错，不自动删你的旧游戏。服务器目录为当前世界下 `piq-cabinet/shared-games/objects`；客户端目录为实例下 `piq-cabinet/shared-games`，按服务器/世界和内容隔离。传输有 4 分片流水线、实际网络发送窗口、速率与超时上限；不支持断点续传。

## 游戏内切换

`Shift + 空手右键 → 同步 / 网络` 设置当前机柜正在使用的模拟器。

- 传画面：主持人的电脑运行核心，其他控制端接收音画；默认保留此兼容模式。
- 本地同步：各控制端运行同一游戏、同一核心，服务器排序输入帧；降低持续视频带宽，但每个参与者都需要对应核心。
- 必须管理员操作，且相连的两台机器都已结束游戏。修改后下次启动生效，不在一局中间切换。
- 不支持的后端会说明原因并禁用选项，不能强行混用。

本版开放 **SFC 机柜**本地同步；MAME 没有开放实验同步：真实《拳皇97》《合金弹头2》从头双实例输入一致，但快照恢复后 PCM/完整状态未全部通过一致性检验，不能用于可靠补帧恢复。MAME 继续传画面，GBA 也继续传画面。

FC/NES 及 FC/SFC 家用机保留已有本地输入同步，不改成传画面控制；它们不是新增机柜切换开关的对象。附近旁观者仍走有界音画流。不是 GGPO 回滚，也不是 MAME 原生机台联网。

## 流畅度和诊断

设置页内可选自动 20/30 帧、省流 20 帧、优先 30 帧；这是本次客户端运行期间的发送偏好，不更改模拟器 CPU 速度。自动模式在编码、排队和估算负载允许时升到 30 帧，有压力时回到 20；音频仍独立发送。保留 1 MiB/s 音画负载预算、整帧丢弃和真实网络写完成背压，不保证所有网络都达到 30 帧。

音画诊断显示取帧、编码、发送队列接纳、接收显示、流量和丢帧等。计数平均值从音画流创建时起算；“取帧”不是模拟器 CPU 实际速度，“队列接纳”也不等于远端已经收到。此项不会消除《合金弹头2》原机本身在复杂场景中的减速，也没擅自开启超频。

## SFC 一致性恢复

家用 SFC 新增周期完整状态摘要检查；只隔离异常控制端输入，健康主持端继续。异常端拿受授权快照加有界输入记录追帧，通过确认后才恢复控制。机柜本地同步复用同一 SFC 核心封装，并有周期摘要、受限快照和追帧流程。

首次双人邀请仍保留已有审批与短暂停表，不声称完全无停顿；失步修复走新单端恢复。主持端失效或历史过期会明确安全结束，不偷偷重新开局。此版没有做主持人掉线后的无缝迁移。

## 建议验收

1. 同一台街机：A 配置启动，B 加 P2；A 退出后 B 独立重启，检查无需重选游戏。
2. SFC 机柜：关机选本地同步，双方重新加入，检查按键/投币/开始、连续音画和远离归还。
3. 中途打开设置：确认模式不能改；全员退出后可改回传画面。
4. 两台双人机通过数据线连接：检查四个席位、同画面、另一台机柜重启使用同一游戏。
5. SFC 家用：邀请、退出、重新加入、旁观和断线；故意网络抖动时应只影响异常端。
6. 传画面时观察诊断；分别检查模拟器内部变慢和画面传输丢帧，避免混为一谈。

自动化测试包含实际核心、实际 worker、外层包编解码、权限/租约纯逻辑、实际发送窗口、缓存文件与最终 JAR 校验。它们不等于两台真实 Minecraft 客户端在你的公网服务器上完成全流程验收；服务器保护插件、真实延迟和实机操作仍需以上测试。
