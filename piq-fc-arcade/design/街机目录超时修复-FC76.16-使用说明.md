# 街机服务器目录超时修复 · FC76.16

2026-09-28；Minecraft 1.21.1 / NeoForge 21.1.236及声明兼容范围 / Java21。本地修复候选，Minecraft多人界面尚待实测，不标稳定。

## 修了什么

原目录一批最多64项，但发送预算按`1024 + 项数 × 4096`计算，发送接口单包最多32768字节。达到8项时预算为33792字节，回复被拒绝，调用方却忽略失败，15秒后就显示“服务器目录请求超时”。页面初始“0项”不等于真实ROM已丢失。

本版统一使用每批7项的目录协议，预算最多29696字节，不提高底层传输安全上限。客户端下一页/上一页、服务器分页、网络包校验和游戏资料保存返回页同步适配；资料保存后仍返回包含该游戏的页。目录总量上限512保持，不是只保留前7个游戏。

短暂连接背压时每250ms重试，最多5秒；最多64个待发连接、每连接一页，新请求替换旧回复。每次重试复核当前连接、租约、机柜和内容权限，仍走原物理连接发送窗口，不能通过重试绕过授权或流控。到期尝试发送小型失败提示，连接仍完全堵塞则记录服务端警告，客户端仍有15秒截止，不无限排队。

未成功取得目录时改显示“服务器目录未读取”，不再冒充“服务器0项”；快速重复请求在本机提示稍候，避免触发服务器限频后一直等待。

不涉及：ROM文件迁移/删除、下载断点续传、PGM保存、核心/模型/贴图、关机/显示距离规则、电脑或家用机行为。沿用FC76.15街机全服规则。

## 安装

1. 备份服务器世界和双方旧主包；退出客户端，安排服务器正常停止后再替换，不在运行中热换JAR。
2. **服务器与所有客户端都更新主包**到`game_console-0.31.0-alpha.76.16.jar`，移走旧`game_console-...jar`，不能新旧主包同时加载。
3. 街机0.1.5.1、完整SFC41/core9、GBA10、电脑7、PvZ9等现有配套附属保持原样。只需更新主包；附属版本声明的39项检查已通过，不代表全部玩法重新实测。
4. 完整启动两端后打开街机 → 配置此模拟器的游戏 → 服务器游戏 → 刷新。已共享游戏/机柜绑定保持，不需要拆机器或重新上传ROM。

本版目录协议为`cabinet-game-6`，上一版为`cabinet-game-5`；两端必须配套更新，不能只换客户端或只换服务器。安装端依据是公共服务端目录/权限/回复处理及客户端菜单/codec同时变化，不只是元数据中的side声明。

候选提供单 JAR、说明、验证、增量源码与哈希清单；不是含 ROM 或完整开发 SDK 的整合包。服务器现有文件清单未核验。
