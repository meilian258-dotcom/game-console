# GC-047：新机器默认与单机旁观范围

适用：本轮 FC57 候选源码；最终版本、成品与完整验证以本轮交付记录为准。本文不代表已经安装或人工验收。

## 入口

OP2 在聊天输入 `/gameconsole settings`。菜单列出当前全局默认和可点选选项；点击只预填命令，按回车才提交。家用机的单机查询复用原同步 GUI，街机查询在聊天显示结果，原调试螺丝刀 GUI 保留。

| 命令 | 用途 |
| --- | --- |
| `/gameconsole settings global sync auto` | 新机器沿用各机型自动默认 |
| `/gameconsole settings global sync local` | 新机器优先本地输入同步 |
| `/gameconsole settings global sync media` | 新机器优先玩家音画串流 |
| `/gameconsole settings global sync server` | 新机器优先服务端托管 |
| `/gameconsole settings global range 16` | 新机器默认旁观接收范围（4～64 格） |
| `/gameconsole settings target` | 瞄准游戏机，查询或打开家用机设置页 |
| `/gameconsole settings target sync local` | 仅将瞄准的空闲设备改成本地输入同步；亦支持 `media`、`server` |
| `/gameconsole settings target range 8` | 仅修改瞄准设备的旁观接收范围（4～64 格） |

单机命令使用**执行时**瞄准的游戏机，不是聊天菜单打开时的旧坐标；需在原交互距离内，不操作未加载区块。连接通讯线的两台街机按整组检查和修改。

## 新旧机器边界

- 全局设置只影响之后新放置的实体。世界载入、区块重载以及旧 NBT 缺字段，都不算新放置。
- 新家用机在首次加载时，按该机型实际能力和服务器执行策略采用默认。模式不可用时，保留机型原默认；不会自动开启服务端运行环境或执行权限。
- 新通用街机保存放置时的默认偏好，在对应后端首次解析时按当前能力固化。已明确设置的后端模式优先；旧机器不跟随新默认。旧 FC 街机仍只能使用原本地输入同步。
- 范围在新实体上固化，单机修改也保存到实体。旧实体无范围字段时保留原路径默认；不会因为修改全局默认而被迁移。
- 全局设置保存于当前世界的 SavedData；没有覆写世界中的已有主机清单，也没有批量停机、重启、改存档或变更游戏库权限。

## 旁观范围不是区块渲染距离

这里控制旁观者接收和播放本模组画面的范围，包括已接入的本地省流旁观；不控制 MC 区块加载、方块模型可见距离或其他模组，不会强制加载远处机器。音画旁观退出边界比进入范围多 4 格，以免边缘反复切换。实际可见和可接收仍受已加载区块、设备、会话与权限限制。

当前单机入口支持 FC、小霸王、已接入 HomeSystems 高级设置的 SFC，以及主包通用单/双人街机。不能据此宣称未接入的旧独立柜、GBA 或 Flash 原型具有相同管理能力。

## 验证与待验收

本轮新增 7 项测试：模式能力组合、范围边界和退出迟滞、非法值、真实 SavedData 读写、旧 NBT 源码连线护栏、OP2/保护/空闲/实例身份护栏。连同原设备调试与公开默认的 12 项回归测试，共 19 项通过；没有启动 Minecraft。

需人工验收：普通玩家无法执行；运行/加入/存档收尾中的机器拒绝修改；改变默认后旧机器不变而新机器采用；卸载并重载区块后设置保留；FC/小霸王/SFC 与通用机柜各测试一次；调小范围后超出玩家不再旁观，增大范围只在区块已经加载时生效；保护插件拦截仍有效。
