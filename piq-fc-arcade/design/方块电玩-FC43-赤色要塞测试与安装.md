# 方块电玩 FC alpha.43：赤色要塞适配测试版

适用：Minecraft 1.21.1、NeoForge 21.1.236 起的 21.1 系列、Java 21。

## 安装和配套

- 本次只更新主模组 `game_console-0.31.0-alpha.43.jar`。完整成品路径：`piq-fc-arcade/build/review-mapper43-v1/`（仅以该目录成功构建见证为准）。
- 客户端与服务器均安装 FC 主模组，依据：`FcNetwork` 双端必需协议注册、服务端方块/会话逻辑与客户端核心/画面；不是根据依赖的 side 字段推断。
- FC 网络协议从 34 改为 35。服主、本人和朋友的 FC 主模组都必须更新到 alpha.43；旧版会被握手拒绝，不能一端 42、一端 43。
- 先退出游戏并正常停止准备更新的服务器，备份世界和 `piq-fc` 数据；只替换旧 FC 主模组 JAR，同一 modId 不要保留两个版本。不要删除 ROM、存档或整个运行库目录。
- 可继续配套上一套街机 `game_console_arcade-0.1.0-alpha.17.jar`、SFC `game_console_sfc-0.1.0-alpha.25.jar`（含 core alpha.9）、GBA `block_arcade_gba-0.1.0-alpha.8.jar`。它们不是本次新构建，版本依赖范围允许 FC43；仍须保留各自原有运行库。SFC 合并包不要再叠加旧独立核心。
- 只玩 FC 不需要额外下载 DLL、BIOS、ROM 包或另一份模拟器。新 Mapper19 WASM 内置在 FC JAR 中；旧 FC 和光枪 WASM 保持原字节。
- 此说明是测试版安装指南，不是公开发行审核结论。

## 本次支持范围

目标是用户已有的 `0946 - 赤色要塞 - 最终任务 (v1.1) (简) [雷精灵].nes`，iNES Mapper19、128 KiB PRG + 128 KiB CHR。未修改用户文件、文件头或散列。

新增独立 Mapper19 核心：三个可切换 8 KiB PRG 窗口、固定末尾窗口、8 个 1 KiB CHR 窗口、nametable/CIRAM、WRAM 分段保护、128B 芯片 RAM、CPU 周期 IRQ。根据 ROM 自动选择，无需玩家手选核心。

这不是所有 Mapper19 游戏的完整兼容声明：暂不包含 N163 扩展波表音频、诊断 CHR 引脚模式和指令内部逐总线周期精确 IRQ；暂不开放 NES2.0 子型号/CHR-RAM 布局。当前这份赤色要塞初始化及切换代码禁用扩展音频，游戏原有 APU 声音已离线验证。

Mapper19 使用独立的模块散列、状态头和存档键；旧 FC/光枪核心和原有存档键不变，不迁移、不覆盖旧存档。新核心的整内存快照包含内部芯片 RAM，但不新增独立 battery/SRAM 文件导入导出功能。

Mapper19 当前仅使用手柄，不能切到光枪核心；若该主机还连接光枪，按提示断开后使用手柄。两人输入保留既有 FC 按键语义（P2 无独立 Start/Select）。

## 玩家验收步骤

1. 新版客户端与服务器启动后，在写卡工作台刷新 ROM 列表，选择自己合法持有的上述游戏写卡。
2. 先选个人存档槽，在 FC 主机开机、取下手柄。确认标题、开始、方向、射击、投弹、声音正常。
3. 加入朋友的 P2，游玩至少一个关卡；再让另一位玩家不操作机器旁观，核对双方画面、声音、输入和退出后的状态。
4. 正常关机并重新开机，选择恢复个人槽；换人开机和相同玩家跨机器使用个人槽后，核对进度归属。
5. 再测试原有其他 FC 游戏和光枪游戏的旧存档，确认未受影响。
6. 如启用服务端托管，在已允许该模式且具备运行环境的服务器重复以上检查。不能把本地双核心测试当作真实网络或 Linux 服务器实测。

遇到异常请保留 `logs/latest.log`，说明同步模式、谁开机、单人或两人及游戏文件名；不要直接删存档尝试。

## 验证说明

离线真实 ROM 已显示标题及可游玩关卡，方向控制和地图滚动已目视核对。Gradle 1706 项：1698 通过、8 跳过、0 失败；Rust 普通79/79与zapper87/87通过（各有1既有忽略文档测试）。最终JAR-only探针只编译QA，生产类和WASM都来自交付JAR；合成输入及跨实例恢复合计370比较帧、275471音频样本一致，模块篡改被拒绝。真实ROM另跑1800帧原局和120帧恢复续跑，单人模式，不冒称Minecraft真实双人测试。

最终 JAR 30,794,355 字节，SHA256：`108DEDB98B2BE0A1D8682868D32DA5698357900B9BBB85FE2CCF4198C55AA372`。分类交付位置：`方块电玩-FC43-赤色要塞测试`，与冻结目录同哈希；build/libs 是含历史源贴图差异的编译中间件，不用于交付。独立检查确认27项预期变更、无删除，旧两WASM及209项资产不变，无ROM、BIOS或私有截图。

真实 Minecraft 多人、长时间通关和全平台测试仍待玩家验收。

芯片实现依据：[NESdev Mapper 019](https://www.nesdev.org/wiki/INES_Mapper_019)、[Namco 163 RAM/音频寄存器说明](https://www.nesdev.org/wiki/Namco_163_audio)。实现为本项目 Rust 原创修改，沿用 nes-rust MIT 许可；没有引入其他模拟器代码、商业 ROM 或 BIOS。
