# 方块电玩：管理员设置与 SFC 省流旁观测试版

适用 FC 0.31.0-alpha.57、SFC 0.1.0-alpha.35、Flash 0.1.0-prototype.4（仅兼容补丁）。2026-09-19。本地候选，不是稳定发行，不代表已安装或真实多人验收。

## 安装范围

- Minecraft 1.21.1 / NeoForge 21.1.236 起的21.1系列 / Java21。服务端与玩家客户端成套更新FC57；使用SFC时双方同时更新SFC35（包含原core9，不额外装重复SFC核心）。源码依据：双方设备注册、共同协议、SFC新增强版本旁观通道，客户端运行和服务端租约校验均有改动。
- 使用Flash播放盒原型3的用户，随FC57改用原型4兼容JAR；其Java/素材/运行器未改，保留完整runtime0.1.2。原型4仅扩展经核对的FC56/57范围，不能宣传性能或联机改善。不用Flash的不必安装。
- 街机0.1.1、GBA alpha.8沿用，没有本轮新核心或新运行库；包内不含ROM、BIOS、SWF。测试前自行备份世界和配置；不要同时放多份同模组JAR。

## OP管理

输入 `/gameconsole settings` 查看可点菜单；点击预填，回车才执行。

| 用法 | 效果 |
| --- | --- |
| `/gameconsole settings global sync local` | 新机器优先本地同步；另有auto、media、server |
| `/gameconsole settings global range 16` | 新机器旁观范围，4～64格 |
| `/gameconsole settings target` | 瞄准设备，查询/打开家用机原同步设置页 |
| `/gameconsole settings target sync media` | 仅修改瞄准空闲机器；另有local、server |
| `/gameconsole settings target range 8` | 仅修改瞄准空闲机器的旁观范围 |

全局只影响新放置机器，旧世界/旧NBT/已有明确设置保留。实际模式仍受机型和服务器权限/运行环境限制；不支持的模式不会被强行启用。单机须OP2、空闲、有交互权限，连接的双街机按整组处理。射线不读取未加载区块。

旁观范围是游戏画面接收和本地回放距离，不是MC区块渲染距离，也不改变声音衰减距离或玩家手柄控制范围。共享音画和SFC本地旁观有4格退出余量；FC原本地路径保留其原边界规则。支持FC/小霸王/SFC家用机和已接入的通用街机，不包含未接入的GBA/Flash管理。

## SFC旁观选项

| 客户端命令 | 行为 |
| --- | --- |
| `/sfc-watch` | 查看当前选项 |
| `/sfc-watch local` | 本地省流旁观（默认），也是失败后的手动重试 |
| `/sfc-watch media` | 音画旁观，不在本机执行游戏核心 |
| `/sfc-watch off` | 关闭SFC旁观 |
| `/sfc-watch rom E:\\Games\\demo.sfc` | 显式导入本机对应ROM；命令中的路径替换成实际路径 |

本地旁观目前针对公开SFC家用机的本地输入同步会话，每客户端最多一个只读核心，优先最近有效屏幕。需要与主持相同的ROM和核心；优先只读本机已验证缓存，缺文件提示导入，不自动向服务器下载、上传或切成音画。服务器托管/玩家音画模式需要主动选择media；local不悄悄退回高流量。

首次加入仍需传检查点并追帧，之后主要接收输入，定期比较状态；不是零流量，也会增加旁观电脑CPU/内存开销。异常/状态不一致/历史过期时只停止这名旁观者，不停主持游戏；重新选择local或media。没有写旁观存档或授予手柄权限。主动公开/私人/街机操作优先，让旁观退出并等核心释放。选项保留在当前客户端进程中，不是持久全服策略。

## 街机流量结论

Native 街机本地同步仍约每1800帧上传一次完整恢复快照，供晚加入/失步使用；不是每周期向所有人广播。现有约3.3MB样本不能直接当公网消耗：HUD统计本模组Minecraft外层压缩前载荷，服务器传输压缩还会改变实际字节数。

本轮没有为了让HUD数字变小而重写快照压缩，也未删恢复快照或拉长安全窗口。Native真实带宽测量/后续优化另列待办，不标“已修复”。
