# 街机操作与 Netplay 投币 · FC76.6 测试候选

适用：2026-09-27，Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21，Windows x64 运行器。候选版本不是稳定版；尚未完成 Minecraft 真人多人交互验收。

## 安装

退出游戏并备份后，将双方（服务器及所有客户端）主包换为 `game_console-0.31.0-alpha.76.6.jar`，不要与旧主包并装。本轮没有代安装、部署、发布或重启。

沿用街机 `0.1.5.1`、完整 SFC `alpha.41`（core9）、GBA `alpha.10`、PvZ `prototype.9`、电脑 `prototype.5` 的 r2 成品、Flash `0.1.3`。这些附属不是本轮重新构建。主包保留共同方块、方块实体、服务端授权/会话/网络和客户端显示/输入，故双方都需要安装，不能仅凭依赖声明中的 side 判断安装端。

协议已改为 `cabinet-room-9`、`cabinet-3`、`cabinet-sync-7`，原生帧接口 PNP4。新旧主包不要混连。本包不含 ROM、BIOS 或玩家存档。

## 现在如何操作街机

1. Shift 空手右键或用设备调试工具查看设置：显示服务器绑定的游戏文件名，例如 `contra.zip`，以及会话状态。长名称可悬停查看。不是游戏中文名数据库；未绑定的本地文件不能凭空识别。
2. 在原街机两侧、约下半部偏后处有红色开关键。空手对准右键启动；已开机时，仅当前主持或 OP2 管理员可以用此键关闭整组。
3. P1 再右键机柜操作区，只退出操作，游戏继续；再右键恢复。暂离时会清空按键，仍保留 P1 主持身份与席位，不会自动把主持转交别人。
4. 主持仍需保持在线、在原许可范围内（通常 8 格）；离线、离开范围、机柜被破坏等仍会关闭会话。不是无人值守托管。
5. 已放置的机柜无需拆掉重放。开关键为程序绘制，与服务端判定共用几何；真实游戏内的可见性、四方向命中和光影兼容仍待测试。此交互用于原生街机后端，不改 FC 卡带机电源行为。

## Netplay 实体投币

机器空闲时，OP2 用设备调试工具将整组“游戏币”切到“实体投币”，并选择 Netplay；随后正常开机、允许玩家加入。每位玩家先取得自己的席位，手持“银色游戏币”，对准所属机柜正面投币口右键，一次消耗一枚、给自己的 P1/P2/P3/P4 送一次投币。必须松开后再次点击，长按不连投。免费模式不扣物品，继续使用原投币按键。

物品模式禁用键盘/手柄免费投币位，服务端继续核验物品、机柜、席位、保护权限和连接。四口游戏输入由服务器过滤后发到主持电脑，由主持核心写入 Netplay；其它原生端只有旁观权限，不能绕过物品规则申请原生控制口。它们仍本地模拟出图，不是音画串流；输入绕经 Minecraft 服务器，比原生免费分席模式可能增加延迟。

四人游戏仍需游戏本身支持并启用四人。三国战纪先按原 FC76.4 流程，用 OP2 的 P1 执行 `/gameconsole arcade pgm confirm`，在维护菜单将 PLAYER MODE 改为 4 PLAYERS 并退出。只连接两柜不会自动修改游戏软 DIP。维护设置仍不保证下次开机保留。

投币消息有序号去重、四口独立按下/松开队列，普通松键不吞已排队投币；会话销毁会清队列。物品发送成功后如主持崩溃，没有端到端确认及自动退币机制；不把它当作持久化交易系统。

## 画面旋转

Netplay 运行器传出核心实际旋转值及原始宽高比，控制玩家和旁观者使用同一旋转路径。现有服务器缓存 `contra.zip` 在五进程探针中返回 rotation=3，已目视核对游戏文字/人物朝向正常、显示比例 3:4。不是按文件名硬编码，也不是把所有游戏一律旋转；其他游戏仍需实测。
