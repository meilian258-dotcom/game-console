# 自动控制与街机数据线 alpha30 测试版

本包只提供文件，不会自动安装或修改世界。请先退出游戏并备份旧 mods；客户端和服务器成套升级。保留你的 ROM、BIOS、存档和配置目录。

## 安装文件

- 核心内置 FC：`piq_fc_arcade-0.31.0-alpha.30.jar`。
- SFC 附属：`piq_sfc-0.1.0-alpha.18.jar`，已经合并所需 SFC 核心，不再额外安装旧 `piq_sfc_home` / `piq_sfc_arcade`。
- 原生街机附属 `piq_native_arcade-0.1.0-alpha.10.jar` 与 runtime helper 本版保持原字节。
- 对同一模组仅保留一份版本。配套 helper 位于游戏目录 `piq-native-arcade/runtime/`，不是 mods 内的模组。
- 新街机房间协议为 `cabinet-room-2`，旧客户端/服务器不可混用；FC/SFC 游戏核心保持原版。

## 拿起手柄后的按键

拿起已借出的 FC/SFC 手柄或光枪，自动接管当前方案的游戏功能键；同键的 Minecraft 标准绑定不再触发。主机关机时也能拿着设备，但不会凭空启动核心或获得联机控制权。

默认方案：WASD + JKL / IOP，Z 为位置锁，F7 打开控制设置。

| 状态 | WASD | 游戏功能键 | 鼠标 |
|---|---|---|---|
| 拿起，未锁位置 | 在世界走动，不重复传游戏方向 | 一直可用 | 正常转视角 |
| 按 Z 锁位置 | 控制游戏方向，屏蔽世界走动/跳跃/潜行/冲刺 | 一直可用 | 正常转视角 |
| 再按 Z 解锁 | 恢复世界走动 | 仍可用 | 正常转视角 |
| 放回设备 | 恢复原绑定 | 恢复原绑定 | 正常 |

位置锁不冻结重力、击退，也不提供无敌。Esc 仍可打开 Minecraft 菜单；菜单、失焦、换手、归还和授权变化都会清除输入，松开按键后才重新接管，避免粘键。

默认功能键：

- FC：J=B，K=A；退格=Select，回车=Start。
- SFC：J=B，K=A，L=Y，I=X，O=L肩键，P=R肩键。
- 街机：J/K/L/I/O/P = 游戏内 1/2/3/4/5/6 号按钮；退格=投币，回车=开始。不同游戏按钮用途以游戏本身为准。

也可选择“方向键 + JKL/IOP”或“方向键 + 小键盘 1–6”，方向键不与 WASD 重合时，未锁位置也能控制游戏方向。自定义功能键若占用 W 等移动键，游戏功能优先，会占掉相应世界移动；设置页有提示。

旧配置只在内存中迁移，未点击保存不会重写文件。旧 Z 游戏键会避让位置锁，实际新键在设置页显示；跟随 Minecraft 绑定的方案只作本模组内局部热键替换，不改 `options.txt`。Legacy 的重置/静音实际键可悬停方案查看，其它固定方案使用设备按钮，不额外截取未列出的 Reset/Mute 快捷键。

对应标准 KeyMapping 和按键事件路径已拦截；不能保证某个其它模组绕过标准事件、直接读取 GLFW 时也会被拦截。

## 光枪、手持显示

- 持枪仍可用 FC 的方向、A/B、Select/Start。无人占 P1 时，已授权枪的按钮作为 P1 输入；别人已占 P1 时不会抢走其键盘控制，只保留射击。本人已有正式 P1 时使用本人租约。归还枪不清掉别人的输入。
- 数据线和光枪支架增加手持显示变换，原模型、UV 和物品栏图保持。
- SFC 第三人称空闲副手时双手握持；副手有其它物品时不接管该手。

## 街机数据线

连接/拆线仍要求管理员权限及两端操作许可，保护插件校验保留。先结束两台机器的游戏，再用数据线右键第一台作为主柜，60 秒内右键第二台。两柜必须同维度、间距不超过 16 格；操作时两端都需在玩家 8 格以内。每台最多接另一台，不能继续串成多柜链。

| 组合 | 主柜席位 | 副柜席位 | 总人数 |
|---|---|---|---|
| 单人 + 单人 | P1 | P2 | 2 |
| 单人 + 双人 | P1 | P2/P3 | 3 |
| 双人 + 单人 | P1/P2 | P3 | 3 |
| 双人 + 双人 | P1/P2 | P3/P4 | 4 |

所选后端必须提供足够的联机端口。SFC 后端两口，仅可连接两台单人柜；原生街机后端最多四口。FC 的旧机柜会话没有接入这个串联房间，不把接线当作新增四人 FC；GBA 初版也不支持连线。接线只扩展可分配端口，游戏 ROM 自身仍须支持相应人数。

从主柜启动，其他玩家在对应机柜右键申请，仍需主人同意；两柜显示同一局。连接后可看到有插头的可见数据线，不用先右键加入。两端已加载且配对身份一致才绘制；远离、卸载或断开后不会用旧坐标画“幽灵线”。线材绕过两台机柜本体，但不模拟线缆物理或自动绕开沿途其它建筑。皮肤与 ROM/存档原数据不合并、不会删除。

持数据线 Shift+右键任一端可拆线（需停局、两端可操作）。原家用 AV 线仍用于主机→电视，数据线用于街机互联或光枪支架→FC，不能混作 AV。

## 验收建议与边界

先测试：空手/拿手柄/关机持柄、Z 两次、菜单后松键、主副手切换；拿枪按 Start 与归还；第三人称及左右手；两台单柜连接、旁观、批准 P2、拆线、重载区块。再测试混接与双柜四人。

随包 checks 是离线自动化、真实核心/字节码/协议编解码与模型数学验证，不等于真实 Minecraft 联机和显卡画面验收。实体 Xbox/NS/PS 手柄、保护插件和复杂整合包按键仍需实际游戏测试。本包不含商业 ROM、BIOS 或用户存档。

GBA 为另一个可选试用包，使用 [mGBA/libretro](https://docs.libretro.com/library/mgba/)；当前只通过共享街机运行本地单人游戏，不是已完成的手持掌机或 GBA 联机。详情见其独立使用说明。
