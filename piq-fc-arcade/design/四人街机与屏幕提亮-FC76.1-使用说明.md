## 四人怎么连接

1. 使用两台双人街机，选择相同的街机后端，用现有通讯线连接为一组。单台仍是两个席位；不是对着一台机器无限加人。
2. 让整组空闲，由有权限的管理员在设备调试/同步与网络中，选“RetroArch Netplay（实验）”，游戏币设为“免费按键”。没有放开实验模式的实体扣币或存档限制。
3. 主机柜分配1P、2P，另一台机柜分配3P、4P。按现有加入设置申请/领取席位；服务端固定绑定端口，先来的3P不会抢成2P。每人用自己的街机按键方案，F7查看/调整投币、开始和游戏键。
4. 游戏文件和 BIOS 需兼容当前 FBNeo 核心，游戏本身必须支持四人；有的 ROM 版本只支持二人/三人，有的需在游戏机台维护菜单调人数。不会把二人游戏变成四人。

四席房间预留三个远端玩家连接，最多再容纳五名原生旁观者；旁观输入不能升级成玩家，离席后需重新授权。主持退出会结束本局，未实现主持迁移。已有音画串流的四输入口保留；旧 MAME“本地同步”仍只支持原验证双人方案，不能把它与 RetroArch Netplay 混淆。

## 三国战纪的四人开关

本轮使用现有 kov.zip 和同目录 pgm.zip 隔离测试，不改原游戏文件。该样本默认是2 PLAYERS：

- 在标题/演示界面，由1P长按 Start 约4秒，松开，进入 MAIN MENU。
- 方向键选择 OPERATOR SETTING，游戏“按钮1”确认。
- 选择 PLAYER MODE，用按钮1切到4 PLAYERS（本样本不是用左右键切换）。
- 先选本页 EXIT，再选 MAIN MENU 的 EXIT，等待返回游戏。
- 四人分别投币、按 Start、选角色。菜单切换后稍等再按下一次，长按方向可能重复跳行。

此实验模式不持久保存游戏进度/NVRAM，重新开局可能需要重设人数；不要把这一步改成修改用户 ROM 或擅自导入存档。其它游戏维护菜单不一定相同。FBNeo 的设置可来自核心选项或游戏维护菜单，见[官方 DIP/维护菜单说明](https://docs.libretro.com/library/fbneo/#dipswitches)。

## 屏幕提亮

共用电视、街机以及 GBA 掌机的游戏画面改用不受方向光/世界光照压暗的屏幕材质。原黑色仍是黑色，不靠拉高全局 gamma 或抬黑；不修改机壳、手柄或用户贴图。保留开机亮度渐变、CRT扫描线、雾和深度遮挡。

电脑的 PvZ/Flash 复用电视显示路径，也获得这一改动，电脑4本身不需重建。这不等于给电脑新增联机；PvZ/Flash的远端旁观与鼠标交接仍未实现。

## 验收与限制

自动测试、独立真实核心进程、离屏GPU着色器测试与 Minecraft 实机验收不同。详细结果在本包 VERIFICATION.md。请实际检查：四名玩家分配1–4P、分别投币/开始/移动/攻击、3P/4P退出重进、旁观有音画且不能操作、主机退出能收尾；再检查白天/夜晚/四朝向的电视、CRT、掌机和电脑画面，资源重载及正在使用的光影包兼容。

Netplay仍消耗流量（输入、协议、初始状态和必要重同步），不是零流量。沿用原FBNeo PGM修补核心，未修复此前NeoGeo完整状态CRC/高流量问题，不把三国战纪结果泛化到所有街机。光影包和Minecraft真人四客户端本轮未自动验收。
