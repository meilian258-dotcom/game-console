# alpha.13 — 电视扫描线遥控器

范围：一个可重复使用的 `tv_remote`，不修改 NES 核心、存档、按键、AV 或既有模型。客户端与服务端协议同步至30。

## 操作和权限

- 创造页或 `/give @s piq_fc_arcade:tv_remote` 获取。主/副手瞄准8格内电视右键，切换该电视的CRT扫描线；无须OP，但必须拥有方块交互权限。
- 默认关闭；`HomeTvBlockEntity.CrtScanlines` 随该电视NBT保存，并通过已有BE更新同步所有观看者。支持全部6种家用电视，不作用于街机/写卡电脑。
- `TvRemoteItem.onItemUseFirst/useOn/use` 共用服务端动作。服务端重新射线，首个方块遮挡，未加载区块阻挡而非强载。代理/锚点边界、权限和标准RightClickBlock事件校验；事件后复核射线、BE/UUID和原手持对象。
- 8tick尝试冷却，原版使用锁存防止长按反复切换；无消耗/耐久。仅ActionBar短提示。第三方领地需遵循标准交互事件，仍待组合实测。

## 显示

开启时以 `CrtScanlineVertexConsumer` 把原游戏quad替换为240个水平条带，交替轻暗。不是透明面覆盖，不另加深度偏移，不修改原纹理或RGB缓存/摘要，不引入shader/PNG。

亮行保持原色，暗行最多乘0.72，alpha/UV/法线/灯光/overlay保留。无时间参数，不滚动、不闪屏。以实际投影短边高度做密度控制：不超过240像素完全原样，240–480像素smoothstep渐入。用于降低远距离走样，不承诺所有光影/FOV都无摩尔纹。关闭和非电视直接走旧绘制路径。

## 验证与边界

纯Pattern覆盖行边界/相位/非法输入/暗度；真实MC VertexConsumer探针验证960顶点单层、位置/UV/alpha/normal/light保持、远距回传4点、后方/空视口、无双重pose。遥控器有8纯Java和9源码约束回归；模型有14工具检查。

全部旧67个冻结外观不变，仅加遥控器1个模型，43额外历史保护。遥控器59元素/314面，无新PNG，七种现有CRT实色。冻结SHA：6620E178C8C03A2826B980F4F6BB0E9C41342D01CAF9140C6859146B45F27FD7。
