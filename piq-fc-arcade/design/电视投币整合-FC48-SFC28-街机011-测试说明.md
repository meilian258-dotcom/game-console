# 方块电玩：电视、投币与设备适配测试版

适用目标：Minecraft 1.21.1 / NeoForge 21.1.236 起的 21.1 系列 / Java 21。
配套版本：FC 0.31.0-alpha.48、可选 SFC 0.1.0-alpha.28（含原 core9）、可选街机附属 0.1.1。
本文是本地测试包说明；实际构建结果、文件名和 SHA256 以包内验证结果为准。未安装到玩家实例或服务器，未发布线上版本；没有新增 ROM、BIOS 或个人存档。

## 安装与保留数据

1. 退出游戏并正常关闭服务器，备份世界、配置和个人存档。
2. 将 ZIP 解压到新目录，不要直接把外层 ZIP 放进 `mods`。只安装所需 JAR：只玩 FC 用主包；SFC 加 SFC 附属；街机加街机附属。
3. 服务端和所有客户端使用同一套 FC48；玩 SFC 的两端配套 SFC28；玩投币街机配套街机0.1.1。旧同 modId JAR 移到实例之外备份，不叠放两个版本。SFC28 已包含 core9，不另装旧独立 SFC 核心。
4. 保留原 ROM、BIOS、存档、配置和运行库目录。新街机桥使用版本化 helper 文件，由街机附属内置来源安全补缺；旧 helper 不删除、不覆盖，未知冲突不强制覆盖。MAME、NeoGeo DLL 和 JNA 沿用原核验字节。
5. 真正执行普通原生街机核心的一端仍需 Windows x64；不是把 Windows DLL 变成 Linux 支持。服务端托管仍需服主明确开启。只接收画面的客户端与执行核心的机器职责不同。
6. GBA 本轮不改，原 GBA8 与三件运行库不在本更新包内。不要把旧 GBA 或历史大合集误认为这次新构建。
7. 重启后先在世界副本验收，不直接覆盖唯一正式世界。回退时成套恢复旧 JAR 与升级前世界备份：旧版不认识本轮新电视和游戏币。

主协议38，街机房间 `cabinet-room-6`、同步设置 `cabinet-sync-5`；源码兼容构造不等于旧客户端可混连。

## 新电视怎么用

创造栏“方块电玩”中新获取的电视调整为：原大 CRT 保留，加灰色双天线电视、红色长天线电视、2×2 液晶电视、3×2 液晶电视。

- 液晶点击地面/桌面放置带支脚版本，点击竖直墙面放置壁挂版本，不新增重复的壁挂物品。
- 液晶要预留完整的四格或六格空间；破坏任意组成部分按整机处理，只产生一台物品。未加载的区块不强制加载。
- 两台小 CRT 一格底座，天线是装饰，红电视天线高于一格，不额外占用一格方块。
- 灰电视独立电源键、右侧两枚小按键为音量；红电视小电源键，音量旋钮上/下半部为音量加/减。
- 液晶右下沿三枚按键从左到右为音量减、音量加、电源；电源灯开启变绿，屏幕照明/彩条/已有开机过渡沿用电视系统。
- 用原 AV 线连接主机和电视，Shift+右键断开。新红 CRT 补了独立 AV 口，原天线孔保留作外观；壁挂 LCD 使用短直角插头向下走线，避免穿墙。
- 游戏画面保持原有 4:3 比例，宽屏留黑边，不强拉伸。旧一格薄 LCD、旧宽 LCD、旧大型 LCD、旧红旋钮 CRT 不再列入新获取入口，但旧注册、模型和世界设备仍保留。

## FC 与小霸王

FC 两侧改为真正的手柄收纳凹槽，取走后能看到空槽；领取/归还点击区域对准实体模型。这里不是背包里的空格。

FC 主机后端为同轴样式插口/插头，电视端仍接三色 AV。继续使用同一根线，不增加一种重复线材；这只是硬件外观与游戏内连线适配，不模拟真实 RF 调制解调。

小霸王新增独立 RESET。新摆放为 2 宽×1 深；已有四格和早期单格设备保留其原布局，不自动缩改旧世界。主机、卡带、盖板、手柄和线缆使用对应布局，不能仅缩外壳留下旧碰撞。

## 街机投币

适用本模组当前通用单人/双人街机选择原生街机后端的游戏；不是对 FC、SFC 家用机收费。Native 附属历史独立机柜仍保持历史免费行为。

1. 新摆通用街机默认实体投币，旧世界无投币标志的街机保持免费。
2. 管理员在创造模式下持调试螺丝刀、整组空闲时设置免费/投币；数据线相连两台按组管理。运行中不偷换已开始的本局规则。
3. 先启动游戏并加入席位，等待游戏就绪；持银色游戏币右键正面的投币口。一枚发送一次该游戏原生投币输入，由原游戏决定点数、共享点数或续关价格，不另造生命系统。
4. 银币没有本轮新增合成配方；先由创造栏/管理员发放。不对玩家设定货币兑换或现金购买。
5. 未入座、旁观、免费、未就绪、越距、保护拒绝、队列忙不扣币；创造模式投币也消耗实体币。长按不会连续扣币。
6. 收费游戏屏蔽普通键盘/实体手柄 SELECT 的免费投币输入；普通功能键和方向不变。三种同步模式使用各自的权威投币路径。
7. 已接纳的投币与普通松键分开：打开菜单/失焦要立即松开游戏方向，但不能抹掉已扣币脉冲。旧附属缺保币松键能力时明确拒绝收费，不以排队零输入替代而产生粘键。

边界：投币成功只表示该输入被接纳，不是读取了商业游戏内部点数。突然离席/停机/核心崩溃/断线与扣物品之间不存在跨进程原子保证，不自动猜测退款或重投，以免重复发币。修改过的音画主持客户端仍是可信客户端架构，不能当作防作弊经济系统。

## 工作台 GC-021 反馈

空手右键 FC 外壳不再自动打开调试菜单；原实体电源、重置、卡带与手柄交互继续有效。高级设置使用调试螺丝刀与原指定管理员入口。

“托管帧率 / 网络”是独立页面，避免塞进遥控器的日常电视选项：

- 管理员 OP2 可以调整全服务器托管视频投递上限 20 / 30 / 60 FPS，默认20，持久到 `piq-sync-server.toml`。
- 这是视频投递上限，不改变模拟器游戏速度或音频，不承诺所有机器、带宽和 TPS 下都达到60。客户端收到确认才显示已保存；过期设置要求刷新。
- 可打开本次客户端运行期间的网络悬浮窗，默认关闭。不改玩家其他设置。
- 显示当前 FC、SFC 家用和共享街机会话所统计的载荷上传/下载 KiB/s，位于 Minecraft 网络压缩之前，不含 TCP/IP 或其他 MOD，不是整服网络抓包；旧独立 SFC core9 协议不计。
- 视频 FPS 是逐路完整接收帧，不是 Minecraft 渲染 FPS。本地输入同步不接收视频，同机内存连接不会伪造网络流量。
- 托管积压视频有界并淘汰过旧画面，避免低 TPS 后追播旧视频。仍需实机验证不同核心的音画表现。

## 建议验收顺序

- 新世界：四种电视桌放，液晶四朝向壁挂，旧大 CRT 对照；按钮、指示灯、无信号、开关机、FC/SFC画面、线头、邻墙遮挡。
- 世界副本：已有旧电视/四格小霸王加载、使用、拆除无丢失；新小霸王确实只占2×1；液晶任意部件拆除、爆炸/取消放置、跨区块卸载不多掉物品。
- FC双手柄分别取还，空槽不穿模，第一/第三人称及反方向摆放都正确；新小霸王 RESET 不误触 POWER。
- 投币：三模式、单双人和连线组，快速点击/长按、主副手、库存仅一币、免费机、未入座、低 TPS、打开菜单/失焦立即松键但不丢币、断线重入、旧附属拒收。
- 权限：普通玩家不能改投币规则或托管上限；保护插件阻止实体设备操作时不扣币、不留下半个电视。
- 托管：20→30→60 运行中切换，不加速游戏；普通玩家只读，过期页/断线不误报保存；HUD数字随真实网络变化。

自动几何、纯逻辑、源码护栏和完整构建不等于以上 Minecraft、双客户端、保护插件与长时间体验已验收。待用户人工验收的项目会保持“待验收”，不会自动设为稳定版。
