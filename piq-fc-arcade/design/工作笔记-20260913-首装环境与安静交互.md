# 首装环境与安静交互

2026-09-13；像素匠；候选 FC37。

## 本轮范围

运行环境检查、随包离线安装；普通右键提示静默；只保留电源和重置命中悬浮提示；家具合入游戏机创造栏；单独玩家教程。

## 边界

不发布二进制下载端点，不修改用户正在使用的 HMCL、服务器或存档。不修改同步协议、模拟器输入、模型与座位逻辑。ROM 和 BIOS 必须自备；不把服务器 ROM 分享通道用作 DLL 下载通道。

外部运行库固定目录分别为 piq-native-arcade/runtime、piq-native-arcade/runtime-snapshot-v1、piq-gba/runtime。FC/SFC 核心内置。离线包放 piq-runtime-packs/piq-runtime-pack-v1.zip；只安装校验通过的缺失文件，冲突文件要求用户备份后自行处理。

## 协作

- root：运行环境 GUI、版本、冻结、教程、打包与维护记录。
- furniture_common：纯 Java RuntimeCatalog/RuntimeInstaller、安全回归。
- furniture_render：提示和悬浮检查、DeviceNotices 错误汇总。
- furniture_models：创造栏最小改动、运行库来源许可核对、独立交付审计。

## 验证状态

FC、Native、SFC Home 全量 check/jar 已通过，最终数目和身份以新目录冻结证据为准，不沿用旧版的实机测试结论。GBA 按现有方式由新 FC API 编译并合入既有许可与运行库元数据；SFC 两个模块继续合为一个发行 JAR，内置 SFC core7 不变。

## 已实现

- FC37 提供运行环境设置页：缺库时主菜单自动提示一次（每次游戏进程最多一次），按所装附属检查；只 FC/SFC 时明确不需要离线包。只有退出世界且无连接、无集成服务器时允许用户点一键补齐。不静默下载安装，不写“已读”标记。
- 固定九文件校验包：先暂存并全项 SHA256 校验，再以不覆盖硬链接提交；已有合格文件复用、不同版本整次拒绝。保留暂存硬链接见证，回滚只删除仍与本轮见证相同的文件；防止把竞争写入者文件当作自己的删除。拒绝非白名单 ZIP 条目、重复、路径穿越及危险路径。
- 主菜单退出/ESC 在安装中先请求取消并等待清理，再返回；世界内仅检查，未把服务器共享游戏通道改作 DLL 传输。崩溃/断电不保证跨文件原子提交，后续检查复用合格文件，不自动删除未知旧暂存。
- DeviceNotices 汇总异常详情到日志和有限内存；客户端短 toast 避免长路径刷屏。精确白名单静默本模组普通交互说明，真实邀请/确认/上传和下载进度、未知反馈保留。只显示电源/重置硬件命中悬浮提示，业务清理和联机协议不变。
- 家具创造栏仅调整注册显示：原有 18 项后加入 22 个家具，取消独立家具 tab；方块、实体、物品 ID 及模型/资源不变。
- 独立 HTML 教程包含首装、ROM、写卡权限/存档、控制器、旁观联机、光枪、线材、GBA、家具与排错。文档技能所要求的捆绑 Word 渲染器不可用，未产出未经验证的 DOCX；改为无外部资源 HTML，文本经第二代理对照代码校核。

## 验证边界

- 真实固定离线包安装测试仅在自建临时树执行，不加载外部 MAME/mGBA DLL 或运行 helper；FC 既有 packagedRuntimeSmoke 会使用其内置 Wasmtime JNI。
- Screen 探针使用实际 Minecraft ESC 派发/按钮对象，但导航和连接状态是受控测试替身，不是启动 Minecraft；不把矩形布局断言描述成游戏截图或实机验收。
- HTML 已校验闭合结构、目录锚点、离线依赖和版式规则；浏览器文件 URL 被工具策略拒绝，未绕过，也没有声称完成浏览器渲染目检。
- Windows x64、本地 NTFS/硬链接能力是离线安装前提；没有跨平台、第三方输入钩子或真实多人网络全覆盖承诺。
