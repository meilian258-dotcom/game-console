# 方块电玩 · GC-018 交互与遥控器测试版

适用：Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21。目标版本：FC 0.31.0-alpha.45、SFC 0.1.0-alpha.26（合并旧 core 0.2.0-alpha.9）。本文件是测试说明，不代表已经通过玩家实机验收或公开发布审核。

## 安装与版本

本次更新包提供两份 JAR，均安装在实际客户端和服务端的 `mods` 目录。FC 主协议从 35 升为 36，服务器和所有玩家必须一起更新，不要新旧混连。

- `game_console-0.31.0-alpha.45.jar`：主模组。只玩 FC 时只需这一份。
- `game_console_sfc-0.1.0-alpha.26.jar`：选用 SFC 时同时安装；已经包含 SFC core 0.2.0-alpha.9，不要再装独立 `piq_sfc_home` / `piq_sfc_arcade` 旧包。
- 街机附属 0.1.0、GBA alpha.8 沿用原配套，不是本次重新构建成果。街机的数据线音效由新版 FC 共享逻辑提供。

更新前备份世界、配置与存档，把旧 FC/SFC JAR 移到实例外备份；同一 MOD ID 只留一版。不要删除 ROM、存档或已匹配的运行库。替换后完整重启客户端和服务端。只使用交付目录的冻结成品，源码 `build/libs` 是中间包，不用于安装。

没有新运行库依赖；FC/SFC 继续使用原内置环境。本包不含商业游戏 ROM、BIOS。首次选用街机/GBA 的额外运行环境仍按对应附属原指南准备。

## 遥控器怎么用

手持“电视遥控器”，瞄准 8 格内的电视右键，打开当前设备设置。菜单显示目标坐标，设置须等待服务器确认后才算保存。

| 选项 | 范围与规则 |
| --- | --- |
| 扫描线 | 当前电视 |
| 开关机动画 | 当前电视，可关闭；默认开启 |
| 使用者文字（FC） | 当前连接的 FC 占用标牌；SFC 家用机原本无此标牌，选项禁用 |
| 加入需同意 | 当前连接的 FC/SFC；默认开启，仅 OP 2 级管理员修改；不绕过席位、游戏人数、多人开放或领地保护 |
| 无信号提示音 | 当前电视的彩条哔声；默认开启 |
| 音量 / 静音 | 当前电视；静音保留原音量，不改变其他电视 |
| 键盘方案 / 实体手柄设置 | 跳转既有个人设置，不修改其他玩家的按键 |

存档设置仍在卡带相关菜单，遥控器不能读写或删除存档、上传 ROM、切换同步模式。动画/声音是同一台电视的共享偏好；本版不另设个人动画覆盖。按钮、插卡和接线的机械声遵循 Minecraft“方块”音量，不随电视静音一起关闭。

拿遥控器不等于获得管理权限。每次请求重新核对实际手持物、电视和主机身份、连接、距离与保护事件；移开目标、换手、离开、拆线或超时后请关闭并重新瞄准打开。菜单有约一分钟有效期；打开个人按键设置较久后返回也可能需要重开。

## 手柄、卡带与文字

- FC P1/P2、SFC：Q 丢弃、从背包向外丢弃均视为归还原主机，不产生可传递的掉落手柄。
- 持原手柄点击原插口/停放位置：归还该端口；不误收另一位玩家的手柄，不把归还又当成自动领取。
- 未开游戏也能取还；保留 6 格超距回收、原主机身份和租约校验。自动超距/失效回收不播放一连串提示音。
- 归还手柄不重启主机、不改存档；开菜单只释放按键，不归还手柄。
- FC 卡带及卡壳调整第一/第三人称朝向，使正面自定义封面可见；不改模型 UV、封面图片、GUI 或世界中的插卡朝向。
- FC/共享街机“正在使用”标牌固定朝向机器，不再追随观察者旋转；排行榜不改变。

## 电视与音效

CRT 开机约 0.7 秒，柔和横线向上下展开；关机约 0.35 秒低亮余辉收束。LCD 使用渐入渐出，不闪白屏。FC、SFC 与彩条共用过渡，首次进服/区块加载不重播历史开机动作。关机不缓存最后游戏帧，而是短暂灰色余辉。

电视状态：

| 状态 | 显示 |
| --- | --- |
| 电视关闭 | 过渡结束后黑屏 |
| 电视打开，主机关机或未连接 | 彩条；按遥控设置决定是否哔声 |
| 无卡主机已接电视，先开电视、再按主机电源 | 深色“未插卡”；不创建游戏会话，无哔声 |
| 游戏运行且信号有效 | 游戏画面 |

“未插卡”是临时空机待机。再次按主机电源关闭；插卡退出待机，仍需按主机电源启动游戏。电视关机、拆线、区块卸载或退出世界后清理，不自动恢复游戏。这一状态不能获得输入权限或写存档。

新增轻量原版机械声：电源、重置、电视音量按钮、插退卡、显式取还手柄/光枪、AV/光枪支架/街机数据线接拆。只在服务端确认事务成功后广播一次；拒绝、失败、状态包、进服或区块加载不触发。没有添加厂商开机音乐。

## 建议按这个顺序验收

1. 备份测试世界，两端更新；旧卡带、旧存档正常打开，不丢设置。
2. FC/SFC 分别测试 P1/P2：关机取还、运行取还、Q、背包外丢、原插口归还、超 6 格回收；朋友的手柄不受影响。
3. CRT/LCD 开关机、快速切换、关动画；断线彩条、空机“未插卡”、插卡再启动；已开机设备重进世界不重播动画。
4. 按钮、插退卡和三类线接拆只响一次，失败不响；电视静音/音量不影响别台。
5. 遥控器改扫描线/音量/提示音并重进保存；普通玩家不得改加入确认或越过领地；拆线/换机器后旧菜单不得改新设备。
6. 双人 FC/SFC：默认申请加入；管理员关闭确认后仍按原多人门槛和快照握手加入；退出、断线与旁观不回归。
7. FC 自定义封面第一/第三人称、左右手；使用者文字固定朝向，开关隐藏不碰排行榜或旁边机器。
8. 街机原同步、GBA 原功能做基本回归，本轮不宣称这两项已经重新实机验证。
