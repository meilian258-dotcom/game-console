# SFC：线材与肩键修正版

打开 `SFC_日版双手柄_线材肩键修正版.bbmodel`。本版包含前一次机壳转角修复，并进一步调整两只手柄的线材、出线胶套与四个肩键。旧模型、旧ZIP均保留。

## 本次修复

- 线材由每根9段粗折线改为15段细线，端头顺着插头／手柄胶套接入；中段下垂至桌面附近，取消横折后突然抬高的尾端。
- 每个转弯不超过22.5°，线材截面从raw 0.22改为0.14。全部仍为Minecraft合法单轴旋转方块，并非任意网格或真正圆管。
- L/R肩键后移至手柄后缘，使用三段弧形厚键帽包住侧缘，不再是面板上的薄条；固定嵌座降低，给按压留出空间。
- 出线胶套缩细并逐级收口，线芯两端都有实质连接。

主机、卡带、手柄主体与其他按钮未改。主机仍半格宽；整套约0.80格宽、0.94格深、0.32格高，包络与前版相同。现有872个方块、34个组。

## 单张皮肤与动画分组

唯一皮肤仍为 `SFC_单张UV.png`（2048×2048），PNG字节完全未改。非线材部件的UV坐标保持原样；新增线段只在旧的黑色线材UV区域内重新划分。线材是纯色微型UV，不适合复杂图案。使用本版 `UV_透明线框.png`、`UV_部件索引.json` 辅助修改。

四个肩键保留原group名称、UUID与7个可动元素，轴心已随位置校准。请使用本版 `按键动画映射.json`，每个肩键建议Y方向按压−0.035模型单位。

已在Blockbench中临时模拟四个肩键按压并恢复，确认帽顶不会被固定嵌座盖住。这是模型位置测试，并未绑定游戏内按键，也没有添加运行时动画。

## Minecraft文件

`minecraft_assets/assets/super_famicom/` 提供静态Java模型和PNG；模型标识仍为 `super_famicom:block/super_famicom`。不是可直接启用的完整资源包；放置、碰撞及游戏功能继续使用你的模组配置。本次未修改服务器，未进行游戏内实测。

预览均来自实际Blockbench模型。几何、连接与UV的检查报告位于 `tools/`。
