# SFC独立卡带

打开 `SFC卡带_独立版_单张UV.bbmodel`。此文件是独立卡带，不包含主机或手柄；之前的SFC整套模型与压缩包未修改。

## 大小与结构

卡带延续主机组合版的比例，没有额外放大：宽5.12、高2.9、厚0.803模型单位，约0.32格宽、0.18格高、0.05格厚。模型中心在X/Z=8，导轨底面Y=0。

保留原卡带壳体、倒角、握持棱和正面标签。原先埋在主机内的黑色插脚已补成灰色导轨、前后唇、PCB与双面装饰金手指。金手指数目是视觉简化，不是电子引脚复刻。

共86个方块、5个组：shell、front_label、back_label、connector、contacts。均使用Minecraft Java支持的单轴旋转，没有网格元素。

## 换游戏标签

`SFC卡带_完整UV.png` 是唯一皮肤，画布1024×1024，所有部件都在这张PNG上。

- 正面游戏标签：左上角像素位置X=32、Y=32，宽616、高278。保持画布尺寸，把自己的游戏图覆盖在这个矩形内。
- `游戏标签_616x278.png` 是正面标签的独立编辑模板。只保存这张小图不会自动改变模型；完成后需贴回完整UV的对应区域。
- 背面标签：X=704、Y=32，宽260、高100。
- `UV_透明线框.png` 可作为辅助图层，导出皮肤时隐藏。`UV_部件索引.json` 和 `标签区域.json` 记录所有位置。

正面暂时沿用原SFC卡带的“16-BIT / GAME PAK”通用标签，没有添加具体游戏插画。UV下半部分为各方块的展开面。

注意：这是卡带专用的1024皮肤，与SFC整套2048皮肤的布局不同，不能直接互换整张PNG。

## Minecraft文件

`minecraft_assets/assets/sfc_cartridge/` 提供静态Java模型与PNG，模型标识为 `sfc_cartridge:block/sfc_cartridge`。这些是模组接入素材，不是可直接启用的完整资源包；家具/物品注册、碰撞与插卡逻辑需你的模组配置。本次没有修改服务器，也未在游戏内实测。

如以后需要把独立版放回原SFC模型的位置：所有卡带元素平移 `[0, 2.18, 3.711]` 模型单位即可恢复对应位置，不需缩放。此为建模坐标说明，不代表已实现动态插卡。

正面、背面和底部预览均来自实际Blockbench模型，检查报告位于 `tools/validation_cartridge.json`。
