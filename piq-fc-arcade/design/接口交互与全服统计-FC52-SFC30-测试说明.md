# 方块电玩 FC52 / SFC30 接口交互与全服统计测试版

适用：Minecraft 1.21.1 / NeoForge 21.1.236。2026-09-17。

## 安装范围

- 服务端和客户端同时更换 FC `game_console-0.31.0-alpha.52.jar`。
- 使用 SFC 时，两端同时更换 `game_console_sfc-0.1.0-alpha.30.jar`；SFC30 最低需要 FC52（新增共享物理接口动作）。不再额外安装旧 piq_sfc_arcade，core9 已内嵌原字节。
- 仅玩 FC/小霸王无需 SFC。街机附属 0.1.1、GBA8 本轮未修改，原成品沿用，不包含在此补丁 ZIP。
- 手动退出客户端、正常停服并备份世界/存档后，将旧同 ID JAR 移到实例外备份，再替换成套版本并完整重启。建议先在世界副本验收。
- 包内不含 ROM、BIOS、用户模型原稿或密钥；不使用工作区两张手柄草稿贴图。

## 新交互

FC、小霸王（含早期布局）、SFC：双手空着，从主机背面瞄准视频接口右键，即可拔线并按既有账本返还一次视频线。不能隔着主机前壳点击后接口。主机及电视两端都要有交互权限，电视区块需已加载。原有“持线 Shift＋右键设备”仍可用。

拔线会停止相连游戏，不是保存按钮。请先保存并退出，避免丢失最后片刻的进度。连线注册 ID 仍为 `piq_fc_arcade:av_cable`，显示名称统一改为“视频线 / Video Cable”，旧物品和连线存档不迁移。

FC 空手柄槽的背板及切面使用原机壳米白塑料材质；只改两份模型各24个面的UV，不增加红托边、不移动手柄、不修改贴图像素。

## OP 全服流量统计

需要 OP2 或服务器控制台：

```text
/gameconsole traffic
/gameconsole traffic watch
/gameconsole traffic off
```

第一条查询当前速率及本次服务器启动累计发送、接收和总量。watch 仅玩家可用，每5秒输出汇总；off 关闭该玩家订阅但不清空累计。最多64个订阅；断线、重连和撤销 OP 会移除订阅。服务端重启后累计归零，不写存档。

箭头为服务端视角：↑发给所有客户端、↓从所有客户端接收。按四个协议组显示：FC/学习机及公共协议、SFC家用、共享街机（SFC/原生/GBA等）、旁观公共流。共享街机/旁观协议无法仅凭包类型准确归属每台机器，因此不伪造机种或单台排行榜。

统计口径：已埋点的本模组压缩前载荷，以及双向旁观心跳；不采集包内容，不是网卡账单，不包括 TCP/IP、加密/压缩/协议头、原版及其他模组流量。旧 SFC core9 的独立协议不在范围内；同进程内存连接不构成网络流量。与客户端 HUD 的统计方向、范围不同，不能直接比较两个总数。

## 街机退出与模式限制

原生/共享街机设置查询会明确提示“仍在运行或退出收尾中”，有权限的玩家停留该页时约每2秒只读刷新一次（限初始约55秒，超时或过期需重开）。保留真实占用、存档和托管线程退出保护，不强行释放，不自动重发模式修改。

FC/NES 核心的旧街机柜仍固定本地输入同步；这不是等待问题。FC/SFC家用机的“玩家音画串流”控制链路尚未实现，用户已同意下一版专项测试，本版不解锁。不要将当前页面显示的三种模式理解为所有机型均已支持。

## 验证与验收

交付包的验证 JSON / 构建见证记录最终自动测试数量与哈希；自动回归不等于实机通过。离线模型预览不是游戏截图。

待用户验收：三机四朝向点击后接口；前壳/侧壳不误触；副手有物品不拔线；保护区域两端拒绝；断开/拆机/重连无重复返线；有卡带时先保存退出；创造/生存模式；FC手柄取还后槽内材质。OP命令需双端实测、普通玩家拒绝、撤OP停止订阅、重连/重启累计边界，并核对多台同时运行与旁观分发。街机退出收尾后设置恢复与真实模式可用性分别验收。

槽内材质、全服统计、接口拔线/改名及退出状态刷新待人工验收；玩家音画串流为后续计划，本版不标稳定。
