# FC71：SFC / FC 新设备加载崩溃修复

适用 Minecraft 1.21.1 / NeoForge 21.1 系列（构建21.1.236）/ Java21；替换 FC70 主包。本轮只修公共初始化校验，不替换模拟器核心、联机协议或设备资产。

## 安装

1. 正常退出游戏；多人服务器需由管理员安排停服更新。备份世界，先在副本验证。
2. 把旧 `game_console-0.31.0-alpha.70.jar` 移到 mods 外保留，放入 `game_console-0.31.0-alpha.71.jar`。同一 MOD 不叠装。多人客户端和服务端统一主包版本；单人只替换客户端 mods 中的主包。
3. 现有完整 SFC38、街机0.1.3不需要更换。若安装PvZ附属，必须把prototype.1/2更换为prototype.3：旧附属的兼容上限排除了FC71。保留FC71，不回退主包；PvZ3保留v2性能优化和存档。此前“PvZ2不用换”为错误说明，历史FC71压缩包中的旧说明以本条勘误为准。SFC38应使用此前完整合包，不叠装额外旧SFC核心。不要卸载SFC后进入原世界。
4. `main.pak` 路径、运行库、卡带/机器/个人存档、设备连线与配置均保留，不删除任何保存目录。此版本没有迁移或清档操作。

两端安装依据：主包共同注册设备方块/物品/实体，服务端管理会话及保存、客户端显示输入；不是根据依赖 side 猜测。SFC38调用主包 HomeEndpointBlockEntity / HomeSyncSettings，因此此次修复位于FC主包。

## 修复内容

用户18:03:59放置SFC时，`SfcHomeConsoleBlockEntity.onLoad → HomeEndpointBlockEntity.onLoad → HomeSyncSettings.placementMode → GameConsoleAdminPolicy.selectNewMode` 抛出 `Invalid console defaults`。

设备支持列表已包含 Netplay 的能力位8，但全局默认选择函数仍只接受旧三模式的能力掩码0～7。本次允许已知的四位能力掩码0～15；全局默认仍只接受自动/玩家串流/本地输入同步/服务器托管，不会自动选择实验Netplay。未知位、非法默认值仍严格拒绝。不改权限、不强制切换已有设备设置、不将错误简单吞掉。

该公共路径也供FC新设备使用；修复同时覆盖新放置、尚未完成默认初始化的设备加载。已有初始化标志和保存格式不变。
