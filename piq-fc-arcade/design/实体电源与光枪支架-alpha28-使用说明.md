# 实体电源与光枪支架 · alpha28 测试版

本包是 FC28 + 合并 SFC16 + 原生街机10；只交付文件，没有自动安装。请先备份实例，再退出游戏更换。服务端和每位玩家必须一起升级，不能混用旧 FC/SFC 协议。

## 放什么文件

`mods` 中放本包的三个 JAR：

- `piq_fc_arcade-0.31.0-alpha.28.jar`
- `piq_sfc-0.1.0-alpha.16.jar`
- `piq_native_arcade-0.1.0-alpha.10.jar`

旧版同名模组移到 `mods` 之外备份，不要并存。SFC16 已合并 SFC 模拟核心，不要额外放旧 `piq_sfc_arcade` 或 `piq_sfc_home` JAR。

`piq-native-arcade/runtime/piq-native-helper.jar` 位于游戏实例根目录的对应子目录，不能放进 `mods`。原生街机10与 helper v3 和上一完整测试包相同，已有相同文件可以保留。本包不包含游戏 ROM、BIOS 或用户存档。

## FC / SFC：开机和控制分开

1. 放主机与电视，使用 AV 线连接，再插入已写好游戏的卡带。接线和插卡不再自动开局。
2. 瞄准电视的实体电源键右键。新放电视默认关机；开启且无运行信号时显示静音彩条。
3. 瞄准主机实体电源键右键。主机加载后电视显示游戏，但不会自动发手柄，也不会抢键盘/实体手柄。
4. 右键停放的 P1 或 P2 手柄领取对应控制口。开机者可直接领取；其他玩家会向开机者申请，批准后同步加入。
5. 拿着手柄右键主机机身放回。游戏继续播放，另一名玩家和旁观者不会被退出。
6. 右键主机电源键，或右键电视电源键关电视，都会结束该连接上的整局并撤销控制。请勿把关电视理解为“只隐藏画面”。

瞄准实体按钮时，准星下方有简短提示。普通电视机身/屏幕右键不再开始游戏或归还手柄。主机机身归还与按钮操作分开：要归还手柄请避开电源和重置键。

FC/SFC 的 RESET 键右键重置当前游戏；保留已借出的手柄，清旧输入和旧加入事务，从新一局同步开始。小霸王模型没有独立 RESET，使用 **Shift+右键电源键**。其余原有 Shift+右键退卡操作保留。

电视音量范围 0–100，每次调整 10，并仍受 Minecraft 主音量、方块音量及距离衰减影响。大 CRT 使用下排靠右的两颗小按钮；小复古电视使用音量旋钮上半加、下半减；液晶电视在原电源键旁补了两个小音量键。瞄准提示可区分。

## 光枪和支架

1. 放置“光枪支架”，拿已有光枪右键放入。支架不会赠送或复制光枪。
2. 拿“光枪连接线”，先右键支架，再右键关机的 FC 主机。两端同维度，距离不超过 16 格；选择有效期 60 秒，操作时需要两端权限。
3. 开电视、插入《打鸭子》等支持光枪的 FC 卡带，再按主机电源。
4. 空手右键支架取出原枪。其他玩家仍需开机者批准。左键射击，准星瞄准连接的电视实际游戏画面；电视外开枪也会作为屏外射击输入。
5. 拿原枪右键原支架归还。只撤销枪的输入，本局继续运行。

支架连接在开机时选择光枪核心；不是所有 FC 游戏都支持光枪。换普通手柄游戏时，先关主机，再拿连接线 Shift+右键支架断线。光枪使用硬件第二口，与普通 P2 手柄互斥。审批未通过、断线或关机时，手里的实物枪仍是原来那一把，但不能继续输入；把原枪放回支架即可，不会生成替身。

## 联机与保存边界

主机开机者负责后台运行，控制口可以全部空着；附近玩家不必领取手柄也能旁观。开机者可在同一维度走动，但需保持在线，且主机/电视/AV 对应区块有效加载。开机者退出、换维度、核心出错或硬件失效会安全停机。本版没有离线运行或宿主迁移。

每人最多一台 FC 和一台 SFC 后台；实际控制输入仍互斥。手柄操作者受距离、权限、实际持物和当前租约检查。重置、关机影响整局，请与其他玩家沟通。

FC 实体电源自动继续原机器进度，不弹个人槽选择；旧个人存档没有删除，也不会自动取用或覆盖。重置不读回旧快照。保存以服务器已确认状态为准，不保证最后一帧已落盘。SFC 保持自身存档格式，本次不进行用户存档转换。

## 建议验收

先在备份或测试世界走一遍：电视彩条 → 主机后台开机 → 取 P1 → 好友申请 P2 → 归还 P1 后 P2 继续、旁观不断 → 重置 → 关电视结束。再测试光枪的放入、连线、取出、审批、屏内/屏外射击和归还。

代码构建、最终 JAR 的核心/状态/协议/几何验证与真实 Minecraft 交互不是同一种测试。本包的自动验证结果见 `checks/`；游戏内按钮点击、保护插件、真实网络延迟、视觉与实体手柄仍需实机验收。
