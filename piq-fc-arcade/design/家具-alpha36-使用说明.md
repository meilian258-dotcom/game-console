# FC36：长条凳与折叠马扎测试版

## 更新与查找

只更新 `piq_fc_arcade-0.31.0-alpha.36.jar`；客户端、朋友和服务器使用同一新版。SFC20、Native12、GBA4 与模拟器运行库不需要更新。先退出游戏/停服并备份世界和旧 FC JAR，同一 mods 目录只保留一个 FC 版本。此包没有自动安装、发布或关机操作。

在新创造栏「PIQ 木制家具」可以找到 11 种木材的长条凳和马扎。生存可按下方配方制作。新增家具会写入新注册ID和配对数据；摆放后不要直接把该世界降级到FC35，回退请使用更新前备份。不要删除世界、存档或 ROM 文件夹。

## 使用

- 长条凳保持原模型两格长、约半格高，需要相邻两格空位。空手右键靠近的半边优先坐对应座位，空位时自动选另一个座位，最多两位玩家。
- 马扎保持原模型小尺寸，一位玩家；空手右键坐下，Shift＋空手右键展开/收起。有人坐着不能折叠，收起时不能坐。两种状态是静态模型切换，不是布料折叠动画。
- 坐下和操作马扎时主手、副手均须为空；坐下后可切换手持物品，不会更改模拟器按键。按默认潜行键 Shift 离座，寻找附近安全落点。
- 马扎的木种、展开/收起状态会随放置、掉落、再放置和重进保留。长凳任一半正常拆除只产出一件对应木种长凳，两半一起清理，不提供单独半凳物品。
- 为避免越过领地保护或强行加载区块，主动拆长凳时若另一半尚未加载，会暂时拒绝拆除；靠近另一半使其加载后重试。破坏、退出或卸载会清除临时坐席，不保存离线占位。

家具不接管 FC/SFC/街机/GBA 输入、游戏会话或存档。坐着能否够到机器仍遵守原交互距离及有线手柄距离，不能借坐席远程开机。

## 木种与配方

支持橡木、云杉木、白桦木、丛林木、金合欢木、深色橡木、红树木、樱花木、竹、绯红木、诡异木，共 22 种家具物品。

长条凳：同一种木板 3 个、木棍 2 根，产出 1 件。

```
木板 木板 木板
木棍 空格 木棍
```

马扎：蓝色羊毛 1 个、对应木板 1 个、铁粒 2 个、木棍 2 根，产出 1 件。

```
空格 羊毛 空格
铁粒 木板 铁粒
木棍 空格 木棍
```

每个配方明确对应木种，长凳的三块木板不能混用。木棍使用原版通用木棍，不参与木种判定。布带保持原模型藏蓝色，铆钉保持金属色，不会被木种染色。

## 原版材质与模型处理

木架通过 `minecraft:block/stripped_<木种>_log` 及 `_top` 引用去皮原木侧面/端面；绯红木、诡异木为对应去皮菌柄，竹为去皮竹块。侧面按构件长度方向重新映射UV。资源包修改这些原版材质时家具跟随，只有木板材质被修改而去皮原木没改的资源包，不会使木架跟着木板变化。

渲染使用当前原版方块贴图图集的sprite，资源重载后重新取材质；不是把原版图片复制进自有PNG。缺少对应去皮材质时优先退回同木种木板。马扎布/金属沿用原模型的独立细节图集，旧游戏机的整张PNG换肤功能没有改动。

来件马扎横木端盖有共面重复面。本版对木材部件进行体积裁剪和共面单一归属，保留端盖轮廓、法线、原尺寸和两种状态的落地高度，不靠纯色遮盖重叠。布带没有重画；离线同视角对比确认织带细缝原模型已有。

## 测试边界与建议验收

本包是测试版，离线预览不等于 Minecraft 游戏截图。自动化检查结果随包 `checks/` 提供，真实游戏中的坐姿、多人交互、第三方领地/动作模组和光影组合仍需验证。

建议先在备份测试世界检查：

1. 四个朝向摆放长凳，两位玩家各自坐下/离座，再分别拆左、右半边，确认只掉一件、无残留占位。
2. 马扎展开/收起、有人时拒绝折叠，折叠后打掉再放回，检查木种与折叠状态。
3. 在区块边界摆长凳、离开再回来；坐着退出、断线后重连，确认不残留座位。
4. 切换修改去皮木材的资源包并按 F3＋T 重载，确认木色/木纹跟随，布/金属和旧游戏机皮肤保持原样。
5. 坐着拿手柄玩现有机器，检查原键位和距离限制；测试同一游戏重复启动仍复用缓存，不恢复旧重复上传。

本版没有进行真人双机或完整 Minecraft/光影实机验收，不能以测试断言数量替代实际游玩次数。
