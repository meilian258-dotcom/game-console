# Netplay 存档：FC76.21 / 完整 SFC42 / 街机1.5.3

适用：2026-09-28，Minecraft 1.21.1、NeoForge 21.1.236、Java 21。原生 Netplay 运行端为 Windows x64。本地测试候选，尚未完成 Minecraft 真人多人/公网弱网/长时验收，不标稳定。本说明取代旧版本的“Netplay 不保存”描述；其余模式与旧保存保持。

## 安装组合

双方统一更新主包 `game_console-0.31.0-alpha.76.21.jar`。使用 SFC 时同时更新**完整** `game_console_sfc-0.1.0-alpha.42.jar`（含旧 core9，不额外装薄包/重复核心）；使用街机附属时同时更新 `game_console_arcade-0.1.5.3.jar`。未安装的附属不必新增。旧 SFC41/街机1.5.2 不可与新主包混用，相关协议/保存授权已变化。其他附属沿用经依赖检查的现有版本。

安装端依据：主包与两附属均包含服务端会话/授权/保存协议和客户端输入/画面/菜单，不能只改客户端；服务端不运行本轮原生核心。先正常退出游戏、安排停服、备份实例/世界/游戏目录，将旧同 ID JAR 移到实例外保留，再替换双方 mods。只把 JAR 放进 mods，源码/说明/ZIP 不放。

## 怎么使用

| 机型 | 存档归属/入口 | 默认与边界 |
|---|---|---|
| FC（含光枪） | 沿用卡带编辑器的个人槽 / 实体卡带 / 不保存 | 尊重原卡带设置；个人槽属于开机玩家，不属于加入者 |
| SFC 家用机 | 卡带编辑器 → `Netplay 存档：不保存 / 个人 / 卡带` | 默认卡带；个人按开机玩家+游戏，卡带按实体卡带+游戏；不是机器存档 |
| FBNeo 通用街机 | 关机空闲时，管理员在街机配置 → 同步与网络 → `存档：不保存 / 个人 / 机器` | 默认不保存；个人属于开机玩家；机器属于通讯线主柜，按游戏隔离 |

开机前设置归属；游戏启动先读取服务器确认过的进度。运行中每约 **30 秒**保存一次检查点，也可进入设备的网络页面/管理终端网络诊断 → 流量页 → **Netplay 存档…**，由主持点击“保存”。只有服务器完成校验、落盘后才显示“已保存到服务器”，按钮点击/发送成功不等于保存完成。

正常关机尝试最后一次保存；期间请等待“已保存”后再断开服务器。直接断网、结束 Java、停服或崩溃无法保证最后几秒进度，最多只能依赖之前已确认的检查点。加入玩家与旁观不能代写；多人房间共用主持选择的这份进度，不会各自写一份。

切换存档策略不迁移、不删除旧档。个人模式换开机玩家会用该玩家自己的进度；卡带模式换主机仍随卡带；机器模式更换通讯线主柜会改变归属。运行中不提供倒带读档，重开游戏才恢复。

## 保存内容与旧档保护

- 检查点包含核心完整状态及核心实际暴露的电池 SAVE_RAM、RTC；并非所有游戏有 RAM/RTC。FC 电池测试已验证 8192 字节；SFC/FBNeo 测试游戏没有暴露这两区，不代表所有游戏都没有。
- FC Netplay 使用独立 `nes-netplay-v1` / `nes-netplay-zapper-v1` 身份，沿用原个人槽/卡带管理。不会把 WASM、旧本地同步存档当作可直接互换的 Netplay 档。
- SFC 与街机新档在服务器世界 `game-console/netplay-saves/` 下按归属、核心、游戏隔离；旧 SFC 本机恢复备份保持独立。备份应包含整个世界及原游戏目录。
- 核心/配置/ROM/BIOS 身份、校验和、大小、事务顺序和主持连接均校验；异常文件拒绝自动加载，不用空白进度覆盖。原子写入保留上一份 `.previous`，不是无限版本历史。
- 街机完整状态可能包含币数、游戏内设置，不是独立 PGM/DIP/NVRAM 维护档实现；不能声称满足“所有 PGM 设置独立保留到换游戏”。公用街机因此默认不保存。
- 管理终端既有存档清理/列表是 **FC 个人存档**；SFC/街机本轮仅有策略选择、手动保存/状态，不新增全服历史存档浏览、回收站、批量保留周期或旧格式转换。服务器需自行保留世界备份。

## 共用逻辑与限制

FC、SFC 家用与 FBNeo 共用主持保存通道、有限队列、分块 ACK、超时、断线回收和本机 PNP7 桥；保留 FC76.20 的 PRE_FRAME 前最新输入采样。Netplay 主协议为4、保存通道1、机柜同步10、SFC家用12；PNP7 为8个输入字，不能用旧 PNP6 EXE 替换。旧 MAME、GBA 未新增 Netplay，未改为 JNI。

本轮没有新增需要全服统一的可调参数；原街机关机与显示距离仍由管理终端 → 街机全服统一覆盖。30秒是内部检查点周期，不是新的每台机柜倒计时。
