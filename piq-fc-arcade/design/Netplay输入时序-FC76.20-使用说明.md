# Netplay 输入时序优化 · FC76.20 候选

日期：2026-09-28；适用 Minecraft 1.21.1、NeoForge 21.1、Java 21；原生 Netplay 客户端为 Windows x64。作者：像素匠。

## 改动与适用范围

修正公共桥读取输入的时机：原来输出画面后先读取输入，再等待下一帧；现在等待后、RetroArch 记录本帧 Netplay 输入前读取，减少等待期间的新按键额外落后一帧的机会。没有加速游戏、关闭回滚/CRC、降低权限或放宽队列/带宽限制，也没有开启 Run-Ahead 或迁移 JNI。

- FC、SFC 家用、FBNeo 街机使用此公共路径。不是只针对某一款 FC 游戏。
- 串流、本地同步、电脑 Flash/PvZ 不改；不增加 GBA/MAME 原先没有的 Netplay 能力。
- 内部本地 IPC 为 PNP6/PNPI；公开 Java 接口和 MC `netplay-3` 不变。EXE 与 Java 必须来自同一主包，不要单独替换原生 EXE。
- FC76.20 从 FC76.18 隔离构建，保留其目录/Mapper 修复；不包含尚未验收的 FC76.19/SFC42/街机1.5.3 保存开发。不能将此包称为“所有 Netplay 存档已完成”。

## 安装与回退

先正常退出游戏/服务器并备份世界和现有 `game-console` 数据，再以本轮 `game_console-0.31.0-alpha.76.20.jar` 替换主模组；同一组件不能多版共存。服务器及参与测试的客户端统一版本，原附属保持现有兼容版本（SFC41/core9、街机1.5.2、GBA10、电脑/PvZ既有配套），不要误装工作区的未交付开发 JAR。

双方安装依据：主模组包含公共 Netplay 授权/会话/传输服务器逻辑和客户端 NetplayProcess；本次时序改动本身执行在客户端，服务端不运行原生模拟器。要求统一版本用于本次验收，并非宣称 MC 联机协议已升级或服务端 CPU 已得到实测改善。

回退时正常结束会话，将主包恢复 FC76.18；本轮没有存档格式变更、迁移或删除。不要删游戏、存档、运行库或临时目录来“修复延迟”。

## 怎么验收

在同一游戏、同一网络与相同帧率/画面设置下，对比 FC76.18 与 FC76.20 的 Netplay。主持玩家和加入玩家分别测试快速点按、持续方向后松开、同时操作、切菜单/失焦、退出再加入。先不开光影/录屏，避免混入渲染负载；串流可继续作为手感对照，但它与 Netplay 的链路不同。

原生隔离测量是“Java 输入 API → 本机收到核心响应画面”，不包含键盘采样、Minecraft 主线程/GPU、显示器或公网延迟；不能据此承诺玩家端必减固定毫秒数。公网抖动、回滚、核心本身延迟和渲染阻塞仍可能影响手感。

## 开发入口

FC76.20 与使用 PNP7/8 字和独立 `native-save` 的保存开发支线不能混装。没有完成所有历史核心二进制的公开对应源码审核，本包是本地验收候选，不是已完成许可审核的公开发行包。
