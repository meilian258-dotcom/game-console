# 方块电玩 · 附属能力声明模板

配套：[模组制作规范 v1](方块电玩模组制作规范-v1.md) · [功能制作说明](功能制作说明模板.md) · [验收清单](功能制作验收清单.md)。模板版本 1.0，2026-09-28。仅新增/改造模拟器或程序运行后端时额外填写；普通模型、物品、界面或修复不必填整套核心能力表。

复制到附属仓库填写，随每个候选版本更新。以下是**文档表单，不是现有配置文件或可被程序读取的 schema**；不得根据填表结果自动开放网络/管理权限。未填写项视为“待核对”，不得宣称支持。

## E. 生命周期、权限与预算

- 电源、运行、操作、观看四者的关系及启动失败处理：待填写。
- 会话代次、连接捕获、取消/迟到回调保护：待填写。
- 退出、关机、无人占席、再次开机规则：待填写；引用采用的策略，不复制一套冲突默认值。
- 操作/观看/绘制距离与声音衰减：待填写；远处主持的必要计算/发送如何保留。
- 谁可以选游戏、启动、占席、旁观、下载、上传、保存、管理：待填写；分别提供服务器校验位置。
- 全服强制/设备/核心/客户端配置优先级与并发冲突：待填写。
- 并发核心、队列、帧/状态/下载上限、超时与降级：待填写。
- CPU/内存/网络/FPS实测：环境、模式、设备/玩家/观众数、时长、结果；未测写待验证。
- 普通100格外玩家收到哪些基础信息、不会收到哪些重型内容：待填写并提供证据。
- 私有路径/凭据/内容正文日志防泄漏和临时目录回收：待填写。

## F. 测试、限制与交付结论

- 精确测试组合与测试内容来源：待填写；公开测试资产必须有分发权。
- 单元/契约测试：命令、结果、证据路径；未运行写明。
- 独立真实核心：命令、结果、版本和哈希。
- MC单机 / 专服多人 / 长时间 / 弱网 / 干净构建：分别记录，不相互代替。
- 使用 [验收清单](功能制作验收清单.md) 的逐项结果文件：待填写。
- 已知限制、实验项、阻塞项、偏离规范的理由：待填写。
- 本轮结论：文档 / 原型 / 候选待验收 / 已人工验收（写范围） / 稳定发行（须另有批准）。
- 人工验收者、时间、版本：未验收时留“未验收”，开发者不能替用户自动通过。
- 不包含的行动：未获授权的安装、部署、发布、重启均不得因填写此表而执行。
