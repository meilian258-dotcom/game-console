# 街机全服规则 · FC76.15

适用：Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21，主包 `game_console-0.31.0-alpha.76.15.jar`。仅街机，不改变家用FC/SFC、GBA和电脑的电源/旁观设置。

## 设置入口

OP手持管理终端，右键打开 → **街机全服** → **全服街机关机与旁观设置**。

- **最后一人右键退出立即关机**：默认关。开启后，只有最后一名正在操作的玩家主动右键退出，才关闭整组街机；主柜1P退出但副柜仍有人玩，不会关机。开机准备、旁观离开或暂时不按键不触发。
- **无人占席倒计时**：0～3600秒，默认60。所有操作席空闲后计时，任何一人重新入席都取消；0表示禁用倒计时。可与立即关机同时开启，作为离开控制范围等非主动退出情形的空席兜底。
- **不自动关机**：立即关机开关关闭，倒计时填0。物理电源仍可关机。主持断线、权限失效、设备被拆、区块卸载、程序故障等既有安全终止仍生效；这不是跨维度/离线托管或强制加载功能。
- **显示／旁观距离**：1～128格，默认16；球形三维距离。靠近关联任一屏幕可进入旁观；显示超距即停止绘制/纹理上传，旁观连接退出有4格缓冲，避免边缘反复连接。不是保证16格外零网络数据。

保存是全服街机覆盖，不是新机器默认值。旧机柜无需重放，尚未加载的机柜也会在以后使用时读取统一规则；不会扫描或强制加载所有机器。旧机柜NBT字段保留作兼容，但不再覆盖本页规则。机柜原“关机／屏幕距离”页只读，提示从管理终端修改。

真实规则变化时，活动空席街机的倒计时从保存时重新开始，有人在操作的机器不会被关掉。开启“立即关机”不会追溯关闭已空席的机器，只作用于之后的主动退出。重复保存相同值不重启计时。并发管理员修改使用修订号拒绝旧值覆盖，失败后刷新再设。

## 范围与性能

- 普通远处玩家不会仅因在线就加入街机运行/串流；旁观延续现有按距离授权与回收机制。
- 主持端仍承担核心运行，必要时给附近玩家发画面。主持走远后只跳过本机不可见纹理上传，不中断其他玩家的游戏。
- 同一房间主副柜任一屏幕在范围内，都可上传一份共享纹理；不可见的另一屏幕不绘制。
- 街机本地音量按最近屏幕距离衰减到0；不改变游戏内总线音量设置。
- 旁观缓存仍在4格缓冲内维持接收/必要解码，核心帧仍可能生成；不宣称整体核心暂停或零CPU开销。
- 全服规则只在玩家登录与规则修改时同步小配置，空席关机沿用席位事件维护截止时间，不新增附近玩家轮询。既有旁观发现检查未移除。
- Minecraft自身仍可能向加载区块范围内的玩家同步机身/基础方块状态；不能将“停止旁观”解释成“完全收不到机器信息”。

## 安装与兼容

服务器和所有客户端一起更新主包；新增 `arcade-server-rules-1` 网络载荷，不支持新旧主包混用。附属沿用街机0.1.5.1、SFC41/core9、GBA10、PC7、PvZ9、Flash0.1.3，兼容范围以随包验证结果为准。

世界级设置保存到世界数据 `piq_arcade_server_rules.dat`，随世界备份。没有批量改写或删除原机柜NBT、ROM、BIOS、PGM设置或玩家存档。不要误用build/libs中包含未发布手柄草稿的中间包，以交付目录冻结JAR为准。
