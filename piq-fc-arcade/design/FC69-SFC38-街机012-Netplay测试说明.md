# 方块电玩 Netplay 游戏内测试说明

适用候选：FC `0.31.0-alpha.69`、SFC `0.1.0-alpha.38`、街机 `0.1.2`。2026-09-24。仅 Windows x64 运行客户端、Minecraft 1.21.1、NeoForge 21.1.236、Java 21。

## 安装

先备份测试世界，正常关闭客户端和服务器。在双方实例的 `mods` 中安装相同版本的 FC69，以及选用的 SFC38、街机0.1.2；同一 MOD ID 的旧 JAR 移到实例外保留，不要叠装。完整 SFC38 已合入旧 core9，不再单独装 SFC 核心包。不要安装 build/libs 里的 SFC 薄包。Flash prototype.8 不兼容，不要混装。

包内说明、校验文件和外层 ZIP 不放 mods。不含 ROM、BIOS，不下载游戏。未自动安装、部署、发布或重启任何游戏实例。

Netplay 用现有 Minecraft 连接传输；不需要开放 RetroArch 端口，不用另开 RetroArch 窗口，也不建立公网房间。原生进程只监听本机回环地址。服务器仍负责 Minecraft 的加入许可、手柄、距离、设备和连接身份检查。

## SFC 测试

1. 使用家用 SFC 主机，连好电视，插入合法游戏卡带。先用熟悉的双人 NTSC 游戏测试。
2. 关机后用调试螺丝刀打开设备设置，管理员选择「RetroArch Netplay（实验）」。旧机器不会自动切换。
3. 开机玩家负责运行 P1；领取 P1 手柄。另一位玩家按当前双人加入规则获准后领取 P2。已有权限规则保留，不能借 Netplay 绕过。
4. 两人分别测试方向、A/B/X/Y、L/R、Start/Select，打开菜单或归还手柄时应立即松键；再测试退出 P2 和重新加入。
5. 主持玩家断线或关闭主机时结束本局，不迁移主持。实验模式不读写保存进度，不导入或覆盖原来的存档/恢复备份。

SFC 旁观沿用音画接收。旁观玩家若原来选择了本地模拟旁观，请执行 `/sfc-watch media`；本轮不会擅自把省流旁观切成音画流。没有把 SFC 的本地旁观实现换成 RetroArch 旁观协议。

## 街机测试

使用主模组的通用单人/双人机柜，选 MAME 后端；旧独立原型机柜不在本次范围。当前仅支持固定核验版本的 `kof97.zip` 和 `mslug2.zip`，不是所有同名 ZIP 都兼容。

1. 管理员在空闲机柜的设备设置里选「RetroArch Netplay（实验）」，把游戏币设为「免费按键」。本轮不接实体付费投币，拒绝启动时不会扣币。
2. 使用一台双人柜，或通讯线连接两台单人柜；最多两席，不支持两台双人柜组成四席。
3. 按原有游戏库流程配置游戏，主持从主柜启动；选择允许多人，再让另一位玩家加入 P2。街机原有加入许可流程保留。
4. 每个运行核心的客户端需要匹配的 `neogeo.zip`；找不到时放在本机街机 ROM 目录（或所选 ROM 同目录）。核心 DLL 已在附属内。注意：现有游戏库上传流程会把游戏同目录的 BIOS 一并列入共享文件，其他玩家可能从该游戏库取得它；本轮没有新增 BIOS 下载服务，也没有改变这套共享规则。只上传你有权分享的文件。
5. 测试双方投币键、开始键、方向及攻击，P2 退出/重进、开菜单松键、主持退出、机柜拆除停止。中途加入需要传输并恢复当前状态，可能短暂等待几秒。旁观仍接收主持音画，不占玩家席位。

固定版本信息：kof97.zip 28,745,740 字节，SHA-256 `804F892924D4650545D3EA2D19FB85670094DC46DB882FECAF3E03009E2C4B9F`；mslug2.zip 17,473,893 字节，SHA-256 `1A82D65E88050FDC75DBCEA180E48802D54C67A4748558FC4BD51C0103D56E4A`；neogeo.zip 953,500 字节，SHA-256 `E1FFD4AB180E2F6AA4A3AA4D2C6F991E19D8EF762BEC8B5A6283704A2EDC3BBC`。这是兼容性标识，不是文件下载来源。

## FC 与回退

FC69 保留 FC68 的 Netplay 实验：普通 FC 家用机、NTSC、关闭存档的卡带；主持 P1、另一位玩家 P2、只读旁观。光枪不在范围。原有本地同步、玩家音画串流、服务器托管均保留，不覆盖旧机器配置。

想比较卡顿时，结束本局、关机后在设备设置切回原来的模式，再启动相同游戏。不要在一局中混用不同模式。Netplay 并非零流量：会传输入和必要状态；Minecraft TCP 链路抖动也仍可能影响体验。没有宣称它已经比原模式更快。

## 验证与反馈

本轮自动检查包括真实 RetroArch/Mesen、Mesen-S、固定 NeoGeo 核心的多进程联机，以及生产 Minecraft 载荷编解码。具体最终通过情况以包内 verification.json 和证据 `outputs/netplay69` 为准。SFC 用自制测试程序检查双方全部 12 键；街机使用用户本机已有游戏和 BIOS，未复制进交付包。

这些不等于已经通过 Minecraft 双机实测。局域网/公网实际延迟、长时稳定性、声卡、光影、航空学组合仍待验收；流量监控数字为 0 的问题按用户要求暂缓。此包为实验测试候选，不标稳定，不是公开上架版。公开分发前仍需完成原生组件对应源码和许可材料核对。

发生黑屏、断开或不同步时，请提供：双方版本、游戏、所选模式、是否重连、复现步骤，以及模组设置→运行环境→复制诊断；保留双方 latest.log。不要删除已有存档或尝试混装旧包。
