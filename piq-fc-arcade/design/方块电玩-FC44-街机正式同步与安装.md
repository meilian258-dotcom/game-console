# 方块电玩：FC44 配套街机 0.1.0

2026-09-15；Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21。

## 这次改了什么

街机本地输入同步由实验入口整理为正式功能，保留用户测试通过的固定核心与同步规则。菜单、运行环境和错误说明统一使用“本地输入同步”，明确兼容范围。不改变既有机器的同步选择，不新增另一种机台。

修复通用街机缺失“正在使用：玩家名”的接线。占用由服务端实际席位决定，旁观不占席；本轮不恢复已经关闭的右键操作流水提示。新显示的退出、断线及双柜清理仍需游戏内复测。

## 安装文件

| 本次文件 | 用途 | 安装端 |
| --- | --- | --- |
| `game_console-0.31.0-alpha.44.jar` | FC 与共享机柜、网络、占用显示 | 客户端和服务端 |
| `game_console_arcade-0.1.0.jar` | 街机附属，内置六项街机运行库 | 客户端和服务端 |

把这两份放到实际实例的 `mods/`。旧 FC 和旧街机 JAR 移到实例之外备份，每种只保留一份；不要删除世界、配置、ROM、存档或已经解压的匹配运行库。更新后完整重启客户端和服务端。主协议仍是 35，推荐所有人统一这套；街机 0.1.0 明确要求 FC44 或同一 0.31 系列后续兼容版，旧 FC 会被前置检查拦住。

FC44 保留 FC43《赤色要塞》Mapper19 修复。旧 FC / 光枪 / Mapper19 三个 WASM 均不改变。现有 SFC alpha.25（内含 core alpha.9）和 GBA alpha.8 不需更新，也不是本次重新构建的成果。FC 主模组仍使用 alpha.44 编号；街机附属正式编号是 0.1.0。

首次使用街机时，Windows x64 / JVM amd64 自动从附属 JAR 补齐六项固定运行库，无需另下运行库包。匹配文件复用，冲突文件不强制覆盖；失败请在「运行环境」查看原因。ROM 和 BIOS 自备，GBA 运行库不在此附属内。Linux 等平台不能运行此 Windows 街机核心，仅接收音画不要求本机执行核心。

## 如何选择本地同步

1. 管理员先结束机柜游戏；连线机柜两端都要空闲。
2. Shift＋空手右键街机，在当前街机模拟器下进入「同步 / 网络」。
3. 选「本地同步」，等服务器确认后重新开机。保持以前测试使用的游戏和 BIOS 文件。
4. 第一位玩家开局，第二位玩家申请加入，初始化快照完整校验并追赶完成后才能操作。旁观者接收音画，不必右键占席。

游戏范围是已核验的 `kof97.zip`（拳皇97）、`mslug2.zip`（合金弹头2），且校验精确内容及配套 `neogeo.zip`，不是任意同名 ZIP。重新压缩、地区版或汉化版也可能不同；不要为了通过检查随意改名或替换 DLL。不匹配时可切回音画串流，没有自动绕过校验或无提示切换模式。

本地同步最多两席：一台双人柜、或者两台单人柜连线；两台双人柜组成四席请使用音画串流。正式化不更改四人兼容范围。

当前模式持续传输入与校验，加入、重同步及周期检查还会传快照；旁观继续传音画。主持端退出仍按现有规则结束本局，不新增无缝主机接管。不同托管位置的存档不会自动互转。

## 默认与原功能保护

已有设置保留。未设置的普通街机继续默认玩家托管；只有服主主动启用且当前后端可用时优先服务器托管。没有按整个 MAME 后端强制默认本地同步，以免其他游戏无法启动。FC、SFC、GBA 的原有默认不改。

保持固定 profile、BIOS/ROM/运行库 SHA 校验、恢复后完整快照校验、会话/连接权限、两席限制、服务器管理权限。未改网络协议、模拟器代码、六项运行库、贴图、模型、键位或存档格式。
