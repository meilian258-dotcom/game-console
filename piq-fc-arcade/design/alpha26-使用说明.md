# 按键修正与光枪 alpha26 测试包

2026-09-11，Minecraft 1.21.1 / NeoForge。仅提供安装包，未自动替换任何实例。

## 安装

先退出游戏，备份旧文件，再替换本包 `mods` 内的三份模组。不要把旧版本留在 mods 内；不要保留另一个独立 SFC core/home 包与合并版重复加载。

- `piq_fc_arcade-0.31.0-alpha.26.jar`：主模组，内置 FC、共享控制设置与 FC 光枪。
- `piq_sfc-0.1.0-alpha.15.jar`：合并的 SFC 附属（含原 SFC 核心）。
- `piq_native_arcade-0.1.0-alpha.10.jar`：原生街机附属。

本次还有一份必须配套更新的 `piq-native-arcade/runtime/piq-native-helper.jar`，复制到游戏实例目录的同名路径，不是 mods 目录。它修正街机按钮 2/3 的顺序；新模组会明确拒绝旧 helper。保留 runtime 中其他原有 DLL/JNA 文件，不要删除整个目录。本包不含 MAME DLL、ROM、BIOS、用户配置或存档；已有运行环境继续使用。

联机双方和服务器应成套更新；FC 网络协议已从 31 升至 32，不能混用旧客户端。原 FC/SFC/街机存档和已有键盘配置不迁移、不删除。回退须成套还原旧三份模组及旧 helper。

## 推荐按键方案

按 **F7** 打开控制设置，分别选择 FC、SFC、街机页，再选“经典”方案并保存。已有用户不会被静默切换，新配置默认经典。设置页直接列出每项功能和实际键位；“跟随 Minecraft 按键设置”才是原先不明确的“现有方案”。

| 系统 | 方向 | 功能键（明确对应） | 开始 / 选择或投币 |
| --- | --- | --- | --- |
| FC | ↑ ↓ ← → | B=Z，A=X | Enter / Backspace |
| SFC | ↑ ↓ ← → | B=Z，A=X，Y=A，X=S，L=Q，R=W | Enter / Backspace |
| 街机 | ↑ ↓ ← → | 按钮 1–6 = Z、X、C、A、S、D | Enter / Backspace |

这里的 SFC `X`、`L` 指手柄功能，不是键盘同名键。例如 SFC 肩键 L 使用键盘 Q。

参考 [RetroArch 官方按键说明](https://docs.libretro.com/guides/input-and-controls/) 的经典布局，并避开 Shift 作为默认 Select；街机采用连续的两排按键而不是 MAME 默认的 Ctrl/Alt/Space/Shift，以便在 Minecraft 中使用。[MAME 官方说明](https://docs.mamedev.org/usingmame/defaultkeys.html) 也说明具体游戏的按钮用途可能不同。“按钮 1–6”是稳定编号，不声称每个游戏都把相同编号叫同一种攻击。

保留“方向键 + 小键盘 1–6”“WASD + JKL / IOP”“自定义”“跟随 Minecraft 按键设置”。小键盘与主键盘数字不是同一个按键。自定义和跟随方案的具体键位以页面显示为准。

## F8 操作锁与 L 冲突

- 经典、WASD 方案领取操作权后，先 **F8** 进入操作模式。世界键盘动作（WASD、L 进度、E 背包、T 聊天、Q 丢弃、数字快捷栏等）都不会触发；鼠标转视角、右键归还、Esc 保留。
- 再按 **F8** 解除，恢复世界操作，同时松开模拟器全部输入。自由移动状态下，键盘和实体手柄都不操作模拟器。
- 小键盘、跟随、自定义初始可并行操作：映射给游戏的按键被拦截，其余按键仍交给 Minecraft。希望 L 等全部不触发时，同样按 F8 锁定。
- 窗口失焦、打开菜单、归还控制权会清除按键及积压点击；回来后先松开物理按键再操作。F7/F8 可在设置里重绑。
- 实体手柄默认启用识别；从同一设置页进入控制器设置。尚未用真实 Xbox / Switch / PlayStation 手柄逐一实测。

## 光枪 / 打鸭子怎么试

1. 用原来的方式给 FC 卡带写入你已有的《打鸭子》，插到 FC 主机，AV 线连接大电视。若普通手柄还被领着，先归还结束旧局。
2. 创造物品栏取“FC 光枪”；有命令权限也可用 `/give @s piq_fc_arcade:fc_zapper`。
3. **主手持枪，右键已接好的 FC 主机或电视**，明确以光枪模式启动。本轮不把已有普通局自动切核心。
4. 经典方案按 **F8** 进入操作；用 Backspace/Enter 选择并开始菜单，具体游戏模式按 ROM 菜单选择。
5. 用准星瞄准电视内的实际游戏画面，**左键开枪**；黑边、机壳、屏幕外、被方块遮挡的位置不会算作有效瞄准。扳机有动画，开枪不挖方块。
6. 持枪再次**右键绑定的主机或电视**，结束光枪局。收起枪、打开菜单或 F8 解锁会释放扳机，不会卡住连发。暂存自己库存保留局；掉落、转交、掉线或设备失效会撤销权限。

大电视无需额外改模型；按实际屏幕位置、朝向、显示比例映射到 256×240 的 NES 画面。射手请保持在电视锚点 8 格内，仅靠近主机但远离电视可能无法输入。光枪是 FC 硬件第二端口配件，但不是第二个 Minecraft 玩家；这一版一位射手，其他玩家走原被动旁观同步，不需领取枪。

枪局使用独立核心和独立存档命名空间，不读写普通 FC 三个存档槽。同一玩家在同一维度、同一电视位置启动同一 ROM 时，若已有有效枪快照，会恢复最近保存状态。右键结束保存最近收到的周期快照，可能缺少最后几秒，并非退出瞬间保存。当前是近似光感兼容，不保证所有光枪 ROM、所有时序都完全准确。

## 验证边界

交付验证清单随包放在 `checks`。验证包含包内真实模拟器工作线程/核心、按键路由、真实字节码变换与数据包编码；没有把离线探针当成 Minecraft 实机测试。本轮未开启真实多人服务器、未运行用户世界，也未实际手持硬件手柄测试。首次游戏内体验请优先检查 L、右键退出、大电视射击和另一玩家不操作时的旁观。

GBA 模型本轮不注册为可运行模拟器；不夹带 ROM/BIOS，也没有启动关机或线上发布。
