# FC72 光枪 Netplay 测试版

适用：Minecraft 1.21.1、NeoForge 21.1 系列（21.1.236 构建）、Java 21。参与模拟的客户端仅 Windows x64。
当前交付目录：`制作Mod/03-街机模拟/方块电玩-FC72-光枪Netplay测试-20260924-r2/`。这是待实机验收的候选，不是稳定版或公开发布批准。

## 安装

1. 正常退出游戏，备份后在世界副本测试。服务器升级由服主安排停服窗口。
2. 客户端与服务器将旧 FC 主包移到 mods 外保留，放入 `game_console-0.31.0-alpha.72.jar`。同 ID 只装一份，所有参与者及服务器统一 FC72。不要混用第一次候选（不带 r2 的目录，菜单说明仍旧）；本指南以 r2 的 SHA 清单为准。
3. 已有完整 SFC38、街机 0.1.3 可以保留；不要改装 build/libs 薄包或卸载 SFC 进入原世界。不需要额外安装 RetroArch。
4. 如果还装了 PvZ，必须把旧 PvZ 附属换成配套 `game_console_pvz-0.1.0-prototype.4.jar`，两端同版。PvZ3 的依赖上限拒绝 FC72。PvZ4 只改兼容声明，main.pak 路径、个人本机档、性能实现不变，仍无 PvZ Netplay。
5. 本轮没有为 GBA/Flash 扩展 Netplay，不据此保证其他未核对附属可混装。

本次只生成本地包和说明，没有安装、部署、发布、重启游戏/服务器或修改用户配置、世界、ROM、存档。首次候选及旧发行文件保留。独立 JVM 底层闪退问题不是本次修复范围。

## 怎么测光枪

1. 工作台将测试 FC 卡带的存档设置为“关闭”。保留有进度的卡带，建议另外制作一张测试卡；Netplay 仍不读取或保存进度。
2. 主机关机时，在设备设置中选择“RetroArch Netplay（实验）”。电视、主机、光枪底座按原流程连接；先连接好光枪再启动主机。
3. 插入有权使用的光枪游戏卡带，打开电视、主机。如果让朋友持枪，开局允许 2P；否则保持单人。
4. 领取光枪，按原操作瞄准电视并射击。主持人自己拿枪可以；主持人持 P1、朋友持枪也可以。同一玩家可借 P1 和光枪，枪占第二设备口，不能再同时接普通 P2 手柄。
5. P1 口空闲时，持枪者可以用已配置的开始/选择等菜单键；有人领取了真正 P1 手柄后，P1 的菜单键优先。N 锁定/解除人物移动，F7 查看实际键位。
6. 结束请正常关闭主机；本次 Netplay 不保存。要回到原存档玩法，关机后切回原运行模式，旧存档不被本实验转换或删除。

## 建议验收顺序

- 自己开机拿枪：进入菜单、开始游戏、中心和边缘瞄准、快速点射、屏幕外射击。
- 归还/再次领取，切物品栏、打开菜单、失焦，确认不持续开枪；挡住电视时不能穿墙命中。
- 同服朋友持枪、主持人拿 P1，双方与第三名旁观者画面是否一致；拒绝 2P 时朋友不能抢枪控制。
- 枪手断线重进、移出有效距离、关闭主机、拆线、主持退出，检查松键及正常结束，不残留控制权。
- 普通 FC 双手柄、SFC、街机各回归一局；记录实际游戏名、谁开机/持枪、延迟、模组版本及日志。

这些 Minecraft 持枪、世界射线与跨电脑网络验收尚未执行，不以自动测试替代。Mapper 19 + 光枪仍保留原不支持提示；不保证所有 NES 光枪游戏、ROM 改版或飞行载具兼容。航空学、光影不在本轮新验收范围。

## 实现与边界

沿用服务器的物理租约、连接/序号/距离/遮挡校验。客户端坐标只是提示，实际瞄准点仍由服务器视线重算。服务器向计算主持发送规范化输入，主持原生 Netplay 同时持有 P1 手柄和 Zapper 两口；远端原生进程只读，MC 中获准的朋友仍能持枪或按 P1 菜单键。这个原生“只读”不等于 MC 玩家被禁止操作。

输入队列保留按键与扳机边缘，合并连续移动；归还/撤销时用修订屏障丢弃旧待处理输入。主持连续 750ms 收不到输入会松开并要求释放后重新按键。普通 FC/SFC/街机保留原按键路径。主持离开结束本局，不自动换主持。

共用进程桥升级 PNP3，网络子协议为 netplay-2，防止混用旧包。原主协议45、附属公共构造、核心 DLL、资产、旧保存命名空间及 FC71 的设备初始化修复保留。
