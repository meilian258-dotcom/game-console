# 方块电玩 FC59 测试候选

2026-09-19。适用 Minecraft 1.21.1 / NeoForge。此说明随 FC59 测试候选交付，最终构建、SHA 与验证结果见同包验证记录；不要把旧 FC58 当作本轮成果。

## 本轮范围

- 双人街机新放置为两格宽、一格深、两格高。前凸操作台只显示，不占前方格，不阻挡玩家。机身仍有碰撞；四朝向的屏幕、投币口、操作动画、数据线端口、名字牌保持对齐。
- 已放置旧街机保留旧位置和十二单元所有权，不自动搬动或改写正在玩的机器。先退出游戏，拆下再重新摆放，才会切换新四单元布局。正常拆卸仍只返还一台机器；旧卡库/存档机制不改。
- 小霸王键帽字体与字重统一，字母不再因为原拼音区域而缩小；宽键、数字区 Enter 不再被拉伸。机身文字、外壳与键帽几何不变。
- 视频线修复两款小电视邻近摆放时的折返，长线增加稳定的自然弧度；FC同一条连接重进世界保持样式，拔掉重新接线可产生另一种变化，不做随机抖动或每帧重算。SFC/Flash旧调用接口仍在，其共用新电视线材按端点位置固定样式。短线不强行弯曲，空间不足时回退规则走线；仅对已知两端机壳避让，不是任意地形物理寻路。手动拖拽节点另列待办，未实现。
- 航空学首版仅 FC 家用机与同一载具上的电视。必须先组装载具，再在载具上放置 FC 和电视、连接视频线、开机；目标为平移与旋转。组装或拆解载具前必须停机还柄并拆下这些设备，仅关机不足以保护旧的多格位置记录。无 Sable 时不增加强制前置；不适配 SFC、小霸王、街机或 Flash，不支持带着已放置设备组装/拆解、跨载具/地面接线及非刚性缩放。光枪支架和遥控器等额外配件不承诺船上完整支持。

## 安装边界

最终 FC59 主包需客户端和服务端一致更新，因为方块状态、连接身份及服务端交互处理均有变化。退出游戏后替换旧 FC JAR，不能与 FC58 叠装。请使用冻结目录的 `game_console-0.31.0-alpha.59.jar`，不要安装源码工程 `build/libs` 中含未审手柄草稿的中间件。

SFC36、Native0.1.1、GBA8及运行库不更新。本轮 SFC36 仅做相同源码重编译回归，冻结工具要求字节与上一版一致；不要把它当作新的 SFC 功能。若已装 Flash，需同步换本轮兼容补丁 prototype.6，原完整运行器0.1.2沿用。没有 Flash 则不需安装。

适配 API 核对目标是 Sable2.0.3 / Companion1.6.0 / Create Aeronautics1.3.0。编译、几何与本地 API 探针不等于 Minecraft 双端/光影/飞行验证。此候选未标稳定，未自动安装、发布或重启。

船上首版不支持调试螺丝刀、电视遥控器、管理终端/命令的瞄准设备设置，以及完整光枪支架操作。它们的独立工具射线尚未适配；不要将FC实体电源按钮/手柄适配理解为所有配件已适配。可在放置前设置新机默认值，现有船上机器不承诺用上述工具调整。

船上无信号提示音尚未完成兼容：Sable2.0.3的声音代理与原声音对象的播放状态查询不一致，按源码链推断可能每秒重启、声音断续。此项不列为已支持或已通过，正常游戏声音及交互短音也仍需飞行实测。

## 请实际验收

1. 新双人柜贴后墙放置；前面放椅子/方块，玩家能靠近，前操作台可穿模。四朝向均测试。
2. 投币/右键/屏幕/双人按键正常；拆任一真实机身格仅掉落一台，旁边方块不受影响。旧机器关机重放后验证新占地。
3. 小霸王字母、功能键、主 Enter、数字区 Enter 和 0 的字号/比例正常。
4. 两款小 CRT、桌面 LCD、壁挂 LCD 在近距离、相反朝向、正下方及长连线下无小环、穿壳或悬空乱跳。
5. 无航空学的原地面 FC 功能正常；先组装空载具，再在其上放置 FC/电视并接线，实际验证飞行转向中画面、声音、手柄、设备按钮与退出。跨船连接被安全拒绝；组装/拆解前必须停机还柄并拆下设备。此步骤尚未在游戏实测，不要先在地面摆好整套设备再直接组装。
