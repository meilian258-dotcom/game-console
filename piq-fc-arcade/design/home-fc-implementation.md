# 家用 FC 首版实施记录

2026-09-08，家用机初版采用复古彩电；卡带拿在手上 Shift+右键打开编辑器，无须先放地上。

## 分工和边界

- 会话/布局/注册接线、版本和协议、整体验证和候选打包。
- 主机/电视方块实体、插拔卡、持久 AV 链接、物品/方块注册、安全事务；独占 registry 和 FamicomConsoleBlock。
- 卡带数据/物品、手持 GUI、ROM 与封面传输、服务端授权、客户端封面缓存；自有 CartridgeNetwork 注册，不修改旧协议入口。
- 03 红白机/04 彩电/05 卡带新 home 资源、导入核验、线缆/插卡/物品封面渲染。保留原手调资产、旧模型和草稿。

## 设计

同一 MOD 新增 retro_tv、fc_cartridge、av_cable，既有 famicom_console 升级功能。原街机不改成插卡操作。首版一主机一电视，同维度 8 格内，先后右键两个端点连接；Shift 用线右键端点断开。线缆仅渲染，不模拟物理。双端持久 UUID 与 link UUID 防同坐标重放和重复返线，不强制加载区块。

卡带最大堆叠 1、独立 UUID，只存 ROM 哈希/封面哈希/名称，文件放服务器共用库。主副手 Shift 使用优先编辑，不误插入；编辑默认 OP，普通玩家使用成品。ROM 复用验证/传输和索引，封面采用有限 PNG、512×256 标签区，懒下载和有界纹理缓存。

电视坐标作为现有模拟会话/显示锚点，主机实体保存卡带和双向连接。selected ROM 对家用电视只取卡带，绝不信任旧机器配置或任意客户端 ROM 参数。普通电视右键必须先有有效链接和卡带。插卡启动同一核心，存档/多人沿用原规则（个人槽可能需要选择），不为电视另启第二个核心。拆除/拔卡/断线即时关闭对应会话，已有最新服务器快照尽力保存，异步退出未完成时不承诺零进度损失。空闲电视默认黑，不自动显示街机旧榜。

计划版本 0.31.0-alpha.1 / 协议 21，新增注册项和数据包，必须双端更新。最小检查：旧全量测试、卡带编解码/界限/事务、链接身份/距离/掉落、真实模型/UV/屏幕边界、最终候选运行时和资源白名单。没有 Minecraft 实机验收不得宣称已验证多人或图形效果。
