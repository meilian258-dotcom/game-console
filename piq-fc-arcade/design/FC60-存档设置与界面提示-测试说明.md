# 方块电玩 FC60 测试候选

2026-09-19。适用 Minecraft 1.21.1 / NeoForge 21.1.236 起的 21.1 系列 / Java 21。本文为 FC60 候选的操作与验收说明；只有最终冻结 JAR、完整构建日志和随包验证记录生成后，才代表本轮成品可供测试。不要把 FC59 旧包或 `build/libs` 中间件当作本轮交付。

## 本轮改动

- FC 卡带管理的“存档设置”打开同一界面内的专用子页，明确列出“不存档”“机器存档”“个人存档”，不再通过同一个按钮循环切换，也不切换到另一个 Screen。选定具体一项才发送修改；仅打开、返回或关闭页面不提交。具体存档列表入口统一称“存档库”，与存档方式选择分开。
- 该设置针对当前卡带 ROM 对应的同一游戏，属于全局游戏设置；不是只改手里这一张卡带、眼前这一台机器，也不是修改全部游戏或所有机器默认值。修改仍以服务端权限、实际卡带身份及上传/写入状态核验为准。设置在下次开机生效，不更改已运行会话的存档方式。
- “不存档”：不保存本次进度，开机不弹个人存档槽选择页。“机器存档”：使用当前机器对应的存档，开机不弹个人槽页。“个人存档”：仍在开机时选择自己的存档槽，然后按原个人存档流程开始。
- 改存档方式不会迁移、合并或删除已有存档。再次选回相应方式后仍按原存档规则访问；不要把切换方式当作具体存档的改名、删除或迁移工具。
- 整理 FC 页面和提示文案，使按钮、当前设置、文件来源和下一步操作更直接。界面文字调整不代表新增模拟器、游戏支持、存档格式、SFC 存档管理或 Flash 联机功能。
- 光枪线改为双手空、Shift＋右键支架出线口或 FC 数据口拔除；普通右键不再拆线。持数据线 Shift＋右键的原入口保留，只有实际消耗的线才退还一次。
- 小马扎 Shift＋右键展开/折叠，成功后播放原版木门风格音效（不是另附的旧版录音）。折叠且无人占用时，双手空、普通右键收回主手，保留木种与折叠状态。
- 折叠马扎在主手可近战：基础总攻击伤害4、攻击速度1.6；不增加剑扫击，不新增耐久或改变原堆叠。展开物品与副手不获得这组攻击加成。收回不复制物品，仍受交互与破坏权限保护。
- 修复船体上 FC 家用机游戏画面黑屏：在游戏画面的全局渲染事件中补上船体插值位置、旋转及法线变换，覆盖公开游戏、私人游戏和旁观画面。只调整 FC 家用机这一画面路径，模型、纹理及 SFC、Flash、小霸王的画面路径不改；本轮新版本尚未完成 Minecraft 船上实机验收。

## 安装边界

客户端与服务端使用相同 FC60 `game_console-0.31.0-alpha.60.jar`。FC 共同注册、服务端设置处理和客户端界面分别承担两端逻辑；不能只凭前置依赖的 side 判断安装端。先正常退出对应测试实例并备份世界，再用最终冻结主包替换旧 FC JAR，同一 MOD ID 仅保留一份。

最终冻结目录为 `piq-fc-arcade/build/review-fc60-v1`，分类测试包为 `方块电玩-存档设置与界面整理-FC60-20260919.zip`。只有随包 SHA 清单与验证记录匹配的文件才是本轮成果；不要安装源码工程 `build/libs` 中含未审手柄草稿的 FC 中间件。

SFC36、Native0.1.1、GBA8及其原运行库沿用，不随本更新 ZIP 重发。SFC36 仅以原源码重编译做兼容回归，冻结结果必须与 FC59 配套的 SFC36 字节完全相同，不冒称新增 SFC 功能。SFC36 已合并原 core9，不叠装独立旧核心包。

若已装 Flash，则双方换用兼容补丁 `game_console_flash_box-0.1.0-prototype.7.jar`；未使用 Flash 的实例不必安装它。原型7仅将明确兼容范围扩至 FC56～FC60，Flash 自身29个类及模型、Mixin与完整 runtime0.1.2沿用；最终仍须核对冻结 FC 的依赖成员和两个 Mixin 目标。已装完整 runtime0.1.2无需重装，首次安装仍按 Flash README 获取完整原型3运行器；它放执行 SWF 的客户端实例根目录，不放 mods，服务端无需 Windows 运行器。本次不包含 ROM、BIOS 或 SWF。

测试候选不标稳定；旧包保留。

## 请在世界副本中验收

1. 以有对应管理权限的玩家打开 FC 卡带管理，确认“存档设置”能进入同一界面的专用子页，三项同时可见、当前项明确；“存档库”仍是具体存档列表而非方式切换。小分辨率和中文/英文界面下检查文字不裁切；返回、Esc及仅浏览不改变设置。
2. 选择“不存档”，退出管理并开机，确认不出现个人存档槽页；正常结束后不产生本次新进度。既有机器档和个人档文件仍存在，不被清空。
3. 选择“机器存档”，确认开机直接使用机器方式而不弹个人槽。正常退出再开机验证原机器进度规则；另一台机器不误用此机器档。
4. 选择“个人存档”，确认开机仍弹原个人槽选择页，选择新槽、已有槽及取消的行为保持原规则；不同玩家只访问自己的个人档。
5. 两张写入同一 ROM 的卡带、另一台机器及另一名玩家核对该游戏设置一致；换到不同 ROM 游戏确认其设置未被批量改动。切换三种方式前后核对旧进度仍可按原规则使用，没有隐式迁移、合并或删除。
6. 非授权玩家、换手/换卡、远离管理电脑及同时管理场景，确认服务端拒绝不合法或过期修改；卡带上传/写入时不能设置。游戏已经运行时修改该游戏元数据，应不改变当前会话的存档方式，下次开机才采用新设置；不要误判为运行时必须拒绝设置。拒绝提示应可理解，客户端不将未成功请求显示成已保存。
7. 回归卡带游戏/封面来源、现有存档管理、仅自己玩页面、运行环境与同步提示。文案应与真实操作相符；原权限、共享游戏库、普通启动与私人启动行为不因文字变化扩大。
8. 已装 Flash 的测试实例核对加载、连线、看电视操作、Esc、失焦及关电视退出保护；这只是 FC60 组合复验，不是新增 Flash 能力或流畅度保证。
9. 光枪线两端各测试普通右键不拔线、空手 Shift＋右键拔线；连续点击不重复返还、不退卡，保护拒绝与回调中松开 Shift 不拆线。线材本身和光枪借还流程保持。
10. 11种木材的小马扎分别测试开合声音、坐席占用/保护拒绝时无成功音效、折叠空手收回/再次放置。生存/创造、满背包、主副手、连续右键均不得复制或丢失物品；自定义名称等已有物品数据保持。
11. 比较折叠主手、展开主手和副手的攻击属性及实际近战；基础总伤害4不等于对有护甲目标每次固定扣4。原版攻击冷却、伤害与保护插件仍适用。
12. 先组装空载具，再在同一船体上放 FC 家用机和电视并接线，分别启动公开游戏、私人游戏及加入旁观。静止、平移、转向及旋转中检查游戏画面是否持续贴合电视屏幕，确认不黑屏、不偏移，旋转后的法线与可见方向正确；另回归地面 FC。此项为本轮新增待实测项目，不以离线变换测试替代 Minecraft 双端、光影或飞行验收。

## 保留限制与证据

本轮保留 FC59 的线材外观、模型、纹理和键帽；航空学相关改动仅为上述 FC 家用机游戏画面的船体插值位置、旋转及法线变换，不扩展 SFC、Flash 或小霸王画面路径。其余原限制继续有效：同船 FC 必须先组装空载具，再放 FC 和电视及接线；组装或拆解前停机还柄并拆下设备。船上工具/光枪配件及无信号声音仍有待验项，不因本次画面修复视为已修复；详见 FC59 测试说明。

测试数量以最终 XML/验证记录为准。FC 既有8项 Windows 权限环境跳过必须明确列出，不算实际执行通过。
