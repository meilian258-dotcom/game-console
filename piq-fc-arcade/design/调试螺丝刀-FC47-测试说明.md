# 方块电玩：调试螺丝刀测试版

适用版本：Minecraft 1.21.1 / NeoForge 21.1 系列，FC 0.31.0-alpha.47。可选 SFC 0.1.0-alpha.27 沿用既有成品，本轮没有修改模拟器核心。

## 安装

1. 备份世界、配置、存档，正常退出游戏并关闭服务器。
2. 服务器及所有客户端统一更换 FC47。同一个 MOD ID 只保留一个 JAR，旧版本移至实例外备份；不能与 FC46 等旧主包混连。本版主协议37，家用设置协议home-sync-2、街机菜单协议cabinet-2、街机同步协议cabinet-sync-4。
3. 只玩 FC，仅安装 game_console-0.31.0-alpha.47.jar。使用 SFC 的两端同时安装 SFC27；如果已是 SFC27，不必再次替换，其文件内容不变，已内含 core9。不要重复安装旧独立 SFC core。
4. 街机0.1.0、GBA8沿用现有附属及运行环境，不包含在这次更新包中。外层 ZIP、说明和预览图不要放进 mods。

安装端依据：新物品由公共注册表注册，设备设置由服务端验证，客户端提供界面及模型；因此 FC47 必须两端安装。本次没有新外置运行库，也不包含游戏 ROM、BIOS 或个人存档。历史内部 ID 保持不变以兼容存档。

## 使用

- 创造模式中，在游戏机物品页搜索“调试螺丝刀”。红色手柄、金属杆，为立体物品；没有合成配方。
- 手持工具，对准 FC / SFC 主机，或单人 / 双人街机右键，打开该设备设置。修改还需管理员权限（OP2）及所在位置的交互权限。
- 家用机可以调整同步方式、加入确认、使用者文字。仅展示并允许修改当前设备已支持的功能；SFC 尚未实现使用者文字，不能靠此工具开启。
- 街机进入已有同步设置，沿用后端、游戏和席位限制。通过数据线连接的机台共用设置，修改会影响整组；不等于只改一块屏幕。
- 运行中的机器不能直接改同步方式，先结束游戏。原有 Shift / 命令设置入口仍保留，不额外强制其使用者进入创造模式。
- 工具只作用于点击的自家设备。对普通方块右键不切换方块状态、不打开箱子，也不寻找附近机器。
- 放下工具、切换手持物、离开目标、切换模式或设备被拆换/重新接线后，旧工具页面可能失效；重新对准设备右键打开即可。

## 与遥控器的分工

遥控器保留电视扫描线、开机动画、音量/静音、无信号提示音，以及个人控制设置入口。主机同步、加入确认和使用者文字由调试入口处理；旧遥控器提交的主机设置指令也会被服务端拒绝。存档设置仍归卡带，本轮不迁移。

## 建议验收

1. 创造模式、OP2，分别点击 FC、SFC、单人和双人街机。核对标题、坐标；旁边摆两台相同机器，确认只改所点目标。
2. 普通玩家、无交互权限的位置、切换生存模式后尝试修改；均不应绕过权限。原 Shift 设置入口仍按原规则使用。
3. 页面打开后换掉螺丝刀、移远、遮挡视线、拆换机器、改变数据线连接，再提交旧页面，确认拒绝旧请求。
4. 对箱子、家具、其它模组机器点击，确认没有误触发。工具空挥不打开最近设备。
5. 在空闲机器修改同步方式，重开页面确认；游戏运行时不允许切换。通讯线连接街机检查两台属于同一组，正常开机/加入游戏不受影响。
6. 遥控器只保留电视常用项；音量、扫描线、声音/动画和个人按键入口正常；写卡存档设置保持原样。
7. 核对物品栏、第一人称、第三人称和副手的可见性。离线预览只确认原模型几何，不代替游戏内持握位置验收。
