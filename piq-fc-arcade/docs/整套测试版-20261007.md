# 方块电玩整套测试版 · 2026-10-07

本套提供主模组和当前配套附属，可用于首次安装，不需要先取得旧 MD 补丁。目标为 Minecraft 1.21.1、NeoForge 21.1.229 起的兼容 21.1 版本、Java 21；原生游戏执行端为 Windows x64。仍是测试版，不是稳定版，也不是包含 Minecraft 的整合包。

## 下载哪个文件

在[本次 Release](https://github.com/meilian258-dotcom/game-console/releases/tag/full-test-20261007-r1)下载：

- 本次直接提供下表的 7 个 JAR；主模组必装，其余按需选择，不需要另找整包 ZIP。
- 每个文件的 SHA-256 列在 Release 正文，可用于核对下载完整性。

GitHub 自动提供的 “Source code” ZIP 只是仓库源码，不是上述安装包，也不包含全部原生依赖源码。不要将源码压缩包或运行库作为独立模组安装。

## 安装或更新

1. 正常退出客户端；更新服务器前先正常停服。备份世界、配置、原 `mods` 和完整 `game-console` 目录。
2. 从本套选择主模组及需要的附属，客户端和服务器使用相同的配套版本。单人游戏只安装到该客户端实例。
3. 将所选 JAR 放入实例的 `mods/`。移出同一模组的旧版本并保留备份；不要同时安装新旧两个 JAR，也不要删除无关模组。
4. 要测试 PvZ 时，再下载 PvZ JAR 放入两端 `mods/`。它不是其他机型的前置，游戏数据需自行合法准备。
5. 先在测试世界检查启动、设备、输入、保存和再次继续，再用于重要世界。第一次操作看[玩家指南](玩家指南.md)。

本包不含 ROM、BIOS、SWF、`main.pak`、玩家存档或预设服务器账号。需要 BIOS 的街机游戏仍须准备匹配内容；放置位置见[玩家指南的内容目录](玩家指南.md#服主怎样找-rom-和-bios)。

## 本次变化和旧档

本次重点是完整成品发行和隐私清理，不是更换模拟核心或完成新的联机功能。

- FC76.44、SFC51/core11 清理旧 WASM 资源中嵌入的个人构建路径；现用 Mesen、Mesen-S、公共 JNI 桥及其 Netplay 核心不替换。
- FC 的旧 Zapper WASM 使用模块摘要和原始内存校验。清理后的摘要改变，因此保留旧文件和旧存档，**不将旧 Zapper WASM 档自动转换为新档**。当前 Mesen 光枪路线不是这一旧 WASM 路线，其核心身份不因此改变。
- SFC 的旧、新 WASM 已通过双向状态读取及 SRAM 对比，保留原状态格式；它与家用 Mesen-S 仍是不同后端，不互读或合并保存，没有迁移或覆盖玩家数据。详见[SFC51 核对说明](../../piq-sfc-home/design/SFC51-核心路径隐私说明.md)。
- MD、GBA、Arcade 和 Computer 使用配套的既有成品，不将它们描述为本次新增功能。PvZ 保留原运行代码和 DLL，只更新公开说明与许可，版本号不变、发行文件摘要变化；更新时仍只保留一份。

## 已知限制

本次 FC 构建与 2,857 项测试执行完成（11 项跳过，失败为 0），另有打包后的真实核心检查。旧、新 FC 光枪 WASM 在独立 JVM 中的 180 帧音画、输入和 RAM 一致，各自的冷启动存档恢复一致；新版明确拒绝旧身份状态，拒绝不改变当前状态。SFC 核对包含 180 帧音画、6 个状态检查点双向互读、8 KiB SRAM、重置和重开。以上不是 Minecraft 实机或所有游戏的兼容结论。

完整安装包不代表所有机型都支持相同模式。GBA 掌机没有原机通讯联机；电脑共享是音画串流和控制权交接；PvZ、Flash 仍是开发验证用途。MD 的同步 RESET 等未完成能力不因本次打包而补齐。

Iris／Complementary 光影、Minecraft 多客户端、弱网和长时游玩仍需实际环境验证。文件校验、自动测试和隔离核心验证不能替代这些实机验收；遇到问题请按[反馈清单](玩家指南.md#遇到问题时提供什么)报告，不上传游戏内容或个人存档。
