### FC76.60 配套测试候选

本批把创造页改为按用途直接生成，SFC／MD／GBA／电脑通过公共接口插入对应分组；家具先长椅后凳子。PvZ13 不再添加退役测试盒的创造页入口，旧注册与世界兼容保留。主包还包含 FC76.58 新增的官方 FCEUmm RetroArch 双手柄路线，原 JNI 默认、旧 Mesen 路线和旧存档保持，新路线使用独立保存域，不自动转换进度。

- **安装配套**：主包 FC76.60，按需选择 SFC56、MD17、GBA16、电脑14、PvZ13。五个新附属均要求 FC76.60 起的兼容主包；客户端和服务端一起升级，包括继续使用 JNI 的玩家。SFC56 已含 core11，不另装薄包或内部核心。电脑14也通过旧 PvZ12 的兼容检查，首次安装建议选同批13。
- **已验证**：本批 Java 3,940 项、零失败／错误、14 条件跳过；NeoForge 21.1.236 的七组真实共同创造页测试共 50,773 条断言通过，覆盖主包单独与配套附属、无 ModernFix 及 5.26.1／5.27.26、旧 PvZ12 兼容，并正常保存停服。模拟核心和原生宿主沿用前版原件。
- **仍待验证**：客户端按 E、翻页／搜索、WaterFrames 实装、完整整合包及真人多人。FC 新 RetroArch 路线的既有真实核心恢复与有序延迟检查限原创 mapper 0，更多游戏、丢包抖动、长局与光枪能力不能据此视为通过；新路线不支持光枪。
- **可选旧件**：街机1.5.12已纳入 FC76.60 专服组合，文件未重发。Replay7仍为 FC76.54 的公开配套，FC76.60 已检查公共 API 兼容，但回放图形与其较高 NeoForge 依赖组合尚未实测；需要时按[回放说明](#回放兼容)单独验证。独立 Flash8／Java ME 冻结路线不加入本批。

本批为测试候选，不是稳定版。安装与备份步骤见[玩家指南](玩家指南.md#获取和安装)，详细行为及验收边界见[创造栏说明](../design/创造栏生成与附属分组-FC76.60.md)和[FC 双后端说明](../design/FC双后端共存.md)。FC76.58／76.59 是本批之前的开发候选，没有单独公开玩家发行。
