### 安装前须知

1. 加入已有服务器时，优先使用服主提供的整套配套版本，不自行混搭下表中的历史附件。
2. 更新前正常退出游戏／停服，备份 `mods`、世界、配置和 `game-console` 数据目录。保留旧组合，在测试世界确认后再使用重要世界。
3. 主模组和所选设备附属在客户端、服务器两端配套安装；单人游戏装在自己的客户端。只装一份同模组 JAR，旧版移出 `mods` 留作备份。
4. 回放补丁仅装客户端。源码 ZIP、许可证、校验文本和开发 API JAR 不放进 `mods`，内部平台与 SFC 核心包也不单独安装。
5. 自行准备有权使用的 ROM、BIOS 或程序数据。安装包不提供这些游戏内容，也不自动转换不兼容的旧核心存档。
