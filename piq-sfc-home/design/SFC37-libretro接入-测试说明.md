# SFC37：公共 libretro 接入测试说明

适用日期：2026-09-23。Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21 / Windows x64。本地开发候选，未发布、未安装到用户实例，未标稳定。

## 这次测试什么

SFC 当前家用机、私人模式、共享街机后端、服务端托管和本地旁观的执行入口改为 Mesen-S / libretro。沿用原设备、卡带、双手柄、权限、会话、三种运行模式和旁观流程，不是引入 RetroArch Netplay。主模组的 FC 核心、存档和联机协议不改。

SFC37 自带固定 SHA256 的 Windows 核心，共用 FC 主包的通用独立进程 worker/JNA。不另装 RetroArch、不另下载运行库。子进程隔离不等于操作系统安全沙箱；仅使用可信且有权使用的 ROM。

新核心原始声音为 32040Hz，连续重采样到设备链路原有的 48000Hz。仍支持两端口各12键。使用核心实际 NTSC/PAL 帧率和动态分辨率，不把 PAL 强制为60帧。首版不支持鼠标、光枪、五人转接器、SGB、外置固件配置或核心选项菜单，特殊芯片和游戏兼容性待实际验证。

## 配套文件

交付目录：`制作Mod/03-街机模拟/方块电玩-SFC-libretro-SFC37-FC67-20260923/`。

- `game_console-0.31.0-alpha.67.jar`：主包，包含附属核心资源读取入口。
- `game_console_sfc-0.1.0-alpha.37.jar`：完整SFC附属，保留原core9注册/资产和旧MOD ID，不再单独叠装core9。

两者放客户端和服务端的 `mods`，双方版本一致。安装端依据：SfcHomeMod 公共物品/方块注册及SfcHomeNetwork服务端会话/工作台协议，客户端有对应硬件渲染与模拟入口；不是仅依据依赖声明的side推断。

不要安装 `piq-sfc-home/build/libs` 的薄中间包，不要叠装旧 `piq_sfc_home` / `piq_sfc_arcade`。Flash prototype.8 的前置范围不包含这一主包，不能混装。GBA/街机迁移没有在本轮实施。

FC66不能配本次SFC37：旧桥按FC模块查找资源，无法读取独立SFC模块内的核心。FC67只补 `LibretroProcess(profile, coreResourceOwner)`；核心由附属声明的Class所属模块提供，worker/JNA仍由FC模块提供，校验和/私有目录/超时/进程回收不放松。以后的附属可复用这个入口，不需要为每个核心把DLL加入FC主包；如需当前桥不支持的新功能，仍可能需要升级接口。

用户正在测试的FC66文件、游戏实例和旧世界均未替换。请完整退出游戏，先备份并复制测试实例/世界，再把旧同ID包移出mods保留，在副本中换本套。回退时一起恢复旧JAR与对应世界/存档副本。

## 存档兼容边界

Mesen-S 与原 jgenesis WASM 的即时档不兼容。本版不迁移、删除或覆盖旧档，也不自动转换旧SRAM。

- 新即时档 PSF1：带ROM、核心二进制/版本/选项/设备身份、长度、SHA256，保存原生状态、画面缓存和重采样相位。其他游戏/核心档及损坏数据拒绝读取。
- 私人模式：新独立 `sfc-libretro-state-v1/mesen-s-piq1-8aca17e7` 身份；沿原PrivateSaveStore归属与原子保存规则，开机可恢复本次新核心自己的保存。
- 服务端托管：独立 `server-hosted-v1/sfc-libretro-v1/<owner>/<machine>/`，仍按原托管规则保存原生SRAM，不自动获得公开卡带快照槽功能。
- 公开本地同步/玩家串流：保留原本的会话隔离恢复备份（`piq-sfc-home/local-backups`），每次会话新UUID，不自动继续上一局，也不是服务器卡带存档。旧会话备份不跨会话清理，新快照可由PSF1头识别。
- 只读旁观仍不保存，不上传游戏或获得手柄权限。没有借迁移完成待办的SFC具体存档管理。
- 即时档/原生SRAM及私人保存首版只在固定Windows核心下验证；不承诺跨平台、跨核心或后续版本自动兼容。RTC类游戏和异常断电持久化未验收。

原core9类/资源保留，以避免破坏注册及历史方块；历史原型设备的旧独立入口未在本轮迁移，不应把它们当成新版SFC的验收入口。

## 建议游戏内验证顺序

1. 独立世界副本只装本套及必要依赖；SFC连接电视，插入你有权使用的游戏，确认开机画面、声音、12键和正常退出。
2. 选择一个已知支持双人的游戏，两名玩家测试两只手柄、按键释放、归还再领取、中途加入、主持离线停止。
3. 测本地输入同步，再测玩家串流；不同模式的画面、音量、正常关机和重新开机分别确认。托管需原配置明确开启，包本身不会自动启用。
4. 第三客户端测试 `/sfc-watch local` 的中途追帧及 `/sfc-watch media`，离开范围/退出/恢复后无旧帧或卡键。
5. 私人模式用新的可丢弃保存测试正常结束→重开继续，确认旧WASM保存文件仍在。不要据公开本地备份推断自动续玩已实现。

FC67保留 `/fc-debug`，但该工具仍只统计FC，不会虚报SFC核心性能。SFC专用性能面板不包含在此次迁移中。
