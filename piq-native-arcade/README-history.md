# 历史版本：街机 0.1.0

适用：Minecraft 1.21.1、NeoForge 21.1.236、Java 21；配套 FC 主模组 `0.31.0-alpha.44`。本节取代下方历史 alpha.1 的安装和功能说明。

## 当前安装

客户端与服务器都安装 `game_console-0.31.0-alpha.44.jar` 和 `game_console_arcade-0.1.0.jar` 到实际实例的 `mods/`，每个 MOD ID 只装一个版本。保留现有配置、世界、ROM 与存档目录；不要把运行库 JAR 放进 mods。更新前备份，更新后完整重启游戏和服务端。

街机六项固定运行库已内置附属 JAR：Windows x64（JVM amd64）首次启动自动补齐缺失项，已有匹配项复用，冲突项不覆盖，失败原因见游戏内「运行环境」。不下载 DLL，不附带 ROM、BIOS 或 GBA 运行库。原始内置资源清单标记 alpha.17 是该固定运行库包的来源版本，不是当前模组版本；这次不改变核心或快照格式。

## 同步模式

- 本地输入同步已作为正式功能：支持已核验版本的 `kof97.zip`、`mslug2.zip`，最多两位控制玩家。精确 ZIP 内容、BIOS 和运行库必须通过校验，同名文件不一定兼容。两台单人柜可连接；两台双人柜的四席仍不支持此模式。
- 玩家托管或服务器托管音画：保留原来游戏和最多四端口的支持，实际人数取决于游戏；服务器托管须服主开启，执行原生核心的服务器须 Windows x64。
- 本地同步的各控制客户端分别运行相同核心，传输输入、校验和及必要快照；旁观仍接收音画。不是零带宽，也不是所有客户端都只传按键。
- 已保存的模式不改。新街机沿用玩家托管默认；只有服主已开启且可用时才优先服务器托管，避免不支持本地同步的游戏首次开机失败。
- 机器空闲时，管理员 Shift＋空手右键 →「同步 / 网络」切换。下次开机生效，不新增机台或调整物品。

通用街机占用显示由 FC44 修复：使用者名字来自服务端实际席位，玩家退出后移除；不恢复以前关闭的右键流水提示。SFC/GBA 放入通用街机时同样受益，不表示独立家用机或掌机新增了占用牌。

## 交付与验证边界

上一版街机本地同步已有人工联机可用记录。本次保留相同固定核心、配置、游戏校验和两席限制；新占用牌及打包改动须按配套指南复测。构建和自动测试结果见 [FC44 配套指南](../piq-fc-arcade/design/方块电玩-FC44-街机正式同步与安装.md)。未自动安装、发布或重启服务器。

此处“正式功能”指本地同步不再作为实验入口，不代表任意街机游戏、平台、四人同步或公共分发手续均已通过。GPL/MAME/JNA 的原许可及对应源码义务仍需在公开发布前逐项核对；本包不是法律或平台审核通过证明。

## 历史记录：0.1.0-alpha.1（以下不适用于当前版本）

这是**真正运行现代 MAME 的 Minecraft 街机技术预览**，不是给 FC 换外壳。新独立模组 `piq_native_arcade`，2 格宽、2.35 格高的六格机柜，16:9 物理屏；4:3、纵屏等内容按核心比例完整留黑边。复用 FC 已冻结的双人外观资源，不修改原 FC 或 SFC 机柜。

首版仅 **Windows x64、Java 21、Minecraft 1.21.1、NeoForge 21.1.236、未开放局域网的单人世界**。支持同一台电脑上两组键盘控制，并非两名 Minecraft 玩家联机。远程服务器和开放到 LAN 的世界不会启动核心。需要另装 FC `0.31.0-alpha.14`；不需要 SFC 核心。

## 安装与试玩

该版是隔离测试候选，不代表稳定发行。

关闭游戏并备份测试世界后，将该版交付文件夹的 `mods/` 与 `piq-native-arcade/` 合并复制到所选游戏实例根目录。同一种模组不要装两份：FC 旧 JAR 先移到实例外备份，再放 alpha.14。不要把 `runtime/` 中的 JAR 当作模组放进 `mods/`。

目录应为：

```text
实例/
  mods/piq_fc_arcade-0.31.0-alpha.14.jar
  mods/piq_native_arcade-0.1.0-alpha.1.jar
  piq-native-arcade/
    runtime/mame_libretro.dll
    runtime/jna-5.14.0.jar
    runtime/piq-native-helper.jar
    diagnostic/invaders.zip
```

1. 单人测试世界的创造栏找到「PIQ 原生街机」机柜；留出两格宽、三格高的空位。第三层只使用下面 0.35 格。
2. 站在机柜正前方、屏幕在视野内，空手右键。首先点「原创诊断测试」核验画面、声音和按键。它是我们自己写的 8080 程序，借用 `invaders` 硬件驱动，并不是附赠《太空侵略者》游戏。
3. 若自行合法持有适合此核心的 ROM set，粘贴 ZIP 的绝对路径，文件名必须是 MAME 驱动短名，如 `驱动名.zip`。不自动下载、不从网上找游戏；本版仅支持单个 ZIP，最大 64 MiB。
4. P1：方向键；J/K/U/I/O/P 动作键；Backspace 投币，Enter 开始。P2：WASD；F/G/R/T/Y/H 动作键；5 投币，2 开始。游戏支持几人及每键功能取决于原驱动；原生键盘可能有多键冲突。
5. Esc 结束本次模拟并返回世界。失焦会松开并清除待执行输入。没有改写 Minecraft 键位；游戏时使用透明、不暂停世界的控制界面，因此人物不移动，先站好位置再启动。

## 边界与安全

- 固定核心是 **MAME 0.289 (4fc9a931)** 的官方 Windows libretro 构建；启动逐次核验 DLL 与 JNA SHA-256。不要随意替换文件，改版本必须重新适配和测试。
- MAME 在专属 Java 子进程内，Minecraft JVM 不加载该 DLL。超过 15 秒没有画面会回收该进程；关闭窗口/退出世界/拆柜/超出 8 格也会结束。只回收自身创建的进程，不按 Java 名称杀进程。
- 进程隔离用于故障回收，**不是操作系统权限沙箱**；仅使用可信 ROM。`-Xmx` 不限制 MAME 原生内存。技术预览不应部署正式多人服务器。
- 没有自动存档、历史恢复、ROM/封面工作台、排行榜、网络联机、CHD、独立 BIOS/父集合依赖分发、鼠标枪或转盘支持。每次从开机开始。重依赖 ROM set 可能无法加载；不承诺全部街机游戏兼容。
- 音频为 48 kHz 立体声，尊重 Minecraft 主音量和方块音量；设备无法打开则静音。画面渲染不可见时可能暂不消费音频，首版用于站在柜前操作。
- 原创诊断 ROM 的校验和与商业原作不同，MAME 的 CRC 提示是预期现象；不代表给它补齐商业 ROM。日志进入独立限量诊断缓冲，不混入二进制画面管道。

JNA 5.14.0 采用其 Apache-2.0 可选许可，保留原 JAR 和许可文本。原创诊断生成源码在附带的 `diagnostic_source.py`；没有商业 ROM、音频素材或游戏封面。对外再分发前须一并提供相应依赖的许可证、通知和对应源码，不能只转发 DLL。

当前是本地技术预览，并未附带完整 MAME 对应源码；固定源码链接是来源记录，不等于完整源码已经随包。详细版本、散列和验证边界见 `runtime-provenance.md`。最新源码快照使用 `source-v2.zip`，旧 `source.zip` 与初次 `CHECKSUMS.json` 作为历史包装记录保留；交付以 `FINAL_CHECKSUMS.json` 为准，MOD 与运行时二进制未因文档修订改变。
