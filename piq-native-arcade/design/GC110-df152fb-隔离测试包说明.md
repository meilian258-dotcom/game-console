## 安装与回退

1. 建议新建独立测试实例和新世界；先退出游戏。若使用复制的实例，先备份整个实例，尤其 `mods`、`config`、世界和 `game-console` 数据。不要直接拿正式世界测试。
2. 在测试实例中，把原主包与街机附属移出 `mods` 并保留备份。即使文件名不是 `game-console`，只要内部 ID 是 `piq_fc_arcade` / `piq_native_arcade` 就不能与新版并存。
3. **仅复制压缩包 `mods` 目录里的两个 JAR**。说明、校验清单、源码 ZIP 不放进 `mods`。首轮使用仅这两个方块电玩组件的独立实例，不与旧 SFC/GBA/电脑等附属任意混装；本包没有验证完整整合包组合。
4. 启动后使用自己的合法游戏文件；本包不包含或下载游戏/BIOS，不改原 ROM。单机先确认进世界与街机出画面，再做多人测试。
5. 回退时退出游戏/正常停测试服，移出这两个测试 JAR，恢复原配套 JAR 和升级前世界/配置/数据备份。不要让旧版直接读写测试后数据；原档不要删除或改名强行迁移。

## 建议先测这些

- OP 在未运行的街机旁空手 Shift＋右键进入配置，在同步/网络页选择 **Netplay**；旧特殊“本地同步”不是这次修好的 JNI Netplay 路径。确认游戏来源、选好游戏后运行。
- 先测三国战纪 `kov`、恐龙快打 `dino`、合金弹头 `mslug`、拳皇97 `kof97`，再测其他游戏。两人加入、实体投币、连续操作、另一玩家晚加入旁观，检查音画、按键与退出重入。
- 想测进度保存，先由 OP 在街机配置中选择个人或机器保存，不能保留“不保存”却期待恢复。测试手动保存及正常关机后再开机；等待服务器保存确认。新 FBNeo 核心身份隔离旧 Netplay 状态，旧档不会自动转成新档；这不是旧数据被删除。
- 遇到失败，发游戏文件名、运行模式、主机/加入/旁观身份、报错截图，以及出问题客户端和测试服的 `logs/latest.log`。如有原生崩溃再附 `hs_err_pid*.log`；不用发 ROM、密码或令牌。

## 已验证与待验证

已有回执：12 款游戏共 52 次最终隔离 JVM 测试通过，含完整状态/音画恢复、真实 JAR 四实例 50ms 单向延迟模拟、投币、保存与新实例重开。主包/SFC/街机合计 3185 项测试，0 失败/错误、9 项既有跳过。上述测试发生在本次打包之前，本次只核对对应字节及打包完整性。

**Minecraft 最终组合启动、真人多人、整合包兼容、长时间弱网和实际手感仍待验证**。JNI 原生故障可能带崩 Minecraft；核心探针通过不等于稳定发行，不保证所有游戏都支持。

- MAME 的 `dino` 测试资源缺 `dl-1425.bin` 等匹配 ROM 集文件，代码不能补出游戏内容；同款 FBNeo Netplay 已通过，不代表 MAME 缺资源已解决。
- 特殊 NeoGeo 旧“本地同步”仍是兼容子进程，尚未迁移 JNI；不要把它与 FBNeo Netplay 混淆。
- 光枪核心回归通过，但本包没有完成 Minecraft 真人瞄准几何验收。
