# 方块电玩 Flash 播放盒原型

这是早期用来验证 SWF 游戏显示和输入的独立播放盒。它使用 Ruffle，不是 libretro 核心，也不是当前推荐整套方块电玩的必装附属。

**Flash 暂按开发验证机型保留。旧播放盒与当前电脑中的 Flash 程序入口不是同一个安装方案。** 想在当前电脑里测试 Flash，请看[电脑说明](../piq-computer/README.md)，不要同时安装这个旧播放盒 JAR。

## 兼容范围

- 独立播放盒最新保留版本为 prototype.8，匹配旧 FC56～FC61；依赖范围不接受当前 FC76 系列。
- 旧测试环境为 Minecraft 1.21.1、Java 21、NeoForge 21.1.236 起的 21.1 系列。本文不建议为它回退现用整合包，请使用独立测试实例。
- 该旧组合需要服务器和客户端都装对应主包与播放盒附属，因为共同注册方块、物品、实体及菜单授权消息。
- 真正运行 SWF 的客户端还需要配套完整 runtime 0.1.2、Windows x64、.NET Desktop Runtime 6 和 WebView2。服务器不运行这些组件。

运行库应位于旧测试实例的 `piq-flash-box/runtime/`，不能只放 EXE，也不能把它当 MOD 丢进 `mods`。电脑使用的 `game-console/piq-flash-box/runtime-stream-0.1.3/` 是另一套路径和配套，不要相互覆盖。

这些是历史原型依赖，不是生产环境推荐配置。GitHub 源码 ZIP 不是含运行库的安装包。

## 原型如何操作

仅在上述旧配套环境和测试世界使用：

1. 创造模式且具有 OP 权限时，放置“Flash 播放盒”，用视频线接电视并开电视。
2. 双手空着右键盒子，选择自己有权使用的本机 `.swf` 文件，点击加载；不能选网页、ZIP 或文件夹，入口上限 32 MiB。
3. 在预览里点击游戏菜单。P1 默认方向键＋空格，P2 默认 WASD＋左 Shift；这只是**同一电脑两套按键**，不是两位服务器玩家。
4. 点击“看电视操作”后，键盘控制游戏，鼠标仍转视角。Esc 退出按键接管，游戏继续；右键返回预览。
5. 需要结束时点击“停止”。失权、断线、离盒子过远或拆线等也会结束；失焦或进入其他菜单会释放输入。

其他游戏的按键配置与运行器构建见[runtime 说明](runtime/README.md)。兼容性按具体 SWF 验证，不因一个样本能玩就保证全部 Flash 游戏。

## 已知限制

- 只有本机游玩，没有远端玩家席位、Netplay、公开音画旁观或实体手柄领取。
- SharedObject 进度不保留，关闭后会丢失相应游戏进度。
- 画面使用截图和有损 JPEG 传递，存在压缩与延迟；声音来自本机 WebView 系统输出，不保证跟随 Minecraft 音量或空间距离。
- 外观是临时测试模型，没有正式生存玩法；世界内交互、混合光影和长时表现仍未认定稳定。
- 运行器限制部分外部请求，但不是恶意 SWF 安全沙箱。只测试可信文件，游戏内容不会随模组提供。

## 开发与资料

暂不将这个旧播放盒补成当前正式机型，也不因文档整理扩大它的主包依赖。后续开发先按[公共制作规范](../piq-fc-arcade/design/机器制作与交互标准.md)确认与电脑程序入口的分工，避免并行维护两套玩家流程。

Java 适配代码、Ruffle、WebView2 分别保留各自许可证，不统一改授。原型构建与验证记录见[历史 README](README-history.md)，完整文档导航见[文档索引](../piq-fc-arcade/docs/README.md)。
