# BlastEm 退役：保留旧数据，移除当前执行链

日期：2026-10-04。范围为 MD 源码中的 BlastEm 退役。该日全仓检查确认，实际生产调用只在 MD，其他组件没有该核心启动入口；外部制品清单中的历史记录不代表可用运行能力。

## 1. 本轮范围与复用

沿用现有固定 GX 和 PIQ Netplay 方案，不新增机器、核心、依赖或公共 API。已读共同 AGENTS、通用制作规范、功能制作模板、全组件接口总览、MD README／构建／能力声明和当前启动、保存、探针实现；不重新选择上游核心，不修改原生桥或 DLL。

| 需求 | 实现与验收 | 状态 |
| --- | --- | --- |
| R01 当前版本不能再运行 BlastEm | `MdProfile` 不提供旧 profile；旧命令仅拒绝；运行器在取得 owner、创建线程和读取 ROM／保存前拒绝旧 token | 已实现，自动验证见第 4 节 |
| R02 新包不携带或要求旧核心 | `verifyCores` 只校验两颗 GX；资源处理排除旧 DLL 并清理同名历史 build 输出，JAR 再排除；最终回归探针检查包中缺席 | 已实现；最终 JAR 由统一交付另验 |
| R03 旧数据原样保留、不能误读 | 不改旧目录／文件；拒绝旧保存命名空间请求；固定现有 GX 保存合同回归 | 已实现，未迁移用户进度 |
| R04 历史证据不当作当前使用说明 | README／能力说明标明退役；历史重建工具需显式参数且拒绝当前资源目录 | 已实现 |

本轮不补 MD 同步 RESET，不做家用机远端按键动画新开发，不新增主持容量，也不接 Flash／PvZ。实体、菜单、内容库、投币／租约、2P 弹窗、联网权限与关机保存的既有流程未被替换，不能据本轮宣称整机已全部达标。

## 2. 调用链、配置与兼容

| 行为 | 当前调用及不变项 | 旧请求处理 |
| --- | --- | --- |
| 私人开机 | `MdClient.Provider` → `MdEngine` → 固定 `MdProfile`，JNI／PROCESS 仍显式选择 | `BLASTEM` token 在构造时同步拒绝，不创建线程、不占 ACTIVE、不读 ROM／旧档 |
| 公开 MEDIA | 原 `MdPublicClient` → `MdEngine` 公开构造 → GX/JNI，服务器保存身份不变 | 不读取私人核心偏好；从未用旧核心作为公共启动后备 |
| JNI Netplay | 原 `MdNetplayProfile`／公共会话，原 PIQ Netplay DLL和独立命名空间 | 不受旧私人核心 token 影响，不降级为 MEDIA |
| 核心查询／旧命令 | `/gameconsole-md` 或 `core genesis` 只报告现有固定核心，不修改运行局 | `core blastem` 明确退役；未知 ID 明确拒绝，不自动选 GX |
| 旧配置／API | 原核心选择只保存在连接内存，没有持久化核心配置需要改写；保留拒绝专用枚举便于旧调用拿到准确错误 | 不能据枚举存在推断仍支持 BlastEm；profile／input／saveNamespace 全部拒绝 |
| 正常退出／busy | 活跃 GX 会话原 owner、保存确认及退出释放不变 | 退役失败发生在 owner 申请前，不留下 busy，不触发保存或备用启动 |

旧 BlastEm 的 `jni-v1/<旧 SHA>` 和 `process-v1/<旧 SHA>` 档案保留，当前不访问。GX 私人合同仍为 `jni-v1|process-v1/gx-v1/<GX SHA>/bb0002f5733b81d3c561b46b1123fbc9e8eb012651a2fa5c578cc2074d360422`；公开 MEDIA 和 JNI Netplay 身份未改。没有自动转换、旧 SRAM 导入或后台目录迁移。需要继续历史进度，先备份后使用原配套历史版本，不把旧档改名塞进 GX 目录。

## 3. 构建、许可与工具

新包必需的原生资源仅为固定 `genesis_plus_gx_libretro.dll` 和 `genesis_plus_gx_piq_netplay_libretro.dll`；原 SHA、来源与非商业许可仍有效。`src/main/resources/core/windows-x64/blastem_libretro.dll` 原件没有删除；它只是历史构建输入，新资源输出和 JAR 不采纳。`licenses/blastem/` 原始内容保留为历史许可证据，不表示当前包仍含或可加载该实现。

当前私人探针 `run_native_probe.py` 必须显式提供待测 FC／MD 包，不能默认拉起 alpha.3；旧核心参数在生成目录前拒绝。`run_legacy_regression_probes.py` 的 legacy 指原 GX MEDIA／私人路径，现校验两颗活动 GX 且拒绝含 BlastEm 的新包。`tools/build_core.py --historical-only` 仅保留历史重现，不得输出到当前资源目录，也不接入 Gradle。

客户端与服务端安装依据仍是本附属注册共同物品／方块／网络业务；本次无新协议、新持久化字段或服务端原生执行。MC1.21.1、Java21、NeoForge 下界继承共同构建策略；完整配套、最终 SHA 与发布状态以对应版本说明为准，不拿旧包充当新成果。
