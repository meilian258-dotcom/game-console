# MD9 · 手柄按键动画补齐

日期：2026-10-02。修改者：像素匠。状态：实现及本轮自动验证完成的测试候选；Minecraft 图形客户端与多人实网待验，未标稳定。

## 1. 本轮范围

MD8 只有共享双手持握姿势，没有按键动态渲染。MD9 补齐十字键上下左右倾斜、A/B/C、X/Y/Z、START 及模型后缘 MODE 键按下／回弹；保留 MD8 朝向、SOKA 标识、卡带封面与菜单／标牌修复。

本机第一/第三人称按真实 canonical 输入响应，改键及实体手柄均适用；公开会话其他附近玩家可看到授权控制者按键。私人输入不上传。菜单、失焦、换手/租约、归还、超距、关机和断线清理；1P/2P 独立，不串键。GUI、掉落及停放模型保持静止。

不变：核心/原生库、ROM、存档格式/归属、联机方式、设备交互距离、AV 线和主模组。未实现的 Netplay/服务端托管/本地同步仍不开放。

## 2. 复用与实现依据

2026-10-02 已阅读共同 AGENTS、通用机器规范、功能制作模板、附属基线、本模块 README/构建与源码。沿用固定 Genesis Plus GX / BlastEm 适配，未更换核心或新建 Libretro 机器，故无需新增上游依赖。

| 来源 | 采用方式 |
| --- | --- |
| FC `ClientControllerAnimation` / `ControllerButtonRenderer` / `ControllerFramePresentation` | 复用身份校验、完成帧/短按锁存、缓存 baked quads、PoseStack 分件变换思路；不复制 FC 八键位或误用 FC 私有类 |
| 共享 `ControllerPose` / `KeyboardInput` / `GamepadInput` | 持握姿势、重新绑定后的 canonical 键盘与实体手柄输入继续调用原接口 |
| MD `MdProfile` / `MdEngine` / `MdPublicClient` / `MdPublicServer` | 使用核心 remap 之前十二位输入；私人核心帧完成后采样；公开本人用最终混合输入，其他玩家用服务器验过租约/距离/序列的输入 |
| MD 原始具名模型及 MD8 派生工具 | 按具名元素分件而非邻近包围盒猜测；原 PNG、SOKA 与桌面模型不改 |

FC 现状需区分：共享持握姿势可以被其他玩家看到；FC 的 `ClientControllerAnimation.state()` 将动态按键限制在本人第一人称及本人 F5 第三人称，其他玩家仍是静态按键。MD9 复用姿势/输入思路，并新增 MD 自有的附近公开按键显示；本轮没有修改 FC 来扩展其远端按键动画。

## 3. 兼容和验证范围

只更新 MD 至 alpha.9，主包继续 FC76.33；新增 MD 私有只发往客户端的轻量动画载荷，协议 `md-public-2`，客户端/服务端均须更新 MD。协议不传 ROM/音画/私人进度，不新增控制权限。

公开视觉包最多每 2 tick 更新，10 tick 保活；只给同维度、在线存活、追踪该操作者且在其 32 格内的接收者，单次最多 64 人。客户端最多保留 64 条远端状态，1 秒失效，按连接/主机/租约/端口/实际手持物品校验，不为动画强加载主机区块。生命周期清零与正常松键分开，短按锁存只作用于显示，不重新注入游戏。私人完成帧另有视觉代次，旧帧不能在换手清零后再次点亮。

已按第 5 节完成输入与模型自动验证、最终包原生核心回归及组合专服启停。离线预览不是 Minecraft 图形实测。真实游戏内动画、远端多人及弱网手感待验收。

## 7. 真人验收步骤和已知边界

1. 领取 1P/2P 手柄，先看第一人称，再按 F5 看本人第三人称；十字键向正确方向倾斜，ABC/XYZ/START 及实际映射 MODE 按下/松开对应正确。重绑键盘、使用实体手柄再重复，不得只认默认物理键。
2. 两人分别控制 1P/2P，互相看对方第三人称；公开输入的动画可见且不串端口。第三位附近玩家只看见外观，不因此取得操作权限；私人输入不发送给他人。
3. 连点、短按、组合按键后打开菜单/切出窗口/换手/归还/超距/关机/断线，确认不粘键。保持别人正常输入时清自己的席位，不能把对方按键一起清掉。
4. 从远处返回、主机区块未加载但操作者可见、重连和重借柄场景，确认不会复活旧动画；GUI、地上掉落、主机停放手柄保持静止，SOKA 和持握方向没有倒退。

本版没有新增 MD Netplay、本地输入同步或服务端托管，也没有修复所有机型的远端动画。多人弱网、实际渲染帧率、长时资源消耗、真实客户端观感尚待验证；自动通过不等于整机标准全部完成。
