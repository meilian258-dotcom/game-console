# MD2 附属能力声明

## alpha.3 / 已有 FC76.28（2026-09-30）

- 默认官方 Genesis Plus GX v1.7.4 c2838c7，通用 JNI；旧 BlastEm 与进程路径显式保留，不自动回退。新核心资源固定SHA，未修改上游DLL，完整非商业许可随包保留。
- 延续 alpha.2 实体内容卡/老式电脑拷卡/AV/电源/私人1P；本轮主包和公共桥未改、不要求新版主包。两端同换MD3，当前实测主包76.28。
- 新核心六键映射、44.1kHz→48k音频、运行时画面比例、首次运行前恢复裁剪SRAM；新旧核心/关键选项/后端档隔离，不迁移旧即时档。
- 本机 `/gameconsole-md core genesis|blastem` 选择下一次核心，已开机/下载中/保存中拒绝切换；退出连接复位Genesis。全服没有新配置。
- 官方Netplay支持是选型依据，不是MC功能：当前回滚探针状态/音频不一致、SRAM不随核心状态回滚；没有开放MD多人/旁观/Netplay，也未改FC/SFC现有联机。
- 12项单元、新核心两后端各28项/旧核心各19项诊断、七包专服Done与正常退出通过；MC真人/旧世界/长时与6键逐键手感待验。详见[MD3说明](MD3-GenesisPlusGX.md)。

## alpha.2 / FC76.27（2026-09-30）

- 增加服务器内容卡：老式电脑服务器目录选取 / 本地明确上传写卡、不可变 SHA256 内容身份、8 MiB 普通 MD ROM 上限。全服读/上传权限沿用管理终端；不是卡带内嵌 ROM，不做跨服自动搬运。
- 实体电源经公共按钮/遮挡/保护校验、MD 借用租约和内容校验后启动既有运行器。默认 JNI；本机本次连接可显式改兼容进程，不能运行中切换或静默失败回退。
- 仍是私人单人、本机个人存档；无公共双人、旁观串流、Netplay、服务器执行核心、CD/32X/交错 SMD。卡带内容与游戏进度分开，个人旧档保留、不冒称随卡进度。
- 复用公共 `ContentCards` 内容与传输服务、`HomeHardware` AV、`HomeApplianceService` 电源、`PrivateHomeClient` 运行/保存；MD 仅提供格式校验、物品、按钮模型坐标及核心 profile。服务器不加载原生核心。
- 中文用途、安装端依据和验收边界见 [alpha.2 指南](MD2-拷卡与实体开机-20260930.md)。两端须同时升级主包76.27和MD2；不是稳定SDK或稳定发行。

## alpha.1 历史声明（保留）

2026-09-29，像素匠。这是实现与验收范围，实际通过层级见README和本轮VERIFICATION，不把规范当实测。

- MC 1.21.1 / NeoForge 21.1 / Java 21；共同前置方块电玩主包76.24，两端安装（公共方块、物品、实体与客户端运行器）。不重复携带平台或 JNI 桥。
- 第一版闭环：用户提供的 MD2 空槽/插卡双状态、实体卡带和可借还手柄、公共 AV 线接电视、私人单人本机运行。复用公共私人菜单、输入捕获、距离6格、电视显示/音量与停止保存流程。
- 默认独立进程；每次显式确认可选 Windows x64 通用 JNI。原生崩溃会影响 MC，单 JVM 一个 JNI 活动槽。试验档与进程档隔离。
- 普通 MD 卡带内容 .md/.bin/.gen，按内容 SHA 隔离；初版不提供服务器 ROM 目录、上传、公开局/双人/旁观、Netplay、本地确定性同步、服务端托管。公共电源不伪称已启动公开游戏，提示私人入口。Sega CD、32X、压缩包/交错 SMD 不开放。
- 使用固定 BlastEm 核心，必须核对来源、SHA、许可、几何/音频/输入/保存；最终版本与 SHA 在 README 回填。
- 保存复用公共 PrivateSaveStore 原子/备份/锁规则，按个人+服务器+内容+核心/后端身份；支持核心实际暴露的状态及 SRAM，未暴露 RTC 不虚构。初版物理卡带是设备占槽物，不把本地路径写到服务器，也不声称已有跨玩家卡带存档。
- 全服权限和租约使用服务端实体/身份、MC 正常交互/保护、6格距离。没有新全服配置，不另造终端权威。键位/核心试验是本机偏好。
- 必须通过自制诊断 ROM 的进程/JNI 音画输入与保存重开、硬件几何四朝向与资源检查、最终 JAR 专服加载；MC 模型/真人体验另列待验。模型源和许可来源保留；用户素材公开分发许可仍待服主确认。

后续公共多人等是未实现能力，不因 DLL 支持两个手柄或存档就开放入口。
