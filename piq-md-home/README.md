## 沿用：MD7 + FC76.32 公开玩法（2026-10-02）

MD 默认公开 **JNI / Genesis Plus GX 玩家音画串流**：一个开机玩家运行核心，两个有独立租约的实体手柄可控制各自端口，附近玩家通过共享 Watch 自动旁观；操作端和旁观端都不需要选择私人 JNI，也不向他们下发游戏 ROM。不是 Netplay；本地同步、服务端托管、Netplay 仍不可用。

操作沿用 FC：老式电脑拷卡/封面 → 接 AV 线并开电视 → 插卡 → 主机电源 → 选择存档及是否允许 2P → 领取对应手柄。卡带工作台可设最多 2 人；开局选择只在卡支持两人时显示。任意一方收起手柄、开菜单、失焦清零自己的输入；归还/超距只收回该手柄，不替另一位松键，也不让主持核心关机。主持留在同维度但走远时停止自己的本地音画呈现，仍为电视附近的玩家供画面；主持退出/跨维度、关电视/拆线/拆主机则结束。

服务器存档沿卡设置：不存档 / 卡带一份共享进度 / 每玩家 **MD 总共三槽**（不是每款游戏三槽）。自动检查点、手动保存、正常结束均等服务器确认；旧进度在新保存成功前保留。卡带存档跟卡 UUID，可换玩家继续；个人档不写入卡。存档库复用公共卡带管理页面、归属/权限与删除确认；私人旧档不自动迁移。

螺丝刀仍开共用设备页。其“私人模式”按钮进入 MD 本机设置，可切换“下次开机公开 / 私人”，等待服务器确认后生效，仅影响本机本次连接。私人模式保留旧核心/进程选择及原独立个人本机档，但卡带归属存档不能被暗中改成个人本机档：要继续卡带档请使用公开模式。公开模式固定 GX/JNI，不受私人核心偏好影响。“手动保存公共会话”仅由当前本机主持执行。

本批需要客户端、服务端同时安装 FC76.32 与 MD7；内容卡协议 `content-card-4`、存档库协议 `cartridge-save-2`、MD 公共协议 `md-public-1`。GBA14 等其余五个 JAR 沿用。主包只增加可复用的内容卡和设备设置扩展，没有 MD 名称分支。安装端仍为两端，原生模拟仅运行在开机客户端；受支持运行端目前 Windows x64 / Java 21，保留现有核心许可限制。

使用、安装和最终验证见[本轮交付指南](design/MD公开会话与服务器存档-20261002.md)，实现细则见[MD7设计与验收](design/MD7-公共玩家串流设计.md)。自动测试/实际核心探针不等于 Minecraft 多客户端真人验收；双人实机输入、晚加入/距离旁观、保护插件、视觉与长时游戏仍需验收，本包不标稳定。实际冻结制品和管理台状态以根维护手册的交付记录为准。

## 历史：MD alpha.2 + 主包 FC76.27（2026-09-30）

本轮补齐老式电脑写入 MD 内容卡、实体电源启动与 AV 交互优先级。两端同装 FC76.27 和 MD alpha.2；MC 1.21.1、NeoForge 21.1.236+ 的 21.1 系列、Java 21，实际执行端 Windows x64。完整步骤、权限、回退和验收范围见[本版指南](design/MD2-拷卡与实体开机-20260930.md)。

1. 手持 MD 卡带右键老式电脑。点击服务器游戏条目写卡，或点“本地游戏：选择后上传并写卡”，明确上传合法 `.md/.bin/.gen` 文件；沿用管理终端游戏库/上传权限。原件不修改，不内置游戏。
2. 放 MD2 与电视，使用 **AV 线**依次点两端；街机通讯线不能代替。打开电视，再持写好的 MD 卡带右键主机插入。
3. 空手右键借出 1P 手柄，准星对准机身顶面米白色电源滑块右键，默认以 JNI 启动卡中指定游戏；再次点电源关机并保存。只有自己看到画面，尚无 MD Netplay / 公共双人 / 旁观串流。
4. 手持手柄操作，租约范围仍为主机 6 格；切换物品、打开菜单或失焦释放输入/暂停；超距、断线、关电视/断开连接会安全停止。归还手柄后，空手 Shift+右键主机拔卡。
5. 兼容进程保留：关机并等保存完成后，执行 `/gameconsole-private cartridge-runtime process`，再点实体电源；`jni` 或 `default` 恢复。只影响本机本次连接的内容卡家用机，不改 FC/SFC 私人页。两种后端存档仍隔离，不转换旧档；JNI 原生故障可能带崩 MC。

卡带保存的是服务器内容身份，不是 ROM 字节或个人进度。同服可传卡，跨服必须同时提供对应服务器内容；本轮没有实现随卡跨玩家进度。MD 不再通过私人页的任意本机路径绕开实体卡，原私人进度按个人/服务器/核心 SHA/ROM SHA/后端保留。

构建默认依赖主包76.27，可用 `-PgameConsoleJar=` 显式覆盖到兼容构建。新增的 `ContentCards.Adapter` / `ContentCartridgeItem` / `PrivateHomeClient.Provider.cartridgePower()` 为共享扩展，不在主包散布 MD 名称特判；其他 provider 默认不启用此路径。未绘制 MD 外接 AV 线实体，不能把连接修复称为线模型完成。

本版测试与待验项见指南；下面 alpha.1 的默认进程、路径输入、空卡占位和旧验证属于历史，不是 alpha.2 的当前用法。

## 使用

1. 在创造模式“方块电玩”末尾找到 MD2 主机和 MD 卡带，或用配方合成。手柄不额外合成，是机器借用物。
2. 放主机/电视，用主包 AV 线连接；先连接再交互主机。持 MD 卡带右键插入，空手右键借出1P手柄；背包需要空格。
3. 手持借用手柄，在主机6格内输入 `/gameconsole-private`，填本机普通 MD ROM 完整路径（`.md/.bin/.gen`）。原文件不上传、不修改。
4. FC76.26 起默认 JNI；可点私人页“本次私人启动”切回进程，重新打开页面采用 JNI 默认。同一 JVM 只允许一个 JNI 核心；JNI 原生故障可能使整个 MC 崩溃，使用独立存档、不导入旧进程档。FC76.24 的旧页面默认进程。
5. 关闭菜单继续玩；失焦/菜单暂停并释放按键。手柄超6格、断线/换世界/取走硬件等使私人会话停止并请求保存。
6. 手持手柄右键原主机归还；空手潜行右键取出卡带。先归还才能拔卡，不吞其他机器的手柄。重载世界取消旧借用票据，旧票据不能控制机器。

初版只接**私人单人**。电视仅本人看到游戏，不向他人发布音画。公共电源不会假报“公开游戏已运行”。两只手柄模型保留，1P借出隐藏，2P目前仅模型，不能加入；无服务器游戏目录/公开双人/Netplay/服务端托管、CD、32X、SMD解交错或 BIOS 功能。物理卡带是插槽物，本地文件通过私人菜单选；尚不是可携带跨玩家进度的内容卡。

键位复用公共 SFC 12位可配置布局（F7）。对应 MD：SFC B→A、A→B、R→C、Y→X、X→Y、L→Z、Select→Mode、Start→Start。默认 WASD方向、J/K/P为ABC、L/I/O为XYZ、退格Mode、回车Start。N切换移动锁；不是新增一套独立MD键位页。
