# 方块电玩 MD

在 Minecraft 中摆放 MD2 家用机，插入自己准备的游戏卡带，通过电视和六键手柄游玩。它是[方块电玩主模组](../README.md)的可选附属，不是独立模拟器，也不包含游戏 ROM。

本组件仍为测试候选。先看[统一玩家指南](../piq-fc-arcade/docs/玩家指南.md)了解安装、公共按键和联机术语；本页只说明 MD 的差异。

## 安装条件

- Minecraft 1.21.1、Java 21、NeoForge 21.1.229 及以上的 21.1 系列；其他模组可能要求更高版本。
- 多人服务器和参与客户端都安装配套的方块电玩主包与 `game-console-md-版本.jar`。只玩单人时装在客户端实例即可。
- 实际运行 MD 核心的客户端目前支持 Windows x64。JNI Netplay 的参与者和旁观者也会在本机运行核心；普通音画串流的观众只接收音画。
- 不要另装内部 `piq-retro-platform` JAR，也不要混装同一模组的多个版本。以收到的整套候选包说明为准，GitHub 源码 ZIP 不是安装包。

两端安装是因为本附属注册了主机、卡带、方块实体和交互消息；不是要求服务器执行 MD 核心。

## 从拷卡到开局

1. 手持 MD 卡带右键老式电脑，在工作台选择游戏并确认写入；上传本地游戏需要服务器允许。
2. 放置 MD 主机和电视，用主包的视频线连接两端，打开电视，再把写好的卡带插入主机。
3. 右键主机实体电源。按卡带设置选择存档；支持双人的公开游戏会单独询问是否允许第二名玩家加入。
4. 加载完成后领取对应手柄。允许双人时，朋友可领取空闲的 2P 手柄加入。按 F7 查看或修改键位。
5. 手持手柄右键原主机可归还；归还手柄不等于关机。正常关机并等待保存完成后，可空手 Shift＋右键主机退卡。

本地 ROM 放在实例内 `game-console/content-cards/piq_md_home/md/`，接受经校验的 `.md`、`.bin`、`.gen`；封面目录为 `game-console/content-card-covers/piq_md_home/md/`。工作台的目录按钮会打开对应位置。服务器库存与本地目录不同，见[内容和 BIOS 管理](../piq-fc-arcade/design/服务端内容目录与街机BIOS-20261003.md)。

## 运行方式有什么区别

- **玩家音画串流**是默认公开方式：开机玩家运行官方未修改的 Genesis Plus GX，其他人通过服务器接收音画，手柄输入返回主持端。
- **JNI Netplay**是可选实验方式：参与客户端各自运行独立的 Genesis Plus GX PIQ Netplay 核心，同步本局输入和状态；旁观不占操作席。它不是 RetroArch 的联网模式，也不承诺低延迟预测回滚。
- **私人模式**只供本人游玩，不外发游戏输入、音画和进度；使用普通 Genesis Plus GX，与公开档隔离。

管理员可在关机、保存结束后用螺丝刀打开设备设置，选择已实现的方式，下次开机生效。普通本地输入同步、服务端托管和 RetroArch Netplay 尚未接通；不可用按钮不是通过修改名称或安装任意 DLL 就能解锁。

JNI 是调用核心的方式，不等于联机模式。原生核心故障可能带来 Minecraft 进程退出，请先在测试世界使用。

## 存档与已知限制

- 公开玩法提供不存档、卡带档和个人档。个人档是每位玩家 MD 总共三槽，不是每款游戏三槽；卡带档跟随实体卡身份。
- 音画串流、JNI Netplay、私人模式及旧核心存档互不自动转换。切换模式后看不到旧档，不代表旧档被删除。
- JNI Netplay 暂不支持同步 RESET；需要重新开始时正常关机，再通过开局界面选择从头开始。
- BlastEm 已退出当前运行和打包链，不是当前可选核心；旧档保留，不自动迁移到 GX。CD、32X 和特殊外设未在本附属开放。
- MD15 已修正物品栏主机越格及卡带朝向；配套 FC76.43 修正公共光影混合通道。见[修复与待验说明](../piq-fc-arcade/design/光影透屏与MD图标修复-20261006.md)，仍需实际游戏复测，不能把自动测试通过当作全部游戏、光影或多人场景稳定。

## 开发与许可

开发先读[构建说明](../source-control/BUILDING.md)和[公共流程总览](../piq-fc-arcade/design/全组件运行流程与复用接口总览.md)。普通核心来源与准备方法见[GX 接入记录](design/MD3-GenesisPlusGX.md)；独立 Netplay 核心的补丁、重建和对应源码要求见[核心构建说明](native-genesis-netplay/README.md)。不要用同名任意 DLL 替换固定构建输入。

详细实施与验收见[JNI Netplay 记录](design/MD-JNI-Netplay-20261003.md)。旧版本说明完整保留在[历史 README](README-history.md)，不按旧步骤安装当前版本。
