# test.3 验证与实机检查

本版只对玩家位置扩展和既有握手适配负责。所有自动检查不等于已完成 Minecraft 画面验收。

## 自动验证范围

- 原录像独立标量解析与快速模式数值坐标对比，以及正向、反向和重复跳转。
- 对完整 Minecraft 瞬移包类应用实际 Sable Mixin 后执行解码：缺标记的快速位置包失败，补原始标记后能够读取，坐标保持。
- 生产索引的同毫秒顺序、未知标记、生命周期、销毁与 ID 重用、世界重置、玩家身份及读取限额。
- 生产注入点的真实 Sponge 转换、原方法主体保留，以及限定快速合成包的作用域。
- 缺失标记时的普通世界证明、载具空间/未知边界拒绝，以及当前线程、世界、接收连接和容器身份检查。
- 使用实际 Sable 类解析反射签名；未知处理器字节拒绝，不只校验位置包序列化器。
- 原录像只读校验、JAR 元数据/资源/许可及交付校验和。

按 [README](README.md#构建) 执行构建及三项检查，不带私人输入时即可运行便携测试。结果只在本机 `build` 中生成；本仓库不提交原始运行报告、录像或缓存。没有执行游戏画面、真实多人、实际声音、光影或视频导出验收。

test.3 最终成品：生产行为、索引、边界和真实包解码 1825 项检查通过，四组 Sable 合同门控通过；5 个生产 Mixin 的真实转换 219 项通过。当前录像的实际快速引擎生成 453 个玩家位置包，在独立 Sable 容器证明夹具下全部补齐，原先 4 个未知标记仍保持未知、未触发回退，306 个非玩家位置包不改，5007 项断言通过；旧录像 8 包另有 92 项断言通过。

以上计数来自 test.3 原交付验证，其中实际录像样本仅在本机使用，不随源码分发；独立克隆不承诺复现相同的样本计数。边界测试中的模拟世界、独立 Sable 容器与真实类签名检查，不等于 Minecraft 当前世界的运行时验证。完整 Minecraft 生命周期中的自动回退、图形显示和 HUD 点击仍待验收。

历史 test.2：生产行为、索引和真实包解码 1652 项检查通过；5 个 Mixin 的真实转换 219 项通过；8 个样本位置包解码成功。这些旧结果不作为 test.3 的新结果。

## 安装后的短测试

1. 打开同一份录像，在普通模式找到可见玩家，并暂停。
2. 按 Q 进入快速模式，检查同一玩家仍在正确位置。
3. 在 B 列表勾选并跟随该玩家，确认镜头落在玩家处，而非空白区域。
4. 前后拖动时间线，暂停后再播放；重复进入和退出快速模式两次。
5. 退出录像再打开，重复第 2、3 步。
6. 对此前会自动退回的录像，先测试开头，再向前后跳转；在普通世界检查玩家位置与普通模式一致。不要以仅仅“没退出快速模式”代替位置正确的验收。

如果出现“玩家位置仍无法安全恢复”提示，补丁会返回普通模式并暂停。保留提示中的原因和日志，确认普通播放和时间跳转仍可使用；不要为绕过提示删除录像或缓存。载具区域不能因为普通世界修复通过就视为完整兼容。

如仍看不见玩家，保留 `latest.log`，并记录是在 Q 切换、B 跟随还是拖动后出现，以及普通模式是否正常。不必公开包含玩家身份、地址和聊天的完整录像。
