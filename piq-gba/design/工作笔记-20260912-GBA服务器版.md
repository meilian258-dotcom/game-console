# GBA 服务器版交付笔记

日期：2026-09-12。维护者：像素匠。

## 实现范围

本版实现 GBA 服务端附属接入、自动验证和测试打包，不包含安装部署或 MAME 性能优化。ROM、BIOS、存档和既有模型不变。

GBA 现在能作为附属在多人 Minecraft 服务器的共享街机入口使用：一个真实控制席，附近玩家自动旁观；保持 GBA 核心仅在主持者 Windows x64 客户端的独立子 JVM 执行。服务器只注册公共后端、管理权限、验证/转发有界音画，不加载 DLL/JNA，不收取 ROM。观众不占 P2，不需要原生运行库或游戏文件。

这不是 GBA 原生串线：不支持宝可梦交换/对战、两掌机多核同步、P2/3/4 或手持 GBA 模型屏幕。现有单柜/双柜外形均仅一个席位。掌机模型保持原样，未导入成新玩法。

## 关键实现

- FC31 `CabinetBackends.registerNetwork(id,1)` 显式声明单席。`CabinetSeats.capacity/validCapacity` 统一真实端口数和拓扑；Ledger 接纳1席；Rooms 无链接 min(2,supported)，1席不创建邀请 gate、拒 P2、不串联，仍复验真实连接/玩家/硬件/保护与租约。
- `cabinet-room-3` 是必选新协议。旧 room-2 Assignment 解码不接受1，不能混用FC30；无新增数据字段，旧2/3/4席授权和旁观路径保持。
- `CabinetBackend.prepareFactory(registered, selection, playerId, connection)` 是兼容默认接口，在客户端主线程捕获不可变开局上下文；旧附属返回同一个 factory，不多开核心。异步工厂仍在 STARTER。同步回调后复验 launch/connection/generation/backend/key/current，异常只关闭仍属本次的会话，不复活或误停新局。
- GBA2 捕获当前完整世界路径或服务器地址/端口、玩家 UUID、原连接对象。worker 只用冻结的 runtime/savePath/Connection，不在切服后重新读取 Minecraft。旧无 context `open(Path)`、误在主线程开核心和已断旧连接均拒绝。
- 保存目录：`piq-gba/saves/scoped-v1/<context SHA256>/<player UUID>/mgba-e31759b/<ROM SHA256>/`。同服同人同ROM跨柜共用，不同服/世界/人隔离。不是服务器云存档。旧 alpha1 未分作用域的 saves 保留字节/时间，不自动读取迁移。每300模拟帧/正常退出的电池存档算法未改。
- GBA10个输入键、核心、重采样、进程/队列/超时、SaveStore 均沿用原版；只新增 GbaSaveScope 与 Backend Launch 两类。FC所有166条受保护 assets/data/core资源保持原字节。

## 验证结果和边界

1. FC Java21离线完整 check/jar：1305项，失败/错误0，保留原7项环境skip；构建前后FC与retro-platform src/构建输入哈希一致。最终JAR相较FC30只10个class条目和2个版本元数据改变，无新增/删除，166受保护资源一致。
2. 最终GBA核心：原创ARM诊断+真实固定mGBA，共98434断言（多数逐字节存档计数，不是9万种功能），真实RGB565/PCM/十键/SRAM保持；进程/存档重启27断言；真实FML GBA2/FC31注册29断言。
3. `checks/gba-server-final.json`：四包/五Mod ID，1686个唯一class；1726 common/FML断言（多数class去重），3792状态/21次真实outer codec回读及截断/非法界限、2项邀请字节码门禁，旧SFC18/Native10实际实例/default factory15断言。隔离common类加载器禁止client/bridge/JNA/LWJGL，实际尝试0。不是ModLauncher/专服完整启动。
4. `checks/gba-context-final.json`：38实际Scope/Store IO断言，78最终Backend/真实Connection边界断言。旧存档bytes/mtime、各服各玩家隔离、旧连接断开但新连接仍活跃等均通过。
5. `checks/gba-factory-final.json`：真实默认工厂方法身份保持；1241断言含96条实际编译后guard有界解释路径，旧回调不会复活/误停新会话。字节码解释不是运行中的Minecraft线程竞态测试。
6. 最终验证全部只编探针、不重编生产，分别绑定实际最终JAR SHA。打包逐项核SHA/CRC/路径/资源/对应源码、回读ZIP；旧包未覆盖。

没有启动用户游戏、远程socket、Minecraft世界或专用测试服务器，没有使用商业游戏实测。旁观画面、保护插件、实际多机网络、GUI/按键仍需用户在备份测试环境验收。旧共享旁观16格入/20格出、8人每源、20fps预算保持；主持者退出、掉线或离开街机原8格范围结束本局，没有迁移/全离线后台执行。

## 再现工具

- `piq-fc-arcade/tools/build_gba_server31.py --output <不存在的新FC阶段>`：完整构建+源码围栏+白名单资源保护。
- `piq-gba/tools/build_gba_preview.py --fc <FC31.jar> --output <不存在的新GBA阶段>`：独立GBA编译与真实子进程测试。
- `piq-gba/tools/check_gba_final.py`：原生与FML最终JAR复验；`check_gba_context2.py`：作用域/连接最终JAR测试。
- `piq-fc-arcade/tools/check_gba_server31.py`：单席/旁观/协议/专服侧隔离/可选旧附属兼容；`check_prepared_factory31.py`：启动上下文门禁。
