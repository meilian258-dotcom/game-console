# GBA 单人街机试玩

这是可选独立附属，需要先安装配套 **FC 主模组 alpha30**；主模组不在这个 ZIP 里。

## 手动放置文件

1. `mods/piq_gba-0.1.0-alpha.1.jar` → 游戏实例的 `mods` 目录。
2. `piq-gba/runtime` 整个目录 → 游戏实例根目录下的同名路径。里面的 helper、JNA、DLL 必须成套，不要放进 `mods`，也不要覆盖原 Native 的运行库。
3. 其余说明、checks、licenses-and-source 是随附验证和许可资料，不需要放进游戏。

本包没有自动安装或启动游戏。请先保留原来的整合包和存档备份；不要把开发目录、旧候选或单独的内部 helper 当作 MOD 安装。

## 如何试玩

仅 Windows x64 / Java 21、本地单人世界；不支持已开放 LAN 的世界或远程服务器。

在现有街机上 **Shift + 右键**，选择 `GBA · 单人试玩`。通过游戏目录按钮放入你有权使用的 `.gba` 文件，选中后确认。普通右键沿用 FC 通用街机当前的启动/退出操作。

当前复用共享 **街机（ARCADE）** 按键配置，核心接受方向、A/B、Start/Select、L/R 十键。X/Y 不是 GBA 按钮；尚未新增独立 GBA 配置页或模拟 GBA 掌机的物理按钮布局。

**这一版是街机上的 GBA 后端，不是手持 GBA。没有掌机屏幕、GBA 连接线联机或多人功能。** 用户提供的 GBA 模型尚未放入游戏，不改其原模型比例或贴图。

## 存档

电池存档在 `piq-gba/saves/mgba-e31759b/<ROM的SHA256>/`，同实例同 ROM 在不同本地世界间共享。每 300 帧及正常退出时保存；突然关闭可能丢失最近约 5 秒。不是 FC 的个人三槽或即时存档菜单，也不会自动读取、覆盖原 ROM 旁的 `.sav`。

主档损坏但备份有效时可恢复；下一次保存保留坏档为 `sram.corrupt-*.bin` 后写回。不要在运行期间手动改动这些目录。

## 来源、验证和限制

配套核心是官方 Libretro mGBA `0.11-219-e31759b`，并非稳定版0.10.5。完整对应提交源码、MPL-2.0、JNA 和 PIQ 源码/许可证放在 `licenses-and-source`。官方源码原样保留上游开源诊断测试资产，但没有作为试玩游戏安装或运行；不附商业游戏或 Nintendo BIOS。

实际测试用原创 ARM 诊断 ROM 验证了 240×160 RGB565、十键、音频、SRAM 保存/恢复和独立进程关闭；并用真实 FML 和最终 FC30 注册器复验。报告在 `checks`。**没有启动 Minecraft 世界做游戏内实机验收，不保证所有商业游戏或特殊传感器卡带兼容。**

原生核心仅在自有子 JVM 内运行，Minecraft JVM 不加载该 DLL。文件哈希、内存/队列、超时都有边界，但这不是操作系统安全沙箱，请只使用可信合法 ROM。

原型最初对 FC29 API 编译，最终交付另行对本包说明指定的 FC30 JAR 复验；`checks/required-main-mod.json` 记录需要的主包 SHA。用 `SHA256.txt` 可核对本包每个文件，不要混用别版 helper 或核心。
