# GBA 经典横版模型

紫色初代横版 Game Boy Advance（AGB-001）外形，不是翻盖 GBA SP。采用适合 Minecraft 的低多边形方块与斜面造型。

## 尺寸与文件

16 模型单位等于游戏内 1 格。成品宽 **8.5 单位（0.53125 格）**、厚 **1.443 单位**；包含边缘端口的总深度为 **4.922 单位**。模型底部落在 Y=0，主体以 X/Z=8 为中心。

- `GBA_经典横版_单张UV.bbmodel`：在 Blockbench 中继续编辑的主文件，包含分组和内嵌贴图。
- `gba.json`：Minecraft Java 静态模型导出，不包含运行时按键动画。
- `GBA_完整UV.png`：唯一主贴图，2048×2048 PNG。
- `皮肤区域.json`、`UV_透明线框.png`、`UV_部件索引.json`：区域坐标、叠加参考线框与逐面索引。
- `按键映射.json`：按键组名、枢轴与按下位移参考。
- `预览_正侧.png`、`预览_俯视.png`、`预览_背面.png`：模型预览。
- `gba_manifest.json`、`tools/validation_gba.json`：模型清单与独立验证结果。

## 替换屏幕与皮肤

屏幕区域在主 PNG 的 **x=880、y=32**，大小 **720×480 像素**；坐标从图片左上角开始，区域为 x=880…1599、y=32…511。屏幕宽高比为 3:2。

将自己的 **240×160** 游戏画面等比放大 **3 倍**后覆盖这个区域即可。像素画建议使用“最近邻”缩放，避免像素边缘变糊；可先参考 `屏幕模板_240x160.png`。不要缩放整张 2048×2048 贴图，也不要移动其他 UV 区域。

**必须保留 PNG 的透明背景和透明区域**。正面机壳皮肤与按键压纹等使用了透明遮罩，填实透明区域会出现多余矩形面。`UV_透明线框.png` 仅供编辑时叠加参考，保存最终皮肤前请隐藏线框图层。

在 Blockbench 内编辑时，将纹理面板中的主纹理重新载入修改后的 PNG，再保存 `.bbmodel`，即可同步更新其内嵌贴图。游戏内实时换肤是否可用、如何指定皮肤路径，取决于你的 FC 模组导入方式。

## 按键与游戏内使用

独立按键组为 `dpad`、`button_a`、`button_b`、`button_start`、`button_select`、`shoulder_l`、`shoulder_r`；电源滑块另有 `power_switch` 分组。十字键目前为一个整体，可围绕枢轴做倾斜。按键文件中的位移以模型单位计，**只是动画制作参考，不代表已绑定游戏输入或安装动画**。

`minecraft_assets` 仅提供模型与贴图资产片段，命名空间为 `gba`；主纹理引用为 `gba:block/skin`。它不是可直接启用的完整模组或资源包：没有配置方块 ID、方块状态、物品映射或 FC 模组导入规则。后续需按服务器及模组实际格式接入；普通 Java 模型 JSON 不保留可驱动的按键骨骼。
