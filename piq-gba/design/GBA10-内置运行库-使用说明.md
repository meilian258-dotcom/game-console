# GBA10 内置运行库测试版

2026-09-26，适用 Minecraft 1.21.1 / NeoForge 21.1.236 / Java 21。

## 安装

退出游戏并备份后，替换两个 JAR，旧版本移出 mods 保存，不要同 ID 并装：

- 主模组 `game_console-0.31.0-alpha.76.3.jar`
- GBA 附属 `game_console_gba-0.1.0-alpha.10.jar`

多人服务器和参与客户端均安装这两个版本；服务端需要共同的物品注册和机柜通信声明，不能仅从依赖 side 判断。街机0.1.5.1、SFC41、电脑4、PvZ8保持原配套，不需要更换。GBA10明确拒绝FC76.2及更早主包，因为缺少内置来源注册接口；主包没有增添GBA二进制，三库只在GBA附属JAR中。

## 首次启动

模组加载完成阶段自动检查和准备运行库，不需要再手动复制 DLL、helper、JNA，也不需要下载离线 ZIP。固定三库仍是原mGBA e31759b/JNA5.14.0/helper，没有更换核心版本。

目标目录：`实际游戏实例/game-console/piq-gba/runtime/`。

- 完整且哈希一致：直接复用，不重写。
- 缺文件：仅从当前已加载的附属 JAR 补齐，全部缺失内容先校验再提交。
- 文件损坏、异版本或路径是链接：拒绝覆盖，保留原文件，在运行环境诊断及日志说明。退出游戏后先备份并移走明确冲突的运行库文件，再重启；不要删除整个 game-console 或 saves。
- Windows x64 执行端使用内置核心。其它系统/ARM不解压、不加载原生库，可加载物品和参加原有旁观；不代表支持本机运行。
- GBA准备安排在LoadComplete加载工作线程，位于街机CommonSetup准备之后，避免两附属正常启动时争抢安装锁；运行时不在渲染/服务器tick安装，不在Minecraft进程加载DLL。

在Windows服务器上，即使不开服务器托管也会准备约4.6MiB运行库，但不会因此启动核心；是否托管仍由原配置/权限决定。安装失败不使整包因DLL缺失而加载崩溃，可从“运行环境”检查，在退出世界/没有模拟器运行时重试。

## 使用和边界

GBA掌机主手右键，Shift+右键选自己的 `.gba` 文件。游戏、电池存档位置和隔离规则不变；仍不附游戏ROM或任天堂BIOS。掌机仍为本地单机，没有新增GBA通讯线联机。单席机柜保留已有旁观与可选服务器托管，不新增控制席。

已完成自动安装/冲突保护/平台限制与最终JAR原生测试，尚未完整Minecraft实机验收；本轮没有自动安装、部署、重启或改动真实存档。详情见同包VERIFICATION.md。

FC76.3此轮只改内置来源注册；此前确认的双人机柜连接线状态漏同步问题仍待修复，没有在此包中顺带宣称修好。管理员DIP/Service建议尚未实施。

## 源码与许可

同包提供原固定运行库的许可、mGBA对应源码归档与身份记录、GBA当前源码及本轮主包改动/构建和测试脚本。mGBA/JNA/helper和原资产均保留原条款；来源说明在JAR的 `META-INF/licenses/gba-runtime/`。这不是已完成所有历史主包依赖公开发行审查的声明。
