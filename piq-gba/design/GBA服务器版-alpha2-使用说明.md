# GBA 服务器版 alpha2（配套 FC alpha31）

这次只交付文件，没有安装到任何客户端或服务器，也没有发布版本。

## 装哪些文件

- 服务器和所有玩家的客户端：将 `mods` 中的 **FC alpha31** 和 **GBA alpha2** 放进各自 `mods` 文件夹。先把旧 FC 主包、旧 GBA 附属移到 `mods` 之外备份，避免同一模组同时出现两个版本。
- 已安装的 **SFC alpha18**、**原生街机 alpha10** 保留，不需要删除；本包不重复附带它们，也不更换它们的模拟核心。
- 要亲自启动 GBA 游戏的 Windows x64 客户端：把 `piq-gba/runtime` 放到游戏实例根目录。完整保留里面三个文件；不要把 helper/JNA 放入 `mods`。
- **服务器不需要 runtime、DLL、BIOS 或 ROM。** 只旁观的客户端不需要 GBA 运行库或该游戏 ROM。

要求 Minecraft 1.21.1、NeoForge 21.1.236 或兼容更新版、Java 21。本版共享街机协议为 `cabinet-room-3`，不能只升级服务器或只升级一个玩家；所有客户端/服务器必须配套 FC31。不要和 FC30 主包混用。

## 怎么玩

1. 放置现有单人或双人外形街机。GBA 在两种柜体上都只有 **一个控制席位**。
2. 空手 Shift + 右键打开设置，选择 GBA，打开 ROM 文件夹，将自己有权使用的 `.gba` 放入客户端 `piq-gba/roms` 并选择。
3. 配置后，普通右键街机启动，再次右键同一台退出。游戏尚未配置时，按提示进入设置，不会让服务器读取本机任意路径。
4. 其他玩家走近即可自动旁观，不必右键占席、下载游戏或启动第二个模拟器。另一玩家右键不会抢走控制权或生成 P2。
5. 控制方式沿用共享街机设置，F7 查看实际绑定；GBA 支持方向、A/B、Start/Select、L/R。X/Y 不是 GBA 功能键。

主持玩家主动退出、离线、走出街机原有约 8 格范围或机柜失效时，本局和旁观结束。没有主持迁移、无人时服务器后台继续运行或服务器代玩。

## 存档在哪里

使用游戏自身的保存功能后，电池存档保存在主持玩家本机：

`piq-gba/saves/scoped-v1/<服务器或世界摘要>/<玩家UUID>/mgba-e31759b/<ROM摘要>/`

同一玩家、同一服务器、同一个游戏在不同街机继续使用同一份进度；不同服务器/本地世界或不同玩家隔离。换服务器地址/端口、改变本地世界目录或玩家 UUID 会形成不同作用域。不会把旧地址下的进度擅自合并。

这是电池 SRAM/EEPROM/Flash 自动落盘，不是任意时刻即时存档，也不是服务器托管或云同步。每 300 个模拟帧及正常退出保存；非正常结束可能丢失尚未落盘的最近进度。旧 alpha1 的 `piq-gba/saves/mgba-e31759b` 保留原样，不自动迁移或覆盖；ROM 旁原有 `.sav` 也不改动。

## 本次没有做什么

- 没有手持 GBA 屏幕或掌机模型交互。
- 没有 GBA 原生通讯线：不能用街机数据线实现《宝可梦》交换/对战，也不能把一台 GBA 游戏分成 P1/P2。
- 没有修改合金弹头减速或旁观视频帧率；它们是独立优化项。
- 不附商业 ROM 或 Nintendo BIOS；沿用现有 mGBA HLE BIOS。运动/光照传感器等特殊卡带未经验证。

## 验证边界与许可证

本地验证使用原创 ARM 诊断程序、真实 mGBA 子进程、实际最终 JAR 的协议/权限/旁观状态及专用服务器侧隔离加载检查。证据随包；这不等于已用两台电脑在真实 Minecraft 服务器上完成游戏验收。首次请在备份过的测试环境验证启动、旁观、退出、重连和游戏内保存。

核心仍为官方 mGBA `0.11-219-e31759b`，仅在启动者独立子进程加载；不是操作系统安全沙箱，请使用可信游戏文件。对应完整源码、MPL-2.0、PIQ GPL-3.0-or-later 与 JNA Apache-2.0 声明在 `licenses-and-source`，原型实现说明见 `docs/GBA实现说明.md`。
