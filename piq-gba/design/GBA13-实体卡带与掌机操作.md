## 生命周期与权限

## 玩家操作

1. 创造列表取“GBA 游戏卡带”，**另一手先不要拿掌机**，持卡右键老式电脑；选择服务器游戏写卡，或明确选择本地 `.gba` 上传写卡。没有上传/游戏库权限请联系管理员，失败不覆盖原卡。
2. 掌机与卡带分持主副手，右键插入；两个手序都支持。掌机仍是物品，不放地面。换卡须先关机，旧卡返回另一手。
3. Shift＋右键开机/关机；普通右键举起到眼前，再右键放下。放下后核心继续，释放操作并静音；再次举起恢复。右键长按不会反复切换。
4. `/gameconsole-gba` 打开设置，或在MC按键设置绑定“GBA 掌机设置 / 退卡”（默认不占用按键）。可调整公共键盘/手柄、查看同步说明，关机后退卡到空另一手或背包；背包无位置则不退卡。返回设置不关机。
5. 切走掌机所在主手槽、移出所在手、死亡/换维度/离线会安全停止并请求原电池保存；这与普通右键“放下”不同。旧的本地选游戏记录保留，但不自动上传/转成新卡。

## 明确输入的构建/QA

旧固定GBA3脚本不是本版入口。先按根BUILDING说明准备并验证主包固定输入，用Java21构建FC76.28。然后：

```text
python piq-gba/tools/build_current.py --fc <FC76.28.jar> --runtime-base <已核准GBA12.jar> --dependencies <真实NeoForge依赖目录> --jdk <JDK21/bin> --output <不存在的输出目录>
python piq-gba/tools/check_current.py --fc <同一FC76.28.jar> --gba <新GBA13.jar> --dependencies <同上> --minecraft-client <官方1.21.1客户端资源jar> --jdk <JDK21/bin> --output <不存在的QA目录>
```

本次仍借核准旧包提取固定运行库及许可，干净克隆尚需这些显式合法输入，不声称全附属构建闭合。QA保留临时ASCII目录并记录路径，生产类仅来自被测JAR的同SHA副本，使用原创诊断ROM和隔离保存，不读写用户ROM/电池档。
