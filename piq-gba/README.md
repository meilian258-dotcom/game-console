## 文件与使用

Java 21、Minecraft 1.21.1 / NeoForge 21.1.236，需要配套 PIQ FC 主模组 **alpha.33**（声明兼容范围 `[0.31.0-alpha.33,0.32)`）。支持本地世界、局域网及远程服务器；本次仅编译 GBA 附属，FC33、旧柜体流程和原生运行库保持不变。

服务端与客户端均需在 `mods` 放置配套 FC 主包和 `piq_gba-0.1.0-alpha.3.jar`，旧 GBA JAR 备份到 mods 之外，勿同时安装。新增掌机有正式物品注册，不能只更新一端。专用服务器只加载 GBA 通用声明和物品，**不需要 DLL、JNA、helper 或游戏 ROM，不在服务器执行原生核心**。

只有实际操作 GBA 的客户端需要 Windows x64，并把随包 `piq-gba/runtime` 整个目录放在实例根目录，不放进 `mods`；helper、JNA 和 DLL 三个文件缺一不可，必须保持配套版本。仅旁观的客户端不启动额外核心，不需要运行库或 ROM。本包只提供文件和说明，没有执行安装或修改实例。

在现有街机 Shift + 右键配置中选 `GBA · 单席游戏`，打开游戏目录，放入你有权使用的 `.gba` 文件并确认选择。游戏文件仅从当前操作玩家本机读取，不上传 ROM，也不使用服务器发来的文件路径。普通右键按 FC 通用机柜流程启动/退出，仍受机柜距离、保护权限及独占租约限制。没有提供商业游戏 ROM 或 Nintendo BIOS；核心使用内置 HLE BIOS。完整上游源码自带开发回归测试 ROM/存档夹具，仅用于源码测试，不是用户游戏或存档，也不是运行必装数据。

单人柜和双人柜选择 GBA 后都只有一个操作席，不弹出 P2 邀请，不允许用数据线把两台柜连成 GBA 多人局。附近玩家无需右键即可按 FC 自动旁观规则观看同一画面，不占操作席。操作者退出、断线、离开允许范围或机柜失效后本局结束，不把核心转交给观众。

街机保留共享 **街机（ARCADE）** 按键方案。新掌机复用共享 **SFC** 十键子集及控制器设置，方向、A/B、Start/Select、L/R 有效，X/Y 不对应 GBA 按钮。Z 切换移动锁定，切走主手物品、死亡或离开世界时关闭并保存电池存档。仅 LEGACY 原有主键在开机时捕获，改变这些键后重新开机生效；其他共享方案按其设置生效。柜体六按钮外观与掌机布局不作同位置承诺。

## 存档与边界

只实现电池 SRAM/EEPROM/Flash，不是 FC 的个人三槽或即时存档菜单。新版路径为实例内 `piq-gba/saves/scoped-v1/<服务器或世界身份摘要>/<玩家UUID>/mgba-e31759b/<ROM的SHA256>/`。启动时在客户端主线程冻结当前世界或完整服务器地址（保留协议与端口）和玩家身份，后台核心不重新读取切换后的世界。相同上下文、玩家、ROM 可延续存档，不同服务器/世界或玩家不共用；这不是服务器云存档，改服务器地址、换实例或离线身份变化可能看到新存档。

**alpha.1 旧目录 `piq-gba/saves/mgba-e31759b/` 保持原字节且不自动读取、迁移或写回**，因此升级首次启动会使用新的隔离存档。也不会读取或覆盖原 ROM 旁的 `.sav`。如需迁移应先备份并明确目标，本版不替用户操作历史存档。

每 300 帧及正常退出保存，写入前备份旧数据并原子替换；突然结束进程可能丢最近约 5 秒。坏主档可读取好备份，下一次保存保留坏档为独立 `sram.corrupt-*.bin` 后恢复。

一个客户端最多一个 GBA 子进程。原生库只在自有 Java 子进程加载；Minecraft 进程中不加载 mGBA/JNA。文件哈希、帧、音频、队列和超时受限；该进程隔离**不是操作系统安全沙箱**，请只选择可信合法 ROM。不支持运动/太阳传感器、GBA 原生网络联机、掌机连接线或任何未验证的特殊卡带功能。

## 本地构建与验收入口

在本工作区使用 Java 21 和现有真实 NeoForge 缓存，不运行旧项目 Gradle：

```text
python piq-gba/tools/build_gba_handheld3.py --fc <冻结FC33主包.jar> --output <piq-gba/build内不存在的新目录>
python piq-gba/tools/check_gba_handheld3.py --fc <同一FC33主包.jar> --bundle <上一步目录> --report <新报告.json>
```

构建脚本只编译 `piq-gba`。最终复验仅编译探针，生产类型从实际交付 JAR 加载，使用原创 ARM 诊断 ROM 验证 RGB565、十键、PCM、SRAM/重启和关闭，并用真实 FML 读取元数据和扫描入口。不会启动 Minecraft 世界，不触碰用户 ROM 或存档。诊断通过不等于全部商业游戏兼容，更不等于已经完成游戏内手持掌机实测。
