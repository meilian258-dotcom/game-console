# 方块电玩 GBA

本附属提供可拿在手里的 GBA 掌机、实体卡带，以及公共机柜中的单席 GBA 游戏选项。掌机使用自己的屏幕和按键，不需要电视或另领家用手柄。

这是[方块电玩](../README.md)的可选测试组件。首次使用先看[统一玩家指南](../piq-fc-arcade/docs/玩家指南.md)，不要把旧版本的右键操作与当前掌机流程混用。

## 安装条件

- Minecraft 1.21.1、Java 21、NeoForge 21.1.229 及以上的 21.1 系列；仍需满足整合包其他模组的要求。
- 多人服务器和参与客户端都安装配套主包与 `game-console-gba-版本.jar`。单人世界只需装进客户端实例。
- 核心运行端目前支持 Windows x64，使用随候选包配套的 mGBA；不需要另外安装 RetroArch，也不提供商业游戏或 Nintendo BIOS。
- JAR 已包含配套运行库并在加载阶段准备文件。不要从网上随意找同名 DLL 覆盖，也不另装内部公共层 JAR。

两端安装用于共同物品注册、卡槽事务和网络授权；个人掌机的核心运行在玩家客户端，不因服务端装了附属就自动托管掌机。

## 掌机怎么用

1. 手持 GBA 卡带右键老式电脑，选择自己的 `.gba` 游戏，确认写入。工作台中的“ROM 目录”可打开本机正确目录；上传需服务器许可。
2. 掌机和写好的卡带分拿主副手，**Shift＋右键插卡**，两手顺序均可。已有卡时不会无声覆盖。
3. 另一只手没有待插入的 GBA 卡带时，**Shift＋右键开关机**。
4. **普通右键举起或放下掌机**。放下只退出操作，不会关机；举起后通过屏幕和已绑定的游戏按键游玩。
5. **Shift＋左键安全拔卡**：等待电池进度保存后退还卡带；保存失败或超时不会直接拔卡。
6. 手持掌机执行 `/gameconsole-gba` 打开设置，可查看键位、实体手柄、运行器与退卡入口；也可在 MC 按键设置里绑定掌机设置键。

本机掌机拷卡目录是 `game-console/content-cards/piq_gba/gba/`。公共机柜使用独立的 `game-console/piq-gba/roms/` 目录，请从对应界面的目录按钮进入，避免放错位置。

## 掌机与街机不是同一种多人模式

掌机目前是本机单人，不广播随身屏幕或音频，不支持 GBA 原生通讯线或 Netplay。卡带可由服务器内容库提供，但这不等于进度自动上传为服务器档。

公共机柜选择“GBA · 单席游戏”后，只有一个操作席；附近玩家通过音画串流旁观，不运行一份可参与的 GBA 联机局。机柜的服务端托管是另一条可用运行路径，不适用于个人掌机。两台机柜不能靠通讯线拼成 GBA 多人局。

受支持的 Windows 运行端默认使用公共 JNI，设置页保留显式的进程兼容选择。二者存档分开，不会自动搬旧档；JNI 原生故障可能使 Minecraft 一起退出。

## 进度和限制

- 保存游戏自身的电池 RAM（SRAM、EEPROM、Flash），不是家用机的个人三槽或任意时刻即时存档。
- 个人掌机进度在本机 `game-console/piq-gba/saves/` 下，按服务器或世界、玩家、游戏与运行器隔离；换实例或身份不自动带走进度。
- 正常关机和安全拔卡会请求保存；意外退出只能保留已落盘的进度。备份时在退出游戏后复制完整对应保存目录。
- 尚未提供随卡服务器进度、掌机通讯线、运动／太阳传感器等特殊卡带能力；JNI 路径的 RTC 内存仍待适配。
- 游戏、模型、多人服务器及具体光影环境的实测范围不同，不保证所有 `.gba` 游戏兼容或当前候选已经稳定。

## 开发入口

构建使用 `tools/build_current.py`，包级核对使用 `tools/check_current.py`，需要显式的配套主包与依赖输入；不要照历史 README 使用旧 GBA3 构建命令。先读[统一构建说明](../source-control/BUILDING.md)、[掌机与卡带说明](design/GBA13-实体卡带与掌机操作.md)及[当前插拔卡手势的实现记录](../piq-md-home/design/MD6-GBA14-反馈修复.md)。

mGBA 和随附依赖保留各自许可证；适配代码的许可证不改变核心或游戏内容权利。游戏文件需由使用者合法提供。

版本变更、核心来源与旧验证记录见[历史 README](README-history.md)；其他文档见[文档索引](../piq-fc-arcade/docs/README.md)。
