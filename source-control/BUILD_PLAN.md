# 固定构建输入：第一阶段

本阶段为 FC 主模组建立固定输入清单与独立缓存，不改变游戏运行逻辑、协议、存档格式或默认运行模式。

## 已完成范围

- 以固定 SHA 和大小描述 JNA、Mesen、JNI 桥、RetroArch 与 WASM 输入。
- 提供导入和完整性检查命令，拒绝缺项、哈希不符及冲突文件。
- 构建显式读取缓存，不隐式读取历史输出或未提交的二进制。
- 在独立源码目录、具备固定依赖缓存的条件下执行实际构建和资源校验。
- 收窄运行目录忽略规则，避免遗漏 Java 的 `world` 源码包，并增加回归测试。

## 验证范围

当时的独立源码构建通过，2558 项测试中 10 项跳过，0 失败或错误；9 项固定输入的哈希、345 份源资源的一致性及错误副本不抢占缓存均完成检查。构建工具测试 19 项，其中 1 项权限测试跳过。

这些数字仅对应本阶段基线，不等于当前全部附属的测试结果，也不代表空 Maven 缓存可以离线构建。没有据此宣称通过 Minecraft 实机、全部核心兼容或 JNI 联机验证。

## 后续边界

附属的历史主包依赖、自定义合包入口、全部第三方源码与许可配套、远端 CI 不属于本阶段完成范围。开发构建不自动成为发行包，素材也须单独审核。

当前操作命令、输入说明与限制见[构建指南](BUILDING.md)。
