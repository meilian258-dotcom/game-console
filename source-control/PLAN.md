# 源码基线与版本控制范围

仓库以方块电玩的源码组件及共用构建工具为范围，保留组件同级布局和既有构建相对路径。早期源码导入建立的是开发基线，不代表稳定发行。

## 纳入与排除

- 纳入源码、测试、构建声明、已审查的模型资源、许可与技术文档。
- 排除构建缓存、运行库二进制、ROM、BIOS、世界、玩家数据、部署配置及凭据。
- 对外部固定输入记录版本、大小、SHA 和许可，不以同名文件代替。
- 无关项目不进入本仓库；新增组件需更新提交范围检查。

## 基线检查

1. 审核实际提交清单、敏感内容和素材许可。
2. 核对 Git 对象与预期源文件字节一致。
3. 在独立克隆中运行源码检查、构建和相关测试；如实列出外部输入条件和未验证项。
4. 备份与源码之外的数据分别管理，不把同盘副本视为远程备份。

日常贡献流程以[开发协作](../GIT_WORKFLOW.md)为准；构建条件见[构建指南](BUILDING.md)。
